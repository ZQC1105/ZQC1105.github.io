以下是 C# 相关问题的中文答案：

## 1. readonly 与 const 的区别

| 特性                 | const                          | readonly                   |
| -------------------- | ------------------------------ | -------------------------- |
| **编译时 vs 运行时** | 编译时常量，值在编译时确定     | 运行时常量，值在运行时确定 |
| **赋值时机**         | 声明时赋值                     | 声明时或构造函数中赋值     |
| **作用域**           | 隐式为静态（static）           | 可以是实例或静态           |
| **内存分配**         | 无内存分配，值内联到代码中     | 有内存分配                 |
| **类型限制**         | 只能用于基本类型、string、null | 可以是任何类型             |
| **修改**             | 不能修改                       | 不能修改（除构造函数外）   |
| **使用场景**         | 数学常量、固定值               | 配置值、需要运行时计算的值 |

**代码示例**：

```csharp
public class Example
{
    // const：编译时常量
    public const double Pi = 3.14159;
    public const string AppName = "MyApp";

    // readonly：运行时常量
    public readonly int Id;
    public static readonly DateTime StartupTime = DateTime.Now;

    public Example(int id)
    {
        Id = id;  // 可以在构造函数中赋值
    }
}

// 使用
Console.WriteLine(Example.Pi);           // 直接类名访问
Console.WriteLine(Example.StartupTime);  // 静态 readonly
var ex = new Example(100);
Console.WriteLine(ex.Id);                 // 实例 readonly
```

## 2. sealed 关键字的用途

**sealed** 用于**阻止继承**或**阻止重写**。

**用途**：

```csharp
// 1. 密封类：不能被继承
public sealed class FinalClass
{
    public void Method() { }
}
// public class Derived : FinalClass { }  // ❌ 编译错误

// 2. 密封方法：阻止派生类重写
public class BaseClass
{
    public virtual void VirtualMethod() { }
}

public class DerivedClass : BaseClass
{
    public sealed override void VirtualMethod() { }  // 密封此方法
}

public class FurtherDerived : DerivedClass
{
    // public override void VirtualMethod() { }  // ❌ 不能重写
}

// 3. 密封属性
public class Base
{
    public virtual string Name { get; set; }
}

public class Derived : Base
{
    public sealed override string Name { get; set; }
}
```

**使用场景**：

- 防止意外继承（如系统关键类）
- 性能优化（密封类可以被 JIT 优化，方法调用可内联）
- 安全考虑（防止继承破坏逻辑）

## 3. 类型的访问修饰符

**顶级类型（命名空间内直接定义）**：

| 修饰符             | 说明                       |
| ------------------ | -------------------------- |
| `public`           | 任何代码都可以访问         |
| `internal`（默认） | 仅在**当前程序集**内可访问 |

**嵌套类型（类内部定义）**：

| 修饰符                         | 说明                             |
| ------------------------------ | -------------------------------- |
| `public`                       | 任何代码都可以访问               |
| `private`（默认）              | 仅包含类内可访问                 |
| `protected`                    | 包含类或派生类内可访问           |
| `internal`                     | 当前程序集内可访问               |
| `protected internal`           | 当前程序集 **或** 派生类内可访问 |
| `private protected`（C# 7.2+） | 当前程序集内的派生类内可访问     |

**示例**：

```csharp
public class OuterClass
{
    public int PublicField;
    private int PrivateField;
    protected int ProtectedField;
    internal int InternalField;
    protected internal int ProtectedInternalField;
    private protected int PrivateProtectedField;

    // 嵌套类型
    public class PublicNested { }
    private class PrivateNested { }
    protected class ProtectedNested { }
    internal class InternalNested { }
}
```

## 4. 接口（Interface）与抽象类（Abstract Class）的区别

| 特性           | 接口                                | 抽象类                  |
| -------------- | ----------------------------------- | ----------------------- |
| **多继承**     | ✅ 一个类可实现多个接口             | ❌ 只能继承一个抽象类   |
| **实现代码**   | ❌ 不能有实现（C# 8+ 允许默认实现） | ✅ 可以有具体方法和实现 |
| **字段**       | ❌ 不能有实例字段                   | ✅ 可以有实例字段       |
| **构造函数**   | ❌ 不能有构造函数                   | ✅ 可以有构造函数       |
| **访问修饰符** | 默认 public，不能其他               | 支持各种访问修饰符      |
| **状态**       | ❌ 无状态                           | ✅ 可以有状态           |
| **版本兼容**   | 添加成员会破坏实现                  | 添加成员不影响派生类    |
| **使用场景**   | 定义契约、多行为                    | 提供公共基类实现        |

**代码示例**：

```csharp
// 接口：定义契约
public interface IFlyable
{
    void Fly();
    // C# 8+ 默认实现
    void Land() => Console.WriteLine("Landing...");
}

// 抽象类：提供部分实现
public abstract class Animal
{
    protected string Name;

    public Animal(string name)
    {
        Name = name;
    }

    public abstract void MakeSound();

    public void Eat() => Console.WriteLine($"{Name} is eating");
}

// 实现
public class Bird : Animal, IFlyable
{
    public Bird(string name) : base(name) { }

    public override void MakeSound() => Console.WriteLine("Chirp");

    public void Fly() => Console.WriteLine($"{Name} is flying");
}
```

## 5. 静态构造函数何时被调用？

静态构造函数在以下情况**首次**发生前被调用（只调用一次）：

1. **首次创建实例**之前
2. **首次访问静态成员**之前

**示例**：

```csharp
public class MyClass
{
    static MyClass()
    {
        Console.WriteLine("静态构造函数执行");
        StaticValue = 100;
    }

    public static int StaticValue;

    public MyClass()
    {
        Console.WriteLine("实例构造函数执行");
    }

    public static void StaticMethod() { }
}

// 触发场景
MyClass.StaticMethod();        // ✅ 触发静态构造函数
var obj1 = new MyClass();      // ✅ 触发静态构造函数（如果之前未触发）
var obj2 = new MyClass();      // ❌ 不会再触发
Console.WriteLine(MyClass.StaticValue);  // ✅ 触发静态构造函数
```

**特点**：

- 无参数、无访问修饰符
- 不能直接调用
- 不能抛出异常（否则类型不可用）
- 执行顺序：静态构造函数 → 基类静态构造函数 → 实例构造函数

## 6. 如何创建扩展方法（Extension Method）？

**步骤**：

1. 创建**静态类**
2. 创建**静态方法**
3. 第一个参数使用 `this` 关键字

**示例**：

```csharp
// 1. 创建扩展方法
public static class StringExtensions
{
    // 扩展 string 类型
    public static bool IsNullOrEmpty(this string str)
    {
        return string.IsNullOrEmpty(str);
    }

    public static string Reverse(this string str)
    {
        return new string(str.Reverse().ToArray());
    }

    // 带参数
    public static string Truncate(this string str, int maxLength)
    {
        if (string.IsNullOrEmpty(str) || str.Length <= maxLength)
            return str;
        return str.Substring(0, maxLength) + "...";
    }
}

public static class IntExtensions
{
    public static bool IsEven(this int number)
    {
        return number % 2 == 0;
    }
}

public static class IEnumerableExtensions
{
    public static void ForEach<T>(this IEnumerable<T> source, Action<T> action)
    {
        foreach (var item in source)
        {
            action(item);
        }
    }
}

// 2. 使用
using StringExtensions;  // 导入命名空间

string text = "Hello World";
bool empty = text.IsNullOrEmpty();        // false
string reversed = text.Reverse();          // "dlroW olleH"
string truncated = text.Truncate(5);       // "Hello..."

int number = 10;
bool isEven = number.IsEven();             // true

var list = new List<int> { 1, 2, 3 };
list.ForEach(x => Console.WriteLine(x));   // 输出 1 2 3
```

## 7. C# 支持多类继承吗？

**不支持**。C# 不支持多个类继承（多重继承），但支持：

- ✅ **多个接口继承**
- ✅ **单类继承 + 多接口实现**

**原因**：

- 避免**菱形继承问题**（钻石问题）
- 减少复杂性

**示例**：

```csharp
// ❌ 不支持多类继承
// public class Child : ClassA, ClassB { }  // 编译错误

// ✅ 单类继承 + 多接口实现
public class Child : ParentClass, IInterfaceA, IInterfaceB, IInterfaceC
{
    // 实现所有接口方法
}

// 接口可以多继承
public interface ICombined : IInterfaceA, IInterfaceB, IInterfaceC
{
}

// 使用默认接口方法（C# 8+）实现类似多继承的行为
public interface ILogger
{
    void Log(string message) => Console.WriteLine($"Log: {message}");
}

public interface IEmailSender
{
    void Send(string to) => Console.WriteLine($"Email to: {to}");
}

public class Service : ILogger, IEmailSender
{
    // 可以继承默认实现，也可以重写
}
```

## 8. 装箱（Boxing）和拆箱（Unboxing）

| 操作     | 说明                        | 性能影响           |
| -------- | --------------------------- | ------------------ |
| **装箱** | 值类型 → 引用类型（object） | 分配堆内存，复制值 |
| **拆箱** | 引用类型 → 值类型           | 类型检查，复制值   |

**示例**：

```csharp
// 装箱
int i = 123;
object obj = i;      // 装箱：int 值被包装到 object 中

// 拆箱
int j = (int)obj;    // 拆箱：从 object 中提取 int

// 示例：ArrayList 存储值类型（装箱）
ArrayList list = new ArrayList();
list.Add(10);        // 装箱 int
list.Add(20);        // 装箱 int
int first = (int)list[0];  // 拆箱

// 泛型避免装箱
List<int> genericList = new List<int>();
genericList.Add(10);  // 无装箱
genericList.Add(20);  // 无装箱

// 常见装箱场景
int x = 10;
object o = x;                    // 装箱
Console.WriteLine(x);            // 无装箱（Console.WriteLine 有 int 重载）
Console.WriteLine(o);            // 无额外装箱

// 危险操作
object obj2 = 100;
long l = (long)obj2;             // ❌ InvalidCastException（类型必须完全匹配）
long l2 = (int)obj2;             // ✅ 先拆箱成 int，再隐式转换
```

**性能对比**：

```csharp
// 装箱版本
Stopwatch sw = Stopwatch.StartNew();
object sum = 0;
for (int i = 0; i < 10_000_000; i++)
{
    sum = (int)sum + i;  // 拆箱 + 加法 + 装箱
}
sw.Stop();  // 很慢

// 无装箱版本
int sum2 = 0;
for (int i = 0; i < 10_000_000; i++)
{
    sum2 += i;  // 直接操作值类型
}
sw.Stop();  // 快很多
```

## 9. 堆（Heap）和栈（Stack）的区别

| 特性         | 栈（Stack）              | 堆（Heap）           |
| ------------ | ------------------------ | -------------------- |
| **存储内容** | 值类型、引用类型的引用   | 引用类型的实际对象   |
| **分配方式** | LIFO（后进先出）         | 随机分配             |
| **分配速度** | 快（移动指针）           | 慢（需查找空闲内存） |
| **生命周期** | 自动（超出作用域即释放） | GC 管理              |
| **大小限制** | 小（默认 1MB）           | 大（系统内存）       |
| **线程关系** | 每个线程独立栈           | 所有线程共享堆       |

**示例**：

```csharp
public void Method()
{
    int x = 10;           // 栈：值类型
    string name = "Bob";  // 栈：引用（指向堆中的字符串）
    Person person = new Person();  // 栈：引用，堆：Person 对象

    // 内存布局
    // 栈：
    //   x = 10
    //   name = 0x1234 (地址)
    //   person = 0x5678 (地址)
    // 堆：
    //   0x1234: "Bob"
    //   0x5678: Person 对象 { Name = null, Age = 0 }
}
```

**图解**：

```
栈（Stack）                      堆（Heap）
高地址 ↑                         ┌─────────────┐
├─────────────┤                 │ Person 对象 │
│ person 引用 ├──────────────→  │  Name: null │
├─────────────┤                 │  Age: 0     │
│ name 引用   ├──────────────→  └─────────────┘
├─────────────┤
│ x = 10      │                 ┌─────────────┐
├─────────────┤                 │ "Bob" 字符串│
│ ...         │                 └─────────────┘
低地址 ↓
```

## 10. string 与 StringBuilder 的区别

| 特性         | string               | StringBuilder    |
| ------------ | -------------------- | ---------------- |
| **可变性**   | 不可变（Immutable）  | 可变（Mutable）  |
| **内存分配** | 每次修改创建新对象   | 在缓冲区中修改   |
| **性能**     | 多次修改时差         | 多次修改时好     |
| **线程安全** | 安全（不可变）       | 不安全（需同步） |
| **命名空间** | System               | System.Text      |
| **适用场景** | 少量拼接、字符串常量 | 大量动态拼接     |

**示例**：

```csharp
// string：不可变
string s = "Hello";
s += " World";  // 创建新字符串，"Hello" 等待 GC

// StringBuilder：可变
StringBuilder sb = new StringBuilder();
sb.Append("Hello");
sb.Append(" World");
string result = sb.ToString();

// 性能对比
Stopwatch sw = Stopwatch.StartNew();

// ❌ 差：100,000 次拼接
string str = "";
for (int i = 0; i < 100000; i++)
{
    str += i.ToString();  // 每次创建新对象
}
sw.Stop();  // 非常慢（几秒）

// ✅ 好：100,000 次拼接
sw.Restart();
StringBuilder sb2 = new StringBuilder();
for (int i = 0; i < 100000; i++)
{
    sb2.Append(i);
}
string result2 = sb2.ToString();
sw.Stop();  // 很快（几毫秒）
```

**StringBuilder 高级用法**：

```csharp
// 预分配容量
StringBuilder sb = new StringBuilder(10000);  // 避免多次扩容

// 链式调用
sb.Clear()
  .Append("Hello")
  .AppendLine()
  .AppendFormat("Value: {0}", 42)
  .Replace("Hello", "Hi");

// 插入和删除
sb.Insert(0, "Start: ");
sb.Remove(0, 7);

// 获取指定字符
char c = sb[5];

// 设置容量
sb.Capacity = 20000;
```

**选择指南**：

| 场景                       | 推荐            |
| -------------------------- | --------------- |
| 字符串常量、少量拼接       | `string`        |
| 循环内大量拼接             | `StringBuilder` |
| 字符串作为键（Dictionary） | `string`        |
| 需要频繁修改内容           | `StringBuilder` |
| 字符串插值（一次拼接）     | `$"{a}{b}{c}"`  |
