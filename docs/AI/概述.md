# Cline 中 MCP：能力扩展协议

MCP（Model Context Protocol）是 Cline 中**最强大的扩展机制**——它让 Cline 能够突破自身限制，**连接外部世界**，调用数据库、API、浏览器等任何外部工具。

---

## 🎯 MCP 一句话定位

> **"让 AI 能用任何外部工具和数据"**

- **Rules** = 告诉 AI "怎么想"（约束）
- **Skills** = 告诉 AI "怎么做"（知识）
- **Workflows** = 定义 "做什么流程"（编排）
- **Hooks** = 事件触发 "自动做"（脚本）
- **MCP** = **扩展能力 "能做更多"**（工具）

---

## 📊 MCP vs 其他机制

| 维度         | Rules    | Skills   | Workflows | Hooks      | **MCP**                     |
| :----------- | :------- | :------- | :-------- | :--------- | :-------------------------- |
| **本质**     | 行为约束 | 专家知识 | 流程编排  | 自动化脚本 | **能力扩展**                |
| **能力范围** | 约束 AI  | 指导 AI  | 组织 AI   | 触发脚本   | **连接外部**                |
| **AI 参与**  | ✅ 遵守  | ✅ 学习  | ✅ 执行   | ❌ 无      | ✅ 调用                     |
| **能做什么** | 改行为   | 改知识   | 改流程    | 自动操作   | **查数据库、调API、浏览器** |
| **复杂度**   | 低       | 中       | 中        | 低         | **高**                      |

## 🏗️ MCP 架构

MCP 采用 **客户端-服务器** 架构：

```
┌─────────────────────────────────────────────────────┐
│                   VS Code + Cline                    │
│                  (MCP Client 端)                     │
└─────────────────────────────────────────────────────┘
                        ↓ MCP 协议
        ┌───────────────┼───────────────┐
        ↓               ↓               ↓
┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│ MCP Server   │ │ MCP Server   │ │ MCP Server   │
│ (PostgreSQL) │ │ (GitHub)     │ │ (Puppeteer)  │
└──────────────┘ └──────────────┘ └──────────────┘
        ↓               ↓               ↓
   PostgreSQL      GitHub API      浏览器自动化
   数据库           REST API        截图/爬虫
```

### 核心概念

| 概念           | 说明               | 示例                                |
| :------------- | :----------------- | :---------------------------------- |
| **MCP Client** | 发起请求的 AI 应用 | Cline 扩展本身                      |
| **MCP Server** | 提供工具的独立服务 | PostgreSQL MCP Server               |
| **Tools**      | 可执行的函数       | `query_database`、`create_issue`    |
| **Resources**  | 可读取的数据       | `postgres://users`、`file://config` |

## 🚀 实际使用示例

### 示例1：查询数据库

**配置**（在 Cline 设置中）：

```json
{
  "mcpServers": {
    "postgres": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-postgresql",
        "postgresql://localhost:5432/myapp"
      ]
    }
  }
}
```

**对话**：

```
用户：查询 users 表中最近注册的 5 个用户

Cline（内部）：
→ 检测到需要查询数据库
→ 发现可用的 MCP 工具：postgres:execute_sql
→ 调用工具，参数：SELECT * FROM users ORDER BY created_at DESC LIMIT 5

Cline（输出）：
"查询到最近注册的 5 个用户：
1. alice@example.com (2024-03-20)
2. bob@example.com (2024-03-19)
..."
```

### 示例2：创建 GitHub Issue

**配置**：

```json
{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_TOKEN": "ghp_xxxxx"
      }
    }
  }
}
```

**对话**：

```
用户：帮我创建一个 Issue，标题是"修复登录 bug"，内容是"用户无法登录"

Cline：
→ 调用 github:create_issue
→ 参数：owner=myrepo, repo=myapp, title="修复登录 bug", body="用户无法登录"

Cline（输出）：
"已创建 Issue #42：https://github.com/myrepo/myapp/issues/42"
```

### 示例3：浏览器截图

**配置**：

```json
{
  "mcpServers": {
    "puppeteer": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-puppeteer"]
    }
  }
}
```

**对话**：

```
用户：帮我截取 https://example.com 的首页截图

Cline：
→ 调用 puppeteer:screenshot
→ 参数：url="https://example.com", fullPage=true

Cline（输出）：
"已保存截图到 screenshot.png"
```

```
│ 步骤3: 执行操作                                      │

├─────────────────────────────────────────────────────┤
│ 步骤4: 触发 Hooks                                   │
│   - 部署成功通知（Hook 触发 MCP: slack）← 联动      │
│   - 记录日志（Hook 写文件）                         │
└─────────────────────────────────────────────────────┘
```

| 机制          | 本质         | 触发方式     | AI 参与 | 能力范围     | 典型用途       |
| :------------ | :----------- | :----------- | :------ | :----------- | :------------- |

| **Skills**    | 专家知识     | 按需触发     | ✅ 学习 | 指导文档     | 最佳实践       |
| **Workflows** | 流程编排     | 手动调用     | ✅ 执行 | 步骤序列     | 发布流程       |

| **MCP**       | **能力扩展** | **按需调用** | ✅ 调用 | **外部工具** | **数据库/API** |
| **内置能力**  | 基础操作     | 直接调用     | ✅ 执行 | 文件/终端    | 代码编辑       |

## 🎯 选择指南

### 用 MCP 当...

- ✅ 需要访问**外部系统**（数据库、API、浏览器）
- ✅ 需要**实时数据**（股票、天气、用户信息）
- ✅ 需要**第三方服务**（GitHub、Slack、Jira）
- ✅ 需要**浏览器自动化**（截图、爬虫、测试）

### 不用 MCP 当...

- ❌ 只是代码编辑、文件操作（内置能力足够）
- ❌ 静态知识指导（用 Skills 更轻量）
- ❌ 简单的终端命令（直接执行即可）
