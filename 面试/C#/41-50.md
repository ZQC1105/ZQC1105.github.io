## 41. IEnumerable 与 IQueryable 的区别

| 特性         | IEnumerable             | IQueryable                     |
| ------------ | ----------------------- | ------------------------------ |
| **命名空间** | System.Collections      | System.Linq                    |
| **执行位置** | 客户端内存（内存中）    | 服务器端（数据库）             |
| **执行时机** | 立即执行                | 延迟执行                       |
| **查询方式** | LINQ to Objects         | LINQ to SQL / Entity Framework |
| **过滤位置** | 在 .NET 内存中过滤      | 转换为 SQL 在数据库过滤        |
| **性能**     | 小数据集适合            | 大数据集适合                   |
| **适用场景** | 内存集合（List、Array） | 远程数据源（数据库、API）      |

**示例**：

```csharp
// IEnumerable：在内存中执行
IEnumerable<Product> productsEnumerable = context.Products.ToList();
var result1 = productsEnumerable.Where(p => p.Price > 100);
// 1. 先加载所有产品到内存
// 2. 再在内存中过滤

// IQueryable：在数据库中执行
IQueryable<Product> productsQueryable = context.Products;
var result2 = productsQueryable.Where(p => p.Price > 100);
// 1. 生成 SQL: SELECT * FROM Products WHERE Price > 100
// 2. 只返回过滤后的结果

// 实际差异
IEnumerable<Product> enumerable = context.Products;
IQueryable<Product> queryable = context.Products;

// 在枚举前可以继续添加条件
var query1 = enumerable.Where(p => p.Price > 100);  // 已加载到内存
var query2 = queryable.Where(p => p.Price > 100);   // 未执行，等待翻译

// 性能对比（10万条数据）
// IEnumerable: 加载10万条到内存 → 高内存
// IQueryable: 数据库执行 WHERE → 低内存
```

## 42. LINQ 中的表达式树（Expression Trees）

**表达式树** 将代码表示为**数据结构**，可在运行时分析和转换。

**工作原理**：

```csharp
// 普通委托（编译为 IL）
Func<int, bool> isEven = x => x % 2 == 0;

// 表达式树（保存为数据结构）
Expression<Func<int, bool>> isEvenExpr = x => x % 2 == 0;

// 表达式树的结构
// 参数: x
// 主体: x % 2 == 0
//   └── 相等比较 (Equal)
//       ├── 取模运算 (Modulo)
//       │   ├── 参数: x
//       │   └── 常量: 2
//       └── 常量: 0
```

**手动构建表达式树**：

```csharp
// 构建 (x, y) => x + y
ParameterExpression paramX = Expression.Parameter(typeof(int), "x");
ParameterExpression paramY = Expression.Parameter(typeof(int), "y");
BinaryExpression body = Expression.Add(paramX, paramY);
Expression<Func<int, int, int>> addExpr =
    Expression.Lambda<Func<int, int, int>>(body, paramX, paramY);

Func<int, int, int> addFunc = addExpr.Compile();
Console.WriteLine(addFunc(3, 5));  // 8
```

**遍历和修改表达式树**：

```csharp
// 访问者模式
public class ParameterReplacer : ExpressionVisitor
{
    private readonly ParameterExpression _oldParam;
    private readonly ParameterExpression _newParam;

    public ParameterReplacer(ParameterExpression oldParam, ParameterExpression newParam)
    {
        _oldParam = oldParam;
        _newParam = newParam;
    }

    protected override Expression VisitParameter(ParameterExpression node)
    {
        return node == _oldParam ? _newParam : base.VisitParameter(node);
    }
}

// 使用
Expression<Func<int, bool>> expr = x => x > 5;
var newParam = Expression.Parameter(typeof(int), "y");
var replacer = new ParameterReplacer(expr.Parameters[0], newParam);
var newExpr = (Expression<Func<int, bool>>)replacer.Visit(expr);
```

**实际应用（动态查询）**：

```csharp
// 动态构建 WHERE 条件
public static Expression<Func<T, bool>> BuildPredicate<T>(
    string propertyName, object value, string op = "=")
{
    var parameter = Expression.Parameter(typeof(T), "x");
    var property = Expression.Property(parameter, propertyName);
    var constant = Expression.Constant(value);

    Expression body = op switch
    {
        "=" => Expression.Equal(property, constant),
        ">" => Expression.GreaterThan(property, constant),
        "<" => Expression.LessThan(property, constant),
        _ => throw new NotSupportedException()
    };

    return Expression.Lambda<Func<T, bool>>(body, parameter);
}

// 使用
var predicate = BuildPredicate<Product>("Price", 100, ">");
var products = dbContext.Products.Where(predicate).ToList();
```

## 43. C# 中异常处理如何工作？

**异常处理** 使用 `try-catch-finally` 块，异常对象沿调用栈向上传播。

**基本结构**：

```csharp
try
{
    // 可能抛出异常的代码
    int result = 10 / int.Parse("0");
}
catch (DivideByZeroException ex)
{
    // 特定异常处理
    Console.WriteLine($"除零错误: {ex.Message}");
}
catch (FormatException ex)
{
    // 另一个特定异常
    Console.WriteLine($"格式错误: {ex.Message}");
}
catch (Exception ex)
{
    // 通用异常（最后捕获）
    Console.WriteLine($"未知错误: {ex.Message}");
    throw;  // 重新抛出
}
finally
{
    // 无论是否发生异常都执行
    Console.WriteLine("清理资源");
}
```

**异常过滤器**：

```csharp
try
{
    ProcessData();
}
catch (Exception ex) when (ex.Message.Contains("timeout"))
{
    // 只有当异常消息包含 "timeout" 时才进入
    Console.WriteLine("超时异常");
}
catch (Exception ex) when (LogException(ex))
{
    // 记录后继续向上传播
}

bool LogException(Exception ex)
{
    Console.WriteLine($"记录: {ex.Message}");
    return false;  // 返回 false 表示不捕获
}
```

**自定义异常**：

```csharp
public class BusinessException : Exception
{
    public string ErrorCode { get; }

    public BusinessException(string message, string errorCode)
        : base(message)
    {
        ErrorCode = errorCode;
    }

    public BusinessException(string message, Exception inner)
        : base(message, inner)
    {
    }
}

// 使用
try
{
    throw new BusinessException("库存不足", "STOCK_001");
}
catch (BusinessException ex)
{
    Console.WriteLine($"错误码: {ex.ErrorCode}");
}
```

**异常传播**：

```csharp
void MethodA()
{
    try
    {
        MethodB();
    }
    catch (Exception ex)
    {
        Console.WriteLine("在 MethodA 中捕获");
        throw;  // 重新抛出，保留原始堆栈
    }
}

void MethodB()
{
    MethodC();
}

void MethodC()
{
    throw new InvalidOperationException("错误发生在 MethodC");
}

// 调用 MethodA() 会输出:
// 在 MethodA 中捕获
// 异常堆栈指向 MethodC 原始位置
```

## 44. 重新抛出异常的所有方式

| 方式                    | 代码                                         | 堆栈跟踪     | 推荐          |
| ----------------------- | -------------------------------------------- | ------------ | ------------- |
| `throw`                 | `throw;`                                     | 保留原始堆栈 | ✅ 推荐       |
| `throw ex`              | `throw ex;`                                  | 重置堆栈     | ❌ 避免       |
| `throw new Exception()` | `throw new Exception("msg", ex);`            | 包装原始异常 | ✅ 添加上下文 |
| `ExceptionDispatchInfo` | `ExceptionDispatchInfo.Capture(ex).Throw();` | 保留原始堆栈 | ⚠️ 高级场景   |

**示例**：

```csharp
// 1. throw（推荐）保留原始堆栈
try
{
    DoWork();
}
catch (Exception ex)
{
    // 记录日志
    _logger.LogError(ex, "发生错误");
    throw;  // 堆栈指向 DoWork()
}

// 2. throw ex（不推荐）丢失堆栈信息
try
{
    DoWork();
}
catch (Exception ex)
{
    throw ex;  // 堆栈指向这里，丢失原始位置
}

// 3. 包装异常（添加业务上下文）
try
{
    ProcessOrder(orderId);
}
catch (SqlException ex)
{
    throw new BusinessException($"处理订单 {orderId} 失败", ex);
}

// 4. ExceptionDispatchInfo（保持原始堆栈）
using System.Runtime.ExceptionServices;

ExceptionDispatchInfo? capturedException = null;
try
{
    DangerousOperation();
}
catch (Exception ex)
{
    capturedException = ExceptionDispatchInfo.Capture(ex);
}

// 稍后重新抛出
capturedException?.Throw();  // 保留原始堆栈

// 5. 条件重新抛出
catch (Exception ex) when (ex is TimeoutException)
{
    // 只对 TimeoutException 重新抛出
    throw;
}
```

## 45. 解释泛型（Generics）

**泛型** 允许定义**类型参数**，创建独立于具体类型的类和方法的代码。

**核心优势**：

| 优势         | 说明                 |
| ------------ | -------------------- |
| **类型安全** | 编译时检查类型       |
| **代码复用** | 一套代码支持多种类型 |
| **性能**     | 避免装箱/拆箱        |

**基本用法**：

```csharp
// 泛型类
public class GenericList<T>
{
    private T[] _items = new T[10];
    private int _count = 0;

    public void Add(T item)
    {
        _items[_count++] = item;
    }

    public T Get(int index)
    {
        return _items[index];
    }

    // 泛型方法
    public void ForEach(Action<T> action)
    {
        for (int i = 0; i < _count; i++)
        {
            action(_items[i]);
        }
    }
}

// 使用
var intList = new GenericList<int>();
intList.Add(10);
intList.Add(20);
int value = intList.Get(0);

var stringList = new GenericList<string>();
stringList.Add("Hello");

// 泛型方法
public T GetMax<T>(T a, T b) where T : IComparable<T>
{
    return a.CompareTo(b) > 0 ? a : b;
}

// 泛型约束
public class Repository<T> where T : class, new()  // 引用类型，有默认构造函数
{
    public T Create() => new T();
}

public class ValueStore<T> where T : struct  // 值类型约束
{
    private T _value;
}

// 协变（out）和逆变（in）
// 协变：返回更具体的类型
IEnumerable<string> strings = new List<string>();
IEnumerable<object> objects = strings;  // 协变

// 逆变：接受更宽泛的参数
Action<object> actionObj = obj => Console.WriteLine(obj);
Action<string> actionStr = actionObj;   // 逆变

// 自定义协变接口
public interface IProducer<out T>
{
    T Produce();
}

// 自定义逆变接口
public interface IConsumer<in T>
{
    void Consume(T item);
}
```

## 46. AutoResetEvent 与 ManualResetEvent 的区别

| 特性             | AutoResetEvent        | ManualResetEvent     |
| ---------------- | --------------------- | -------------------- |
| **等待线程释放** | 每次释放**一个**线程  | 释放**所有**等待线程 |
| **自动重置**     | ✅ 释放后自动关闭     | ❌ 需手动 Reset()    |
| **使用场景**     | 生产者-消费者、资源池 | 信号广播、启动通知   |

**AutoResetEvent 示例**：

```csharp
// 自动重置事件（一次释放一个线程）
private static AutoResetEvent _autoEvent = new AutoResetEvent(false);
private static int _sharedResource = 0;

static void Producer()
{
    for (int i = 0; i < 5; i++)
    {
        Thread.Sleep(1000);
        _sharedResource = i;
        Console.WriteLine($"生产: {i}");
        _autoEvent.Set();  // 释放一个等待的消费者
    }
}

static void Consumer(string name)
{
    for (int i = 0; i < 3; i++)
    {
        _autoEvent.WaitOne();  // 等待信号
        Console.WriteLine($"{name} 消费: {_sharedResource}");
    }
}

// 启动
var producer = new Thread(Producer);
var consumer1 = new Thread(() => Consumer("消费者1"));
var consumer2 = new Thread(() => Consumer("消费者2"));
producer.Start();
consumer1.Start();
consumer2.Start();
// 每个 Set() 只释放一个消费者
```

**ManualResetEvent 示例**：

```csharp
// 手动重置事件（释放所有等待线程）
private static ManualResetEvent _manualEvent = new ManualResetEvent(false);

static void Worker(string name)
{
    Console.WriteLine($"{name} 等待开始信号...");
    _manualEvent.WaitOne();  // 等待信号
    Console.WriteLine($"{name} 开始工作");
}

// 启动多个工作线程
for (int i = 0; i < 5; i++)
{
    var thread = new Thread(() => Worker($"线程{i}"));
    thread.Start();
}

Thread.Sleep(2000);
Console.WriteLine("发出开始信号！");
_manualEvent.Set();  // 释放所有等待线程

Thread.Sleep(1000);
_manualEvent.Reset();  // 手动重置，后续的 WaitOne 会再次阻塞

// ManualResetEventSlim（性能更好的版本）
var slimEvent = new ManualResetEventSlim(false);
slimEvent.Set();
slimEvent.Wait();
```

## 47. C# 中的 Channel（通道）

**Channel**（.NET Core 3+）是**线程安全的队列**，用于生产者-消费者模式，支持异步读写。

**类型**：

| 类型               | 说明                           |
| ------------------ | ------------------------------ |
| `UnboundedChannel` | 无界通道，无限容量             |
| `BoundedChannel`   | 有界通道，有限容量（满时阻塞） |

**基本用法**：

```csharp
using System.Threading.Channels;

// 1. 创建通道
var unbounded = Channel.CreateUnbounded<string>();
var bounded = Channel.CreateBounded<string>(new BoundedChannelOptions(10)
{
    FullMode = BoundedChannelFullMode.Wait  // 满时等待
});

// 2. 生产者
async Task Producer(ChannelWriter<string> writer)
{
    for (int i = 0; i < 100; i++)
    {
        await writer.WriteAsync($"Item {i}");
        await Task.Delay(100);
    }
    writer.Complete();  // 标记完成
}

// 3. 消费者
async Task Consumer(ChannelReader<string> reader)
{
    await foreach (var item in reader.ReadAllAsync())
    {
        Console.WriteLine($"消费: {item}");
    }
}

// 4. 使用
var channel = Channel.CreateUnbounded<string>();
var producer = Producer(channel.Writer);
var consumer = Consumer(channel.Reader);
await Task.WhenAll(producer, consumer);
```

**高级用法**：

```csharp
// 多生产者-多消费者
var channel = Channel.CreateBounded<int>(100);

// 多个生产者
var producers = Enumerable.Range(0, 5).Select(async _ =>
{
    for (int i = 0; i < 20; i++)
    {
        await channel.Writer.WriteAsync(i);
    }
});

// 多个消费者
var consumers = Enumerable.Range(0, 3).Select(async _ =>
{
    await foreach (var item in channel.Reader.ReadAllAsync())
    {
        Console.WriteLine($"线程 {Thread.CurrentThread.ManagedThreadId} 消费: {item}");
    }
});

await Task.WhenAll(producers);
channel.Writer.Complete();
await Task.WhenAll(consumers);

// 带取消令牌
using var cts = new CancellationTokenSource(TimeSpan.FromSeconds(5));
try
{
    await channel.Writer.WriteAsync("item", cts.Token);
}
catch (OperationCanceledException)
{
    Console.WriteLine("超时");
}

// 批量读取
var batch = new List<int>();
while (channel.Reader.TryRead(out var item))
{
    batch.Add(item);
    if (batch.Count >= 10) break;
}
```

## 48. volatile 与 Interlocked 的区别

| 特性             | volatile                    | Interlocked                     |
| ---------------- | --------------------------- | ------------------------------- |
| **作用**         | 禁止编译器/CPU 重排序       | 提供原子操作                    |
| **操作类型**     | 单个读写操作                | 复合操作（读-改-写）            |
| **支持字段类型** | 简单类型（int、bool、引用） | 多种类型（int、long、对象引用） |
| **线程同步**     | 仅保证可见性                | 保证原子性和可见性              |

**volatile 示例**：

```csharp
// volatile 确保读取最新值，不保证复合操作原子性
class VolatileExample
{
    private volatile bool _stop = false;
    private volatile int _value = 0;

    public void Worker()
    {
        while (!_stop)  // 每次循环读取最新值
        {
            // 工作
        }
    }

    public void Stop() => _stop = true;

    // ❌ volatile 不保证复合操作
    public void Increment()
    {
        _value++;  // 不是原子操作（读-改-写）
        // 多线程下可能丢失更新
    }
}
```

**Interlocked 示例**：

```csharp
class InterlockedExample
{
    private int _counter = 0;
    private long _total = 0;

    public void Increment()
    {
        // 原子递增
        Interlocked.Increment(ref _counter);

        // 原子添加
        Interlocked.Add(ref _total, 10);

        // 原子交换
        int old = Interlocked.Exchange(ref _counter, 100);

        // 条件交换
        int result = Interlocked.CompareExchange(ref _counter, 50, 100);
    }

    // 实现锁
    private int _locked = 0;

    public bool TryEnter()
    {
        return Interlocked.CompareExchange(ref _locked, 1, 0) == 0;
    }

    public void Exit()
    {
        Interlocked.Exchange(ref _locked, 0);
    }
}

// 两者结合使用
class CombinedExample
{
    private volatile int _flag = 0;  // 可见性
    private int _counter = 0;         // 原子操作

    public void Update()
    {
        if (_flag == 1)  // 读取 volatile
        {
            Interlocked.Increment(ref _counter);  // 原子更新
        }
    }
}
```

## 49. 异步流（Async Streams）的工作原理

**异步流**（C# 8+）允许异步生成和使用数据序列，使用 `IAsyncEnumerable<T>` 和 `await foreach`。

**工作原理**：

```csharp
// 生产者：异步返回多个值
public static async IAsyncEnumerable<int> GenerateNumbersAsync()
{
    for (int i = 0; i < 10; i++)
    {
        await Task.Delay(100);  // 模拟异步操作
        yield return i;         // 异步产生值
    }
}

// 消费者：异步迭代
await foreach (var number in GenerateNumbersAsync())
{
    Console.WriteLine(number);
}

// 带取消令牌
public static async IAsyncEnumerable<int> GenerateWithCancellationAsync(
    [EnumeratorCancellation] CancellationToken cancellationToken = default)
{
    for (int i = 0; i < 10; i++)
    {
        await Task.Delay(100, cancellationToken);
        yield return i;
    }
}

await foreach (var n in GenerateWithCancellationAsync().WithCancellation(cts.Token))
{
    Console.WriteLine(n);
}
```

**数据流处理**：

```csharp
// 分页读取
public async IAsyncEnumerable<Product> GetProductsAsync()
{
    int page = 0;
    int pageSize = 100;

    while (true)
    {
        var batch = await _dbContext.Products
            .Skip(page * pageSize)
            .Take(pageSize)
            .ToArrayAsync();

        if (!batch.Any()) break;

        foreach (var product in batch)
        {
            yield return product;
        }

        page++;
    }
}

// 管道处理
await foreach (var product in GetProductsAsync()
    .Where(p => p.Price > 100)
    .Select(p => p.Name)
    .Take(50))
{
    Console.WriteLine(product);
}

// 异步流转换
public static async IAsyncEnumerable<TResult> SelectAsync<TSource, TResult>(
    this IAsyncEnumerable<TSource> source,
    Func<TSource, Task<TResult>> selector)
{
    await foreach (var item in source)
    {
        yield return await selector(item);
    }
}
```

## 50. Task.Run 与 TaskFactory.StartNew 的区别

| 特性             | Task.Run                | TaskFactory.StartNew       |
| ---------------- | ----------------------- | -------------------------- |
| **默认调度器**   | TaskScheduler.Default   | TaskScheduler.Default      |
| **父任务附加**   | 不支持（默认 Detached） | 可配置（AttachedToParent） |
| **线程局部状态** | 清除（避免状态泄漏）    | 保留                       |
| **异步委托**     | 智能解包                | 返回 Task<Task>            |
| **推荐使用**     | ✅ 首选                 | ⚠️ 高级场景                |

**示例**：

```csharp
// Task.Run（推荐）
Task task1 = Task.Run(() => DoWork());
Task<int> task2 = Task.Run(() => Compute());

// 带异步委托
Task.Run(async () =>
{
    await Task.Delay(1000);
    Console.WriteLine("完成");
});

// TaskFactory.StartNew
TaskFactory factory = Task.Factory;

// 基本用法
Task task3 = factory.StartNew(() => DoWork());

// 附加到父任务
Task parent = Task.Factory.StartNew(() =>
{
    var child = Task.Factory.StartNew(() =>
    {
        Console.WriteLine("子任务");
    }, TaskCreationOptions.AttachedToParent);
});
parent.Wait();  // 等待子任务完成

// 使用 LongRunning 选项
Task task4 = factory.StartNew(() => LongRunningOperation(),
    TaskCreationOptions.LongRunning);

// 异步委托问题（需解包）
Task task5 = factory.StartNew(async () =>
{
    await Task.Delay(1000);
});
// 返回 Task<Task>，需要用 Unwrap()
Task unwrapped = factory.StartNew(async () =>
{
    await Task.Delay(1000);
}).Unwrap();
```

**差异演示**：

```csharp
// 1. 异步委托处理
// Task.Run：自动解包
Task runTask = Task.Run(async () => await Task.Delay(100));  // Task

// StartNew：返回 Task<Task>
Task<Task> startNewTask = Task.Factory.StartNew(async () => await Task.Delay(100));
Task proper = startNewTask.Unwrap();  // 需要解包

// 2. 线程局部状态
[ThreadStatic]
static int ThreadLocal = 0;

// Task.Run：清除状态
Task.Run(() => Console.WriteLine(ThreadLocal));  // 0（新线程）

// StartNew：可能继承状态
Task.Factory.StartNew(() => Console.WriteLine(ThreadLocal));  // 可能继承

// 3. 性能
// Task.Run 是 StartNew 的简化包装
public static Task Run(Action action)
{
    return Task.Factory.StartNew(action,
        CancellationToken.None,
        TaskCreationOptions.DenyChildAttach,
        TaskScheduler.Default);
}
```

**选择建议**：

```csharp
// ✅ 使用 Task.Run
Task.Run(() => Compute());
Task.Run(async () => await DownloadAsync());
```
