## Go语言的方法和函数

在Go语言中，**函数**和**方法**是两个相关但不同的概念。我结合你的Gin服务场景来具体说明：

---

## 一、函数（Function）

### 1. 基本定义

函数是**独立存在的代码块**，不属于任何类型，可以直接调用。

```go
// 函数定义
func 函数名(参数列表) 返回值类型 {
    // 函数体
    return 值
}

// 示例：一个简单的求和函数
func Add(a, b int) int {
    return a + b
}

// 调用函数
result := Add(3, 5)  // result = 8
```

### 2. 在Gin服务中的函数示例

```go
package main

import "github.com/gin-gonic/gin"

// 这是一个普通的函数，用于验证token
func validateToken(token string) bool {
    // 验证逻辑
    return token == "valid-token"
}

// 这也是一个普通函数，用于处理错误
func handleError(c *gin.Context, statusCode int, message string) {
    c.JSON(statusCode, gin.H{
        "error": message,
    })
}

func main() {
    r := gin.Default()

    r.GET("/ping", func(c *gin.Context) {  // 这个匿名函数稍后会讲
        token := c.Query("token")

        // 调用普通函数
        if !validateToken(token) {
            handleError(c, 401, "unauthorized")
            return
        }

        c.JSON(200, gin.H{"message": "pong"})
    })

    r.Run()
}
```

### 3. 函数的特殊形式

#### 匿名函数

```go
// 直接定义并调用
func() {
    fmt.Println("我是匿名函数")
}()

// 赋值给变量
add := func(a, b int) int {
    return a + b
}
result := add(3, 5)

// Gin中常用的匿名函数
r.GET("/ping", func(c *gin.Context) {  // 这个就是匿名函数
    c.JSON(200, gin.H{"message": "pong"})
})
```

#### 闭包

```go
// 函数返回函数
func counter() func() int {
    i := 0
    return func() int {
        i++
        return i
    }
}

// 使用
c := counter()
fmt.Println(c()) // 1
fmt.Println(c()) // 2
```

## 二、方法（Method）

### 1. 基本定义

方法是**绑定到特定类型**的函数，有一个特殊的**接收者（receiver）**参数。

```go
// 方法定义
func (接收者 类型) 方法名(参数列表) 返回值类型 {
    // 方法体
}

// 示例：定义一个User类型
type User struct {
    Name string
    Age  int
}

// 这是User类型的方法
func (u User) SayHello() {
    fmt.Printf("你好，我是 %s，今年 %d 岁\n", u.Name, u.Age)
}

// 这也是User类型的方法（指针接收者，可以修改值）
func (u *User) Birthday() {
    u.Age++
}

// 使用
user := User{Name: "张三", Age: 25}
user.SayHello()  // 调用方法
user.Birthday()  // 年龄变成26
user.SayHello()  // 你好，我是 张三，今年 26 岁
```

### 2. 在Gin服务中的方法示例

```go
package main

import "github.com/gin-gonic/gin"

// 定义一个服务结构体
type UserService struct {
    db     map[string]User
    router *gin.Engine
}

type User struct {
    ID   string `json:"id"`
    Name string `json:"name"`
    Age  int    `json:"age"`
}

// 创建新服务的方法
func NewUserService() *UserService {
    return &UserService{
        db:     make(map[string]User),
        router: gin.Default(),
    }
}

// 获取用户的方法（接收者：UserService）
func (s *UserService) GetUser(c *gin.Context) {
    id := c.Param("id")
    user, exists := s.db[id]
    if !exists {
        c.JSON(404, gin.H{"error": "user not found"})
        return
    }
    c.JSON(200, user)
}

// 创建用户的方法
func (s *UserService) CreateUser(c *gin.Context) {
    var user User
    if err := c.ShouldBindJSON(&user); err != nil {
        c.JSON(400, gin.H{"error": err.Error()})
        return
    }
    s.db[user.ID] = user
    c.JSON(201, user)
}

// 注册路由的方法
func (s *UserService) SetupRoutes() {
    s.router.GET("/users/:id", s.GetUser)      // 这里调用了上面的方法
    s.router.POST("/users", s.CreateUser)       // 这里也调用了上面的方法
}

// 启动服务的方法
func (s *UserService) Run(addr string) error {
    return s.router.Run(addr)
}

func main() {
    // 创建服务实例
    service := NewUserService()

    // 调用方法设置路由
    service.SetupRoutes()

    // 调用方法启动服务
    service.Run(":8080")
}
```

## 三、函数 vs 方法：核心区别

| 特性               | 函数                   | 方法                                 |
| ------------------ | ---------------------- | ------------------------------------ |
| **所属**           | 独立的，不属于任何类型 | 绑定到特定的类型                     |
| **调用方式**       | `函数名(参数)`         | `实例.方法名(参数)`                  |
| **接收者**         | 没有接收者             | 有接收者（`func (r Type) Method()`） |
| **面向对象**       | 过程式编程             | 类似其他语言的类方法                 |
| **能否修改接收者** | 不适用                 | 指针接收者可以修改                   |

## 四、接收者类型详解

### 1. 值接收者 vs 指针接收者

```go
type Counter struct {
    Value int
}

// 值接收者：不能修改原始值
func (c Counter) Add1() {
    c.Value++  // 只修改了副本，不影响原始值
}

// 指针接收者：可以修改原始值
func (c *Counter) Add2() {
    c.Value++  // 修改了原始值
}

// 使用
c := Counter{Value: 0}
c.Add1()
fmt.Println(c.Value) // 0（没变）

c.Add2()
fmt.Println(c.Value) // 1（变了）
```

### 2. Gin服务中的接收者使用场景

```go
type APIServer struct {
    port     string
    router   *gin.Engine
    services map[string]interface{}
}

// 指针接收者：因为要修改router
func (s *APIServer) RegisterRoutes() {
    // 设置路由...
}

// 指针接收者：因为要修改services
func (s *APIServer) RegisterService(name string, service interface{}) {
    s.services[name] = service
}

// 值接收者也可以，因为只读
func (s APIServer) GetPort() string {
    return s.port
}
```

## 五、在实际Gin项目中的组织方式

```go
package main

import "github.com/gin-gonic/gin"

// 1. 定义模型（通常用结构体）
type Product struct {
    ID    string  `json:"id"`
    Name  string  `json:"name"`
    Price float64 `json:"price"`
}

// 模型的方法（业务逻辑）
func (p *Product) ApplyDiscount(percent float64) {
    p.Price = p.Price * (1 - percent/100)
}

// 2. 定义服务（处理业务逻辑）
type ProductService struct {
    products map[string]*Product
}

// 构造函数（普通函数，返回实例）
func NewProductService() *ProductService {
    return &ProductService{
        products: make(map[string]*Product),
    }
}

// 服务的方法
func (s *ProductService) AddProduct(p *Product) {
    s.products[p.ID] = p
}

func (s *ProductService) GetProduct(id string) (*Product, bool) {
    p, exists := s.products[id]
    return p, exists
}

// 3. 定义API处理器（处理HTTP请求）
type ProductHandler struct {
    service *ProductService
}

// 构造函数
func NewProductHandler(service *ProductService) *ProductHandler {
    return &ProductHandler{service: service}
}

// 处理器的方法（Gin的路由处理函数）
func (h *ProductHandler) CreateProduct(c *gin.Context) {
    var product Product
    if err := c.ShouldBindJSON(&product); err != nil {
        c.JSON(400, gin.H{"error": err.Error()})
        return
    }

    // 调用服务的方法
    h.service.AddProduct(&product)

    c.JSON(201, product)
}

func (h *ProductHandler) GetProduct(c *gin.Context) {
    id := c.Param("id")

    // 调用服务的方法
    product, exists := h.service.GetProduct(id)
    if !exists {
        c.JSON(404, gin.H{"error": "product not found"})
        return
    }

    c.JSON(200, product)
}

// 4. 主函数
func main() {
    r := gin.Default()

    // 初始化
    productService := NewProductService()     // 普通函数
    productHandler := NewProductHandler(productService)  // 普通函数

    // 注册路由
    r.POST("/products", productHandler.CreateProduct)  // 调用方法
    r.GET("/products/:id", productHandler.GetProduct)   // 调用方法

    r.Run(":8080")
}
```

## 六、总结

| 概念           | 特点                           | 在Gin中的典型用途            |
| -------------- | ------------------------------ | ---------------------------- |
| **函数**       | 独立、无接收者、功能单一       | 工具函数、验证、辅助逻辑     |
| **方法**       | 绑定到类型、有接收者、操作数据 | 业务逻辑、路由处理、数据操作 |
| **指针接收者** | 可以修改接收者、避免复制       | 修改服务状态、性能优化       |
| **值接收者**   | 只读操作、每次调用复制         | 不修改状态的查询操作         |

**最佳实践建议**：

- 需要修改接收者 → 用指针接收者
- 接收者很大（避免复制）→ 用指针接收者
- 只读操作 → 值接收者和指针接收者都可以
- 保持一致性：同一个类型的方法用同一种接收者
