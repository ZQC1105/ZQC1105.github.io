你的理解基本正确，但需要补充一点细节。在 ASP.NET Core 中，**主要的模型绑定来源**确实是这 4 种，但还有其他几种常用的：

## 1. 四大主要来源

### ① `[FromRoute]` - 路由参数
```csharp
[HttpGet("{id}/{name}")]
public IActionResult Get(
    [FromRoute] int id,           // 从 /users/123/john 获取
    [FromRoute] string name)      // 从路由模板中绑定
{ }
```

### ② `[FromQuery]` - URL 查询字符串
```csharp
[HttpGet("search")]
public IActionResult Search(
    [FromQuery] string keyword,   // ?keyword=abc
    [FromQuery] int page = 1,     // ?page=2
    [FromQuery] string[] tags)    // ?tags=dotnet&tags=csharp
{ }
```

### ③ `[FromBody]` - 请求体
```csharp
[HttpPost]
public IActionResult Create(
    [FromBody] UserDto user)      // JSON/XML 等格式自动反序列化
{ }

// 注意：一个请求只能有一个 [FromBody]（因为请求体只能读取一次）
```

### ④ `[FromForm]` - 表单数据（你说的 IFromFile 其实是这个的扩展）
```csharp
[HttpPost("upload")]
public IActionResult Upload(
    [FromForm] string name,       // 表单字段
    [FromForm] IFormFile file)    // 文件上传
{ }
```

## 2. 其他重要的绑定来源

### ⑤ `[FromHeader]` - 请求头
```csharp
[HttpGet]
public IActionResult Get(
    [FromHeader] string authorization,  // 从 Header 获取
    [FromHeader(Name = "User-Agent")] string userAgent)
{ }
```

### ⑥ `[FromServices]` - DI 容器（不是从 HTTP 请求获取）
```csharp
[HttpGet]
public IActionResult Get(
    [FromServices] ILogger<UsersController> logger,  // 从 DI 获取
    [FromServices] IUserService userService)
{ }
```

### ⑦ 默认绑定规则（无特性的情况）
```csharp
// 复杂类型 → [FromBody]（前提是 [ApiController] 特性）
// 简单类型 → [FromQuery]
// IFormFile 类型 → [FromForm]
// 路由参数 → 自动匹配 [FromRoute]

[HttpPost("{id}")]
public IActionResult Update(
    int id,              // 从路由获取（匹配 {id}）
    UserDto user,        // 从 Body 获取（复杂类型）
    string optional)     // 从 Query 获取（简单类型，未匹配路由）
{ }
```

## 3. 实际应用示例

```csharp
[Route("api/users")]
[ApiController]
public class UsersController : ControllerBase
{
    // 混合绑定示例
    [HttpPost("{id}/avatar")]
    public IActionResult UploadAvatar(
        [FromRoute] int id,                    // 路由: /users/123/avatar
        [FromQuery] bool resize = true,        // 查询: ?resize=true
        [FromForm] IFormFile avatar,           // 表单文件字段
        [FromHeader(Name = "X-Version")] string apiVersion)  // 请求头
    {
        // 业务逻辑
    }
    
    // 文件上传专用
    [HttpPost("upload-multiple")]
    public IActionResult UploadMultiple(
        [FromForm] List<IFormFile> files,      // 多个文件
        [FromForm] string description)         // 额外表单字段
    { }
}
```

## 4. 绑定优先级（当存在冲突时）

```
[FromRoute] > [FromQuery] > [FromBody] > 默认规则
```

## 5. 注意事项

- **`[ApiController]` 特性**会改变默认行为（复杂类型默认从 Body 绑定）
- **`IFormFile`/`IFormFileCollection`** 必须配合 `[FromForm]` 使用
- 一个 Action 中**不能有多个 `[FromBody]`**，但可以有多个其他来源
- **`[FromServices]`** 是特例，不是从 HTTP 请求获取数据

你的总结基本正确，只是 `IFromFile` 应该是 `IFormFile`，并且它属于 `[FromForm]` 绑定源的一种特殊形式。
