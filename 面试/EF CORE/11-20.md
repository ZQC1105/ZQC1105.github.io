## 11. 什么是 EF Core 中的阴影属性（Shadow Properties）？

**阴影属性** 是指在实体类中**没有定义对应的 .NET 属性**，但在 EF Core 模型中存在并映射到数据库列的属性。ChangeTracker 会跟踪这些属性的状态。

**常见用途**：

| 用途                   | 示例                                  |
| ---------------------- | ------------------------------------- |
| 审计字段               | `CreatedAt`、`UpdatedAt`、`CreatedBy` |
| 外键（未在实体中定义） | 当不使用导航属性时                    |
| 并发令牌               | `RowVersion`                          |
| 租户隔离               | `TenantId`                            |

**定义阴影属性**：

```csharp
// Fluent API 配置阴影属性
protected override void OnModelCreating(ModelBuilder modelBuilder)
{
    // 添加阴影属性
    modelBuilder.Entity<Blog>()
        .Property<DateTime>("CreatedAt")
        .HasDefaultValueSql("GETDATE()");

    modelBuilder.Entity<Blog>()
        .Property<string>("LastModifiedBy")
        .HasMaxLength(50);

    modelBuilder.Entity<Post>()
        .Property<byte[]>("RowVersion")
        .IsRowVersion();  // 并发令牌
}

// 使用阴影属性
public class Blog
{
    public int Id { get; set; }
    public string Name { get; set; }
    // 没有 CreatedAt 属性
}

// 读写阴影属性
var blog = context.Blogs.First();

// 读取
var createdAt = context.Entry(blog).Property<DateTime>("CreatedAt").CurrentValue;

// 写入
context.Entry(blog).Property("LastModifiedBy").CurrentValue = "admin";

// 查询中使用
var recentBlogs = context.Blogs
    .Where(b => EF.Property<DateTime>(b, "CreatedAt") > DateTime.Today)
    .ToList();
```

**自动生成的阴影属性（外键）**：

```csharp
public class Blog
{
    public int Id { get; set; }
    public string Name { get; set; }
    public ICollection<Post> Posts { get; set; }
}

public class Post
{
    public int Id { get; set; }
    public string Title { get; set; }
    // 没有 BlogId 属性
    public Blog Blog { get; set; }  // 只有导航属性
}

// EF Core 自动创建阴影属性 "BlogId"
var post = context.Posts.Include(p => p.Blog).First();
var blogId = context.Entry(post).Property<int>("BlogId").CurrentValue;
```

## 12. EF Core 如何处理并发冲突？

**并发冲突** 发生在多个用户同时修改同一数据时。EF Core 通过**并发令牌**检测冲突。

**处理机制**：

```
用户 A                              用户 B
   |                                   |
读取记录 (Version=1)                读取记录 (Version=1)
   |                                   |
修改记录                            修改记录
   |                                   |
保存 (Version=1 → WHERE Version=1)   保存 (Version=1 → WHERE Version=1)
   |                                   |
成功 (Version=2)                    失败 (Version 已变为 2)
```

**配置并发令牌**：

```csharp
// 方式一：数据注解
public class Product
{
    public int Id { get; set; }
    public string Name { get; set; }

    [ConcurrencyCheck]
    public int Stock { get; set; }

    [Timestamp]  // SQL Server 的 rowversion
    public byte[] RowVersion { get; set; }
}

// 方式二：Fluent API
protected override void OnModelCreating(ModelBuilder modelBuilder)
{
    modelBuilder.Entity<Product>()
        .Property(p => p.Stock)
        .IsConcurrencyToken();

    modelBuilder.Entity<Product>()
        .Property(p => p.RowVersion)
        .IsRowVersion();  // 自动处理乐观并发
}
```

**处理并发冲突（乐观并发）**：

```csharp
public async Task UpdateProductAsync(int id, string newName, int newPrice)
{
    using var context = new AppDbContext();

    // 方法一：自动重试（推荐）
    var saved = false;
    while (!saved)
    {
        try
        {
            var product = await context.Products.FindAsync(id);
            product.Name = newName;
            product.Price = newPrice;

            await context.SaveChangesAsync();
            saved = true;
        }
        catch (DbUpdateConcurrencyException ex)
        {
            foreach (var entry in ex.Entries)
            {
                // 获取当前数据库值
                var databaseValues = await entry.GetDatabaseValuesAsync();

                if (databaseValues == null)
                {
                    // 记录已被删除
                    entry.State = EntityState.Detached;
                    throw new Exception("记录已被删除");
                }

                // 获取原始值、当前值、数据库值
                var proposedValues = entry.CurrentValues;
                var originalValues = entry.OriginalValues;

                // 解决冲突：保留当前值
                entry.OriginalValues.SetValues(databaseValues);

                // 或合并值
                // proposedValues["Name"] = databaseValues["Name"]; // 用数据库值覆盖
                // entry.CurrentValues.SetValues(proposedValues);
            }
        }
    }
}
```

**自定义冲突解决策略**：

```csharp
// 客户端获胜（覆盖数据库）
entry.OriginalValues.SetValues(databaseValues);
await context.SaveChangesAsync();

// 数据库获胜（丢弃更改）
entry.CurrentValues.SetValues(databaseValues);
entry.State = EntityState.Unchanged;

// 合并（如增量更新）
var currentStock = proposedValues["Stock"];
var dbStock = databaseValues["Stock"];
entry.CurrentValues["Stock"] = currentStock + dbStock;
await context.SaveChangesAsync();
```

## 13. 如何使用 Fluent API 配置索引？

```csharp
protected override void OnModelCreating(ModelBuilder modelBuilder)
{
    // 1. 简单单列索引
    modelBuilder.Entity<Product>()
        .HasIndex(p => p.Name)
        .HasDatabaseName("IX_Products_Name");

    // 2. 复合索引（多列）
    modelBuilder.Entity<Product>()
        .HasIndex(p => new { p.CategoryId, p.Price })
        .HasDatabaseName("IX_Products_Category_Price");

    // 3. 唯一索引
    modelBuilder.Entity<User>()
        .HasIndex(u => u.Email)
        .IsUnique();

    // 4. 包含列索引（SQL Server）
    modelBuilder.Entity<Order>()
        .HasIndex(o => o.OrderDate)
        .IncludeProperties(o => new { o.Status, o.TotalAmount });

    // 5. 过滤索引（部分索引）
    modelBuilder.Entity<Product>()
        .HasIndex(p => p.IsActive)
        .HasFilter("[IsActive] = 1");

    // 6. 排序索引（EF Core 7+）
    modelBuilder.Entity<Product>()
        .HasIndex(p => p.Name)
        .SortOrder(SortOrder.Descending);

    // 7. 复合索引指定排序方向
    modelBuilder.Entity<Product>()
        .HasIndex(p => new { p.CategoryId, p.Price })
        .SortOrder(
            SortOrder.Ascending,
            SortOrder.Descending);

    // 8. 集群索引（SQL Server）
    modelBuilder.Entity<Order>()
        .HasIndex(o => o.OrderNumber)
        .IsClustered();

    // 9. 检查索引是否存在（幂等迁移）
    modelBuilder.Entity<Product>()
        .HasIndex(p => p.Code)
        .IsUnique()
        .HasDatabaseName("IX_Products_Code")
        .HasAnnotation("SqlServer:Include", "Name,Price");  // 旧语法
}
```

**高级索引配置**：

```csharp
// 条件唯一索引（允许空值重复，但非空值唯一）
modelBuilder.Entity<User>()
    .HasIndex(u => u.ExternalId)
    .IsUnique()
    .HasFilter("[ExternalId] IS NOT NULL");

// 全文索引（需数据库支持）
modelBuilder.Entity<Document>()

```

## 14. EF Core 查询中 FirstOrDefault 和 SingleOrDefault 的区别

| 方法                | 期望结果   | 无结果时          | 多条结果时                    | 查询生成                   |
| ------------------- | ---------- | ----------------- | ----------------------------- | -------------------------- |
| **FirstOrDefault**  | 0 或 1+ 条 | 返回 null/default | 返回**第一条**（带 ORDER BY） | `SELECT TOP 1` / `LIMIT 1` |
| **SingleOrDefault** | 0 或 1 条  | 返回 null/default | **抛出异常**                  | 无限制，获取所有后检查     |

**代码示例**：

```csharp
// FirstOrDefault - 取第一条
var firstProduct = context.Products
    .OrderBy(p => p.Price)
    .FirstOrDefault();  // 最便宜的商品，或 null

// SingleOrDefault - 期望唯一
var productById = context.Products
    .SingleOrDefault(p => p.Id == 123);  // 唯一 ID，安全

// ❌ 错误使用 SingleOrDefault
var productByName = context.Products
    .SingleOrDefault(p => p.CategoryId == 5);
// 如果有多个 CategoryId=5 的商品 → 抛出 InvalidOperationException

// 正确：确保唯一性
var uniqueProduct = context.Products
    .Where(p => p.SerialNumber == "SN-001")
    .SingleOrDefault();  // SerialNumber 应该是唯一的
```

**性能考虑**：

```csharp
// FirstOrDefault - 高效（仅查询 1 行）
var sqlFirst = context.Products
    .OrderBy(p => p.Price)
    .FirstOrDefault();
// SQL: SELECT TOP 1 * FROM Products ORDER BY Price

// SingleOrDefault - 可能低效（查询所有行，客户端检查）
var sqlSingle = context.Products
    .Where(p => p.CategoryId == 5)
    .SingleOrDefault();
// SQL: SELECT * FROM Products WHERE CategoryId = 5
// 然后在内存中检查是否只有一条

// 优化：使用 Take(2) + FirstOrDefault 手动检查
var items = context.Products
    .Where(p => p.CategoryId == 5)
    .Take(2)
    .ToList();

if (items.Count == 0) return null;
if (items.Count > 1) throw new InvalidOperationException("多条结果");
return items[0];
```

**选择指南**：

| 场景               | 推荐方法                      |
| ------------------ | ----------------------------- |
| 按 ID 查询（主键） | `Find` 或 `SingleOrDefault`   |
| 按唯一索引查询     | `SingleOrDefault`             |
| 取最大/最小值      | `FirstOrDefault` + `OrderBy`  |
| 分页取第一页       | `FirstOrDefault`              |
| 验证数据完整性     | `SingleOrDefault`（会抛异常） |

## 15. AsSplitQuery 的作用是什么？

**AsSplitQuery** 将包含多个 `Include` / `ThenInclude` 的查询**拆分为多个 SQL 查询**执行，避免 Cartesian explosion（笛卡尔爆炸）。

**问题演示**：

```csharp
// 实体关系：Blog → Posts → Comments
// 一个 Blog 有 10 个 Post，每个 Post 有 10 个 Comment

// 单个查询（默认）
var blogs = context.Blogs
    .Include(b => b.Posts)
        .ThenInclude(p => p.Comments)
    .ToList();
// SQL: SELECT * FROM Blogs
//      LEFT JOIN Posts ON ...
//      LEFT JOIN Comments ON ...
// 结果行数: 1 × 10 × 10 = 100 行（笛卡尔积）
// 大量重复数据（Blog 和 Post 数据重复 100 次）

// 拆分查询（AsSplitQuery）
var blogs = context.Blogs
    .Include(b => b.Posts)
        .ThenInclude(p => p.Comments)
    .AsSplitQuery()
    .ToList();
// 生成 3 个 SQL:
// 查询 1: SELECT * FROM Blogs
// 查询 2: SELECT * FROM Posts WHERE BlogId IN (1,2,3...)
// 查询 3: SELECT * FROM Comments WHERE PostId IN (1,2,3...)
// 无数据重复，性能更好（尤其是大数据量时）
```

**全局配置拆分查询**：

```csharp
// 全局启用拆分查询
protected override void OnConfiguring(DbContextOptionsBuilder optionsBuilder)
{
    optionsBuilder.UseSqlServer(
        connectionString,
        options => options.UseQuerySplittingBehavior(QuerySplittingBehavior.SplitQuery)
    );
}

// 或按查询覆盖
var blogs = context.Blogs
    .Include(b => b.Posts)
    .AsSingleQuery()  // 强制单个查询
    .ToList();
```

**性能对比**：

| 场景         | 单查询（默认）    | 拆分查询            |
| ------------ | ----------------- | ------------------- |
| 少量数据     | ✅ 快（1 次往返） | ⚠️ 较慢（多次往返） |
| 大量嵌套数据 | ❌ 数据膨胀严重   | ✅ 无重复，内存友好 |
| 网络延迟高   | ✅ 好             | ⚠️ 多次往返开销大   |
| 复杂筛选     | ⚠️ 可能低效       | ✅ 各表独立筛选     |

**最佳实践**：

```csharp
// 推荐：根据具体情况选择
var query = context.Orders
    .Include(o => o.Items)
        .ThenInclude(i => i.Product)
            .ThenInclude(p => p.Category)
    .Include(o => o.Customer)
        .ThenInclude(c => c.Address)
    .AsSplitQuery();  // 深度嵌套时使用

// 分页时注意：拆分查询 + Skip/Take 可能产生不一致结果
var paged = context.Blogs
    .Include(b => b.Posts)
    .OrderBy(b => b.Id)
    .Skip(10).Take(5)
    .AsSplitQuery()  // ⚠️ 可能导致 Posts 不完整
    .ToList();
```

## 16. EF Core 如何将 LINQ 表达式转换为 SQL？

EF Core 使用**表达式树（Expression Tree）** 和**查询管道**将 LINQ 查询转换为 SQL。

**转换流程**：

```
LINQ 查询代码
    ↓
表达式树 (Expression Tree)
    ↓
Query Compilation (查询编译)
    ↓
翻译器 (Translator) - 将表达式节点转换为 SQL 片段
    ↓
SQL 生成器 (SqlGenerator)
    ↓
参数化 SQL 字符串
    ↓
数据库执行
```

**示例转换过程**：

```csharp
// C# 代码
var query = context.Products
    .Where(p => p.Price > 100 && p.CategoryId == 5)
    .OrderBy(p => p.Name)
    .Select(p => new { p.Id, p.Name });

// 表达式树（简化）
// LambdaExpression: p => p.Price > 100 && p.CategoryId == 5
//   ├─ BinaryExpression (AndAlso)
//   │   ├─ BinaryExpression (GreaterThan)
//   │   │   ├─ MemberExpression (p.Price)
//   │   │   └─ ConstantExpression (100)
//   │   └─ BinaryExpression (Equal)
//   │       ├─ MemberExpression (p.CategoryId)
//   │       └─ ConstantExpression (5)
//   └─ ...

// 生成的 SQL
SELECT [p].[Id], [p].[Name]
FROM [Products] AS [p]
WHERE [p].[Price] > 100 AND [p].[CategoryId] = 5
ORDER BY [p].[Name]
```

**支持和不支持的转换**：

```csharp
// ✅ 支持 - 可以转换为 SQL
var query1 = context.Users
    .Where(u => u.CreatedAt > DateTime.Now.AddDays(-7))
    .Select(u => new { u.Name, u.Email });

var query2 = context.Orders
    .GroupBy(o => o.Status)
    .Select(g => new { Status = g.Key, Count = g.Count() });

// ⚠️ 部分支持 - 客户端评估（EF Core 6+ 会警告）
var query3 = context.Users
    .Where(u => Regex.IsMatch(u.Name, "^A.*"))
    .ToList();  // Regex 无法翻译，在客户端执行过滤

// ❌ 不支持 - 必须客户端评估
var localList = new List<int> { 1, 2, 3 };
var query4 = context.Orders
    .Where(o => localList.Contains(o.Id))
    .ToList();  // 可以（Contains 被翻译为 IN）

var query5 = context.Users
    .Select(u => new { Name = u.Name.ToUpper() })  // 支持
    .AsEnumerable()  // 切换到客户端
    .Select(u => new { Name = u.Name.Substring(0, 1) });  // 客户端执行
```

**客户端评估警告**：

```csharp
// 配置客户端评估行为
protected override void OnConfiguring(DbContextOptionsBuilder optionsBuilder)
{
    optionsBuilder
        .UseSqlServer(connectionString)
        .ConfigureWarnings(warnings =>
            warnings.Throw(RelationalEventId.QueryClientEvaluationWarning));
}
```

## 17. 什么是全局查询过滤器？何时使用？

**全局查询过滤器** 是在 `OnModelCreating` 中定义的自动应用于所有查询的 `WHERE` 条件，用于**行级安全**或**软删除**。

**主要用途**：

| 场景         | 示例                          |
| ------------ | ----------------------------- |
| 软删除       | `IsDeleted == false`          |
| 多租户       | `TenantId == currentTenantId` |
| 数据隔离     | `OrganizationId == userOrgId` |
| 有效数据过滤 | `Status != "Archived"`        |

**实现示例**：

```csharp
public class AppDbContext : DbContext
{
    private readonly int _currentTenantId;
    private readonly string _currentUserId;

    public AppDbContext(DbContextOptions options, IHttpContextAccessor httpContextAccessor)
        : base(options)
    {
        // 从当前请求获取租户信息
        _currentTenantId = int.Parse(httpContextAccessor.HttpContext?.User?.FindFirst("TenantId")?.Value ?? "0");
        _currentUserId = httpContextAccessor.HttpContext?.User?.FindFirst(ClaimTypes.NameIdentifier)?.Value;
    }

    protected override void OnModelCreating(ModelBuilder modelBuilder)
    {
        // 1. 软删除过滤器
        modelBuilder.Entity<Post>()
            .HasQueryFilter(p => !p.IsDeleted);

        // 2. 多租户过滤器
        modelBuilder.Entity<Product>()
            .HasQueryFilter(p => p.TenantId == _currentTenantId);

        // 3. 组合过滤器
        modelBuilder.Entity<Order>()
            .HasQueryFilter(o => !o.IsDeleted && o.TenantId == _currentTenantId);

        // 4. 带忽略条件的过滤器（EF Core 6+）
        modelBuilder.Entity<User>()
            .HasQueryFilter(u => !u.IsDeleted || EF.Property<bool>(u, "IsSystemAccount"));

        // 5. 使用参数化过滤器
        modelBuilder.Entity<Document>()
            .HasQueryFilter(d => d.CreatedBy == _currentUserId || d.IsPublic);
    }
}

public class Post
{
    public int Id { get; set; }
    public string Title { get; set; }
    public bool IsDeleted { get; set; } = false;
    public int TenantId { get; set; }
}
```

**绕过全局过滤器**：

```csharp
// 需要查询已删除的数据时
var deletedPosts = context.Posts
    .IgnoreQueryFilters()
    .Where(p => p.IsDeleted)
    .ToList();

// 跨租户查询（管理员功能）
var allProducts = context.Products
    .IgnoreQueryFilters()
    .ToList();
```

**禁用特定实体过滤器**：

```csharp
protected override void OnModelCreating(ModelBuilder modelBuilder)
{
    modelBuilder.Entity<Product>()
        .HasQueryFilter(p => p.TenantId == _currentTenantId);

    // 对特定查询禁用（上面已展示 IgnoreQueryFilters）
}
```

## 18. SaveChanges 和 SaveChangesAsync 的区别

| 特性          | SaveChanges       | SaveChangesAsync          |
| ------------- | ----------------- | ------------------------- |
| **执行方式**  | 同步阻塞          | 异步非阻塞                |
| **返回值**    | `int`（影响行数） | `Task<int>`               |
| **异常处理**  | 同步抛出          | 异步抛出（可 await）      |
| **UI 响应性** | ❌ 阻塞 UI 线程   | ✅ 不阻塞                 |
| **可取消**    | ❌ 不支持         | ✅ 支持 CancellationToken |
| **性能**      | 不释放线程        | 释放线程处理其他请求      |

**代码示例**：

```csharp
// 同步（不推荐用于 Web 应用）
[HttpPost("sync")]
public IActionResult CreateSync(Product product)
{
    context.Products.Add(product);
    int rows = context.SaveChanges();  // 阻塞线程
    return Ok(rows);
}

// 异步（推荐）
[HttpPost("async")]
public async Task<IActionResult> CreateAsync(Product product)
{
    context.Products.Add(product);
    int rows = await context.SaveChangesAsync();  // 释放线程
    return Ok(rows);
}

// 带取消令牌
[HttpPost("with-cancellation")]
public async Task<IActionResult> CreateWithCancellationAsync(
    Product product,
    CancellationToken cancellationToken)
{
    context.Products.Add(product);
    int rows = await context.SaveChangesAsync(cancellationToken);
    return Ok(rows);
}
```

**性能影响**：

```csharp
// 高并发场景测试（1000 并发请求）
// 同步 SaveChanges：所有线程阻塞，等待数据库响应
// 线程池耗尽 → 请求排队 → 响应变慢

// 异步 SaveChangesAsync：数据库 I/O 期间线程被释放
// 线程可处理其他请求 → 吞吐量更高
```

**何时使用同步**：

```csharp
// ✅ 控制台应用程序（简单场景）
static void Main()
{
    using var context = new AppDbContext();
    context.SaveChanges();  // 可以接受
}

// ✅ 单元测试
[Test]
public void TestSave()
{
    var context = new InMemoryDbContext();
    context.SaveChanges();  // 同步简单
}

// ❌ Web API（避免使用）
[HttpGet("bad")]
public IActionResult Bad() => Ok(context.SaveChanges());  // 阻塞
```

## 19. EF Core 如何处理实体中的枚举属性？

EF Core 默认将枚举存储为**枚举的底层整数值**，但可以配置为存储**字符串**。

**默认方式（整数值）**：

```csharp
public enum OrderStatus
{
    Pending = 0,
    Processing = 1,
    Shipped = 2,
    Delivered = 3,
    Cancelled = 4
}

public class Order
{
    public int Id { get; set; }
    public OrderStatus Status { get; set; }  // 存储为 int
}

// 数据库存储：Status 列类型为 int，值为 0,1,2,3,4
```

**配置为字符串存储**：

```csharp
// 方式一：Fluent API（推荐）
protected override void OnModelCreating(ModelBuilder modelBuilder)
{
    modelBuilder.Entity<Order>()
        .Property(o => o.Status)
        .HasConversion<string>();

    // 或指定最大长度
    modelBuilder.Entity<Order>()
        .Property(o => o.Status)
        .HasConversion<string>()
        .HasMaxLength(20);
}

// 方式二：值转换器（更灵活）
protected override void OnModelCreating(ModelBuilder modelBuilder)
{
    modelBuilder.Entity<Order>()
        .Property(o => o.Status)
        .HasConversion(
            v => v.ToString(),           // 写入数据库
            v => (OrderStatus)Enum.Parse(typeof(OrderStatus), v)  // 读取
        );
}

// 方式三：数据注解（EF Core 2.1+）
public class Order
{
    public int Id { get; set; }

    [Column(TypeName = "nvarchar(20)")]
    public OrderStatus Status { get; set; }
}
```

**枚举集合的处理**：

```csharp
public enum Tag
{
    Tech, Sports, News, Entertainment
}

public class Article
{
    public int Id { get; set; }
    public List<Tag> Tags { get; set; }  // 枚举集合
}

// 方式一：存储为逗号分隔字符串
modelBuilder.Entity<Article>()
    .Property(a => a.Tags)
    .HasConversion(
        v => string.Join(',', v),
        v => v.Split(',', StringSplitOptions.RemoveEmptyEntries)
              .Select(s => Enum.Parse<Tag>(s)).ToList()
    );

// 方式二：存储为 JSON（EF Core 7+）
modelBuilder.Entity<Article>()
    .OwnsOne(a => a.Tags, owned =>
    {
        owned.ToJson();
    });
```

**查询中的枚举使用**：

```csharp
// 整数值存储
var pendingOrders = context.Orders
    .Where(o => o.Status == OrderStatus.Pending)
    .ToList();
// SQL: WHERE [Status] = 0

// 字符串存储
var shippedOrders = context.Orders
    .Where(o => o.Status == OrderStatus.Shipped)
    .ToList();
// SQL: WHERE [Status] = N'Shipped'
```

## 20. 什么是 EF Core 中的拥有类型（Owned Types）？

**拥有类型** 是作为**值对象**的实体，没有独立的身份标识（ID），完全从属于所有者实体，映射到同一张表或单独的表。

**核心特点**：

| 特性       | 常规实体         | 拥有类型                 |
| ---------- | ---------------- | ------------------------ |
| 身份标识   | 有独立主键       | 无独立主键，依赖所有者   |
| 生命周期   | 独立             | 与所有者相同             |
| 独立查询   | 可以             | 不可以                   |
| 共享性     | 可被多个实体引用 | 只能属于一个所有者       |
| 数据库映射 | 单独的表         | 同一张表（默认）或单独表 |

**基本用法**：

```csharp
// 定义拥有类型（值对象）
[Owned]
public class Address
{
    public string Street { get; set; }
    public string City { get; set; }
    public string PostalCode { get; set; }
    public string Country { get; set; }
}

// 所有者实体
public class Customer
{
    public int Id { get; set; }
    public string Name { get; set; }
    public Address HomeAddress { get; set; }      // 拥有类型
    public Address BillingAddress { get; set; }   // 可以有多个
}

// 数据库映射（单表）
// Customers 表包含列：
// Id, Name,
// HomeAddress_Street, HomeAddress_City, HomeAddress_PostalCode, HomeAddress_Country,
// BillingAddress_Street, BillingAddress_City, BillingAddress_PostalCode, BillingAddress_Country
```

**配置为单独表（EF Core 6+）**：

```csharp
modelBuilder.Entity<Customer>(entity =>
{
    // 将拥有类型存储到单独的表
    entity.OwnsOne(c => c.HomeAddress, address =>
    {
        address.ToTable("CustomerAddresses");
        address.WithOwner().HasForeignKey("CustomerId");
    });
});
```

**嵌套拥有类型**：

```csharp
[Owned]
public class Address
{
    public string Street { get; set; }
    public City City { get; set; }  // 嵌套拥有类型
}

[Owned]
public class City
{
    public string Name { get; set; }
    public string State { get; set; }
}

// 生成的列：
// Address_Street, Address_City_Name, Address_City_State
```

**集合拥有类型**：

```csharp
public class Order
{
    public int Id { get; set; }
    public ICollection<OrderLine> Lines { get; set; }  // 拥有类型的集合
}

[Owned]
public class OrderLine
{
    public string ProductName { get; set; }
    public int Quantity { get; set; }
    public decimal Price { get; set; }
}

// EF Core 7+ 自动创建单独的表 OrderLines
// 包含 OrderId 外键
```

**查询拥有类型**：

```csharp
// 可以通过点号访问
var customersInTokyo = context.Customers
    .Where(c => c.HomeAddress.City == "Tokyo")
    .ToList();

// 选择特定属性
var addresses = context.Customers
    .Select(c => new { c.Name, Street = c.HomeAddress.Street })
    .ToList();
```
