## ✅ **是的，完全正确！就是通过结构体名称映射到表名！**

XORM 通过 **结构体名称** 和 **命名映射规则** 来确定对应的数据库表名。

## 📋 **表名映射规则**

### **1. 默认规则：结构体名 → 表名**

```go
// 定义模型
type Issue struct { ... }     // 默认表名: issue
type PullRequest struct { ... } // 默认表名: pull_request
type User struct { ... }       // 默认表名: user
type RepoManager struct { ... } // 默认表名: repo_manager
```

**转换规则**（使用 SnakeMapper）：

- `Issue` → `issue`（驼峰转蛇形，全小写）
- `PullRequest` → `pull_request`
- `RepoManager` → `repo_manager`

### **2. 自定义表名**

可以通过实现 `TableName()` 方法来指定表名：

```go
// 方式1：实现 TableName 方法
type Issue struct {
    ID   int64
    Title string
}

func (Issue) TableName() string {
    return "gitea_issue"  // 自定义表名
}

// 方式2：使用标签（某些版本支持）
type Issue struct {
    ID   int64  `xorm:"'gitea_issue.id'"`
    Title string
}

// 方式3：通过引擎映射
engine.Table("gitea_issue").Insert(issue)
```

当您调用 `e.Insert(issue)` 时，XORM 内部会：

```go
// XORM 内部简化流程
func (engine *Engine) Insert(bean interface{}) (int64, error) {
    // 1. 通过反射获取结构体类型
    t := reflect.TypeOf(bean)

    // 2. 检查是否实现了 TableName 方法
    if tableName, ok := bean.(TableNameProvider); ok {
        table = tableName.TableName()  // 使用自定义表名
    } else {
        // 3. 否则通过命名规则转换
        table = engine.mapper.Obj2Table(t.Name())
        // Issue → issue, PullRequest → pull_request
    }

    // 4. 生成 SQL
    sql := fmt.Sprintf("INSERT INTO %s (...) VALUES (...)", table)

    // 5. 执行
    return engine.Exec(sql)
}
```

## 📊 **完整的映射流程**

```go
e.Insert(opts.Issue)
    ↓
[反射] 获取结构体类型 = Issue
    ↓
[接口检查] 实现了 TableName()? → 调用 TableName()
    ↓否
[命名映射] Obj2Table("Issue") = "issue" (SnakeMapper)
    ↓
[字段映射] 遍历所有字段，通过 xorm 标签获取列名
    ↓
[生成SQL] INSERT INTO issue (id, repo_id, index, title, ...) VALUES (?, ?, ?, ?, ...)
    ↓
[执行] 发送到数据库
```

## 🔧 **XORM 的表名映射配置**

```go
// 初始化时设置命名映射器
engine, _ := xorm.NewEngine("mysql", "dsn")

// 设置不同的命名规则
engine.SetMapper(xorm.SnakeMapper{})      // Issue → issue（默认）
engine.SetMapper(xorm.GonicMapper{})      // Issue → issue
engine.SetMapper(xorm.SameMapper{})       // Issue → Issue（保持相同）

// 设置表名前缀
engine.SetTableMapper(xorm.NewPrefixMapper(xorm.SnakeMapper{}, "gitea_"))
// Issue → gitea_issue
```

## 🎯 **总结**

**是的，XORM 通过结构体名称来确定表名：**

1. 默认将结构体名 `Issue` 转换为小写蛇形 `issue`
2. 可以通过 `TableName()` 方法自定义
3. 可以通过引擎设置修改命名规则
4. 最终生成的 SQL 语句中会使用确定的表名

这就是 `e.Insert(issue)` 知道该往哪个表插入数据的原理！
