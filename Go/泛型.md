## Go 泛型 vs C# 泛型 完整对比

### 一、基本语法对比

| 特性         | Go                             | C#                            |
| ------------ | ------------------------------ | ----------------------------- |
| **语法位置** | 函数名后：`func F[T any](t T)` | 类/方法名后：`void F<T>(T t)` |
| **类型参数** | 方括号 `[]`                    | 尖括号 `<>`                   |
| **约束**     | `interface` 或 `~` 近似类型    | `where` 关键字                |

```go
// Go 泛型
func Map[T any, R any](items []T, fn func(T) R) []R {
    result := make([]R, len(items))
    for i, item := range items {
        result[i] = fn(item)
    }
    return result
}

// 使用
numbers := []int{1, 2, 3}
strings := Map(numbers, func(n int) string {
    return strconv.Itoa(n)
})
```

```csharp
// C# 泛型
public IEnumerable<R> Map<T, R>(IEnumerable<T> items, Func<T, R> fn) {
    foreach (var item in items) {
        yield return fn(item);
    }
}

// 使用
var numbers = new[] { 1, 2, 3 };
var strings = Map(numbers, n => n.ToString());
```

### 二、约束能力对比

#### Go 的约束（基于接口）

```go
// 1. 接口约束
type Stringer interface {
    String() string
}

func Print[T Stringer](t T) {
    fmt.Println(t.String())
}

// 2. 近似类型约束 (~)
type MyInt int
type Number interface {
    ~int | ~int64 | ~float64  // 接受近似类型
}

func Sum[T Number](nums []T) T {
    var sum T
    for _, n := range nums {
        sum += n
    }
    return sum
}
// 可以接受 int, int64, float64, 以及 MyInt

// 3. 组合约束
type Comparable interface {
    ~int | ~string | ~float64
    comparable  // 内置约束
}

// 4. 内置约束
func Find[T comparable](items []T, target T) int {
    for i, v := range items {
        if v == target {  // comparable 允许使用 ==
            return i
        }
    }
    return -1
}
```

#### C# 的约束

```csharp
// 1. 基类约束
public void Process<T>(T obj) where T : MyBaseClass

// 2. 接口约束
public void Print<T>(T obj) where T : IStringer

// 3. 构造函数约束
public T Create<T>() where T : new()

// 4. 值类型/引用类型约束
public void ValueMethod<T>(T val) where T : struct
public void RefMethod<T>(T val) where T : class

// 5. 多重约束
public void Method<T>(T obj) where T : class, IMyInterface, new()
```

### 三、核心功能对比表

| 功能              | Go          | C#          | 说明                            |
| ----------------- | ----------- | ----------- | ------------------------------- |
| **泛型类/结构体** | ✅ 支持     | ✅ 支持     | Go: `type Stack[T any] struct`  |
| **泛型方法**      | ✅ 支持     | ✅ 支持     | 两者都支持                      |
| **泛型接口**      | ✅ 支持     | ✅ 支持     | Go 1.18+ 支持                   |
| **类型推断**      | ✅ 支持     | ✅ 支持     | Go: `Map(arr, fn)` 无需指定类型 |
| **约束中的运算**  | ❌ 不支持   | ✅ 支持     | C# 可做 `t1 + t2` 等运算        |
| **协变/逆变**     | ❌ 不支持   | ✅ 支持     | `out T` / `in T` 关键字         |
| **特化**          | ❌ 不支持   | ❌ 不支持   | 两者都不支持模板特化            |
| **运行时类型**    | ✅ 有       | ⚠️ 擦除     | Go 泛型在运行时保留类型信息     |
| **性能**          | ✅ 编译生成 | ✅ 编译生成 | 都是编译时生成具体代码          |

### 四、实际应用对比

#### 1. 泛型集合

```go
// Go
type Stack[T any] struct {
    items []T
}

func (s *Stack[T]) Push(item T) {
    s.items = append(s.items, item)
}

func (s *Stack[T]) Pop() (T, error) {
    if len(s.items) == 0 {
        var zero T
        return zero, errors.New("empty")
    }
    item := s.items[len(s.items)-1]
    s.items = s.items[:len(s.items)-1]
    return item, nil
}
```

```csharp
// C#
public class Stack<T>
{
    private List<T> items = new();

    public void Push(T item) => items.Add(item);

    public T Pop()
    {
        if (items.Count == 0)
            throw new InvalidOperationException("empty");
        var item = items[^1];
        items.RemoveAt(items.Count - 1);
        return item;
    }
}
```

#### 2. 泛型缓存/单例

```go
// Go - 每个类型独立
var instances = sync.Map{}

func GetInstance[T any]() *T {
    key := reflect.TypeOf((*T)(nil)).Elem()

    if val, ok := instances.Load(key); ok {
        return val.(*T)
    }

    instance := new(T)
    instances.Store(key, instance)
    return instance
}
```

```csharp
// C# - 每个封闭类型独立
public static class Singleton<T> where T : new()
{
    private static readonly Lazy<T> _instance =
        new(() => new T());

    public static T Instance => _instance.Value;
}
```

### 五、Go 泛型的特点总结

#### ✅ **优点**

1. **简单直接** - 语法简洁，学习曲线平缓
2. **编译时生成** - 无运行时性能损失
3. **类型保留** - 反射可获取泛型类型信息
4. **接口组合** - 利用接口实现灵活约束
5. **近似类型** - `~int` 支持自定义类型

#### ❌ **局限性**

1. **不能做算术运算** - `a + b` 需要反射或类型断言
2. **没有协变/逆变** - `List[any]` 不能接收 `List[string]`
3. **方法不能额外泛型** - 方法泛型参数必须和类型一致
4. **没有通配符** - 不支持 `?` 类似 C# 的 `IEnumerable<?>`
5. **性能开销** - 比手写具体类型略慢（但比反射快）

### 六、选型建议

**选 Go 泛型当：**

- 需要容器类（栈、队列、映射）
- 需要通用算法（排序、过滤、映射）
- 避免代码重复（多个类型相同逻辑）
- 类型安全比运行时灵活更重要

**不选 Go 泛型当：**

- 需要复杂的算术运算
- 需要协变/逆变场景
- 代码非常简单，泛型反而复杂
- 性能极致优化（手写具体类型更快）

### 七、实用示例：泛型函数库

```go
// 通用的 Filter 函数
func Filter[T any](items []T, predicate func(T) bool) []T {
    result := make([]T, 0)
    for _, item := range items {
        if predicate(item) {
            result = append(result, item)
        }
    }
    return result
}

// 通用的 Reduce 函数
func Reduce[T, R any](items []T, init R, fn func(R, T) R) R {
    result := init
    for _, item := range items {
        result = fn(result, item)
    }
    return result
}

// 通用的 Contains 函数
func Contains[T comparable](items []T, target T) bool {
    for _, item := range items {
        if item == target {
            return true
        }
    }
    return false
}
```

Go 的泛型设计理念是 **"足够用，但不复杂"**，它在类型安全和简洁性之间取得了很好的平衡！
