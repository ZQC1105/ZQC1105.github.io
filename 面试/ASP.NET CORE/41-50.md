## 41. Swagger 的作用是什么？

**Swagger**（现在也称为 **OpenAPI**）是一个用于描述、生成、消费和可视化 RESTful API 的工具集。

**主要作用**：

| 功能                 | 说明                                                            |
| -------------------- | --------------------------------------------------------------- |
| **API 文档自动生成** | 根据代码自动生成 API 文档，无需手动维护                         |
| **交互式测试界面**   | Swagger UI 提供可直接调用 API 的测试页面                        |
| **客户端 SDK 生成**  | 根据 OpenAPI 规范自动生成 TypeScript、Java、Python 等客户端代码 |
| **API 契约定义**     | 统一的服务描述格式，方便前后端协作                              |
| **一致性检查**       | 确保文档与实际实现一致                                          |

**ASP.NET Core 集成**：

```csharp
// 安装: dotnet add package Swashbuckle.AspNetCore

builder.Services.AddEndpointsApiExplorer();
builder.Services.AddSwaggerGen(options =>
{
    options.SwaggerDoc("v1", new OpenApiInfo
    {
        Title = "My API",
        Version = "v1",
        Description = "API 描述",
        Contact = new OpenApiContact { Name = "Support", Email = "support@example.com" }
    });
});

var app = builder.Build();

if (app.Environment.IsDevelopment())
{
    app.UseSwagger();
    app.UseSwaggerUI();
}
```


## 46. IHostApplicationLifetime 事件有哪些？如何附加回调？

**IHostApplicationLifetime** 提供三个事件，用于响应应用程序的生命周期变化：

| 事件                    | 触发时机               | 用途                           |
| ----------------------- | ---------------------- | ------------------------------ |
| **ApplicationStarted**  | 应用程序**完全启动后** | 执行启动后任务（如预热缓存）   |
| **ApplicationStopping** | 应用程序**正在停止时** | 优雅关闭前的清理（阻止新请求） |
| **ApplicationStopped**  | 应用程序**完全停止后** | 最终清理（释放资源、关闭连接） |

**使用示例**：

```csharp
public class StartupTasksService : IHostedService
{
    private readonly IHostApplicationLifetime _lifetime;
    private readonly ILogger<StartupTasksService> _logger;

    public StartupTasksService(IHostApplicationLifetime lifetime, ILogger<StartupTasksService> logger)
    {
        _lifetime = lifetime;
        _logger = logger;
    }

    public Task StartAsync(CancellationToken cancellationToken)
    {
        _lifetime.ApplicationStarted.Register(() =>
        {
            _logger.LogInformation("应用程序已启动，执行预热任务...");
            // 加载缓存、建立连接池等
            WarmupCache();
        });

        _lifetime.ApplicationStopping.Register(() =>
        {
            _logger.LogInformation("应用程序正在停止，拒绝新请求...");
            // 通知负载均衡器移除此节点
        });

        _lifetime.ApplicationStopped.Register(() =>
        {
            _logger.LogInformation("应用程序已停止，清理资源...");
            // 关闭数据库连接、释放文件句柄
            CleanupResources();
        });

        return Task.CompletedTask;
    }

    public Task StopAsync(CancellationToken cancellationToken)
    {
        return Task.CompletedTask;
    }
}

// 注册
builder.Services.AddHostedService<StartupTasksService>();
```

**直接在 Program.cs 中使用**：

```csharp
var app = builder.Build();

var lifetime = app.Services.GetRequiredService<IHostApplicationLifetime>();

lifetime.ApplicationStarted.Register(() =>
{
    Console.WriteLine("应用启动完成");
});

lifetime.ApplicationStopping.Register(() =>
{
    Console.WriteLine("应用正在停止...");
    // 执行同步清理（注意不要阻塞太久）
});

lifetime.ApplicationStopped.Register(() =>
{
    Console.WriteLine("应用已停止");
});

app.Run();
```

**优雅关闭示例**：

## 47. 如何停止 BackgroundService 的执行？

**方法一：通过 CancellationToken（推荐）**

```csharp
public class MyBackgroundService : BackgroundService
{
    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        while (!stoppingToken.IsCancellationRequested)
        {
            try
            {
                await DoWorkAsync(stoppingToken);
                await Task.Delay(TimeSpan.FromSeconds(5), stoppingToken);
            }
            catch (OperationCanceledException)
            {
                // 正常取消
                break;
            }
        }

        // 清理代码
        await CleanupAsync();
    }
}

// 外部停止（应用关闭时自动触发）
// 或手动停止（通过 IHostApplicationLifetime）
public class AdminController : ControllerBase
{
    private readonly IHostApplicationLifetime _lifetime;

    [HttpPost("stop-background")]
    public IActionResult StopBackground()
    {
        _lifetime.StopApplication();  // 停止整个应用（包括所有 BackgroundService）
        return Ok("正在停止...");
    }
}
```

**方法二：使用 CancellationTokenSource 手动控制**

```csharp
public class ManagedBackgroundService : BackgroundService
{
    private readonly CancellationTokenSource _manualCts = new();

    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        // 合并两个取消源：应用停止 + 手动停止
        using var combinedCts = CancellationTokenSource.CreateLinkedTokenSource(
            stoppingToken, _manualCts.Token);

        while (!combinedCts.Token.IsCancellationRequested)
        {
            await DoWorkAsync(combinedCts.Token);
        }
    }

    public Task StopAsync()
    {
        _manualCts.Cancel();
        return Task.CompletedTask;
    }
}

// 使用
var bgService = app.Services.GetRequiredService<ManagedBackgroundService>();
await bgService.StopAsync();
```

**方法三：使用 IHostedService 接口直接控制**

```csharp
public class ControllableService : IHostedService
{
    private CancellationTokenSource _cts;
    private Task _executingTask;

    public Task StartAsync(CancellationToken cancellationToken)
    {
        _cts = CancellationTokenSource.CreateLinkedTokenSource(cancellationToken);
        _executingTask = ExecuteAsync(_cts.Token);
        return Task.CompletedTask;
    }

    public async Task StopAsync(CancellationToken cancellationToken)
    {
        _cts?.Cancel();
        if (_executingTask != null)
        {
            await _executingTask.WaitAsync(cancellationToken);
        }
    }

    public async Task ManualStopAsync()
    {
        _cts?.Cancel();
        if (_executingTask != null)
        {
            await _executingTask;
        }
    }

    private async Task ExecuteAsync(CancellationToken token)
    {
        while (!token.IsCancellationRequested)
        {
            // 工作逻辑
        }
    }
}
```

## 48. Controller Action 中可使用的默认返回类型有哪些？

| 返回类型                   | 说明                     | 示例                               |
| -------------------------- | ------------------------ | ---------------------------------- |
| **IActionResult**          | 接口类型，可返回各种结果 | `return Ok()`、`return NotFound()` |
| **ActionResult\<T\>**      | 泛型版本，明确返回类型   | `ActionResult<Product>`            |
| **T**（具体类型）          | 直接返回对象，自动序列化 | `Product`、`List<Product>`         |
| **HttpResponseMessage**    | 用于 Web API 兼容性      | 返回完整的 HTTP 响应               |
| **IResult**（Minimal API） | Minimal API 的结果类型   | `Results.Ok()`                     |
| **Task\<T\>**              | 异步版本的上述所有类型   | `async Task<ActionResult>`         |

**详细示例**：

```csharp
[ApiController]
[Route("api/[controller]")]
public class DemoController : ControllerBase
{
    // 1. IActionResult - 最灵活
    [HttpGet("action-result")]
    public IActionResult GetActionResult()
    {
        if (!ModelState.IsValid)
            return BadRequest(ModelState);

        var product = new Product { Id = 1, Name = "Test" };
        return Ok(product);
    }

    // 2. ActionResult<T> - 推荐，明确返回类型
    [HttpGet("{id}")]
    public ActionResult<Product> GetProduct(int id)
    {
        var product = _service.GetProduct(id);
        if (product == null)
            return NotFound();

        return product;
    }

    // 3. 具体类型 - 最简洁，但无法返回错误状态码
    [HttpGet("simple")]
    public Product GetSimple()
    {
        return new Product { Id = 1, Name = "Test" };
    }

    // 4. 异步返回
    [HttpGet("async")]
    public async Task<ActionResult<List<Product>>> GetProductsAsync()
    {
        var products = await _service.GetProductsAsync();
        return Ok(products);
    }

    // 5. 各种状态码
    [HttpPost]
    public IActionResult Create(Product product)
    {
        // 201 Created
        return CreatedAtAction(nameof(GetProduct), new { id = product.Id }, product);
    }

    [HttpDelete("{id}")]
    public IActionResult Delete(int id)
    {
        if (!_service.Exists(id))
            return NotFound();

        _service.Delete(id);
        return NoContent();  // 204
    }
}
```

## 49. 什么是模型绑定？它在 ASP.NET Core Controller 中如何工作？

**模型绑定** 是将 HTTP 请求数据（查询字符串、表单数据、路由数据、请求体）自动映射到 **Controller Action 参数**或 **模型属性** 的过程。

**工作流程**：

```
HTTP 请求 → 模型绑定器 → 解析数据 → 验证 → 绑定到参数/模型
```

**数据源优先级**（默认顺序）：

1. **Form** 数据（application/x-www-form-urlencoded）
2. **Route** 数据（URL 路径参数）
3. **Query** 字符串
4. **Body**（JSON/XML，需用 [FromBody] 指定）

**示例**：

```csharp
// 请求: POST /api/products/5?version=2
// Content-Type: application/json
// Body: {"name": "Laptop", "price": 999}

[HttpPost("{id}")]
public IActionResult Update(
    [FromRoute] int id,           // 从 URL: 5
    [FromQuery] int version,      // 从 QueryString: 2
    [FromBody] Product product)   // 从 JSON 请求体
{
    // product.Name = "Laptop", product.Price = 999
    return Ok();
}

// 复杂类型自动绑定（属性匹配）
public class SearchModel
{
    public string Keyword { get; set; }    // 匹配 ?keyword=...
    public int Page { get; set; } = 1;     // 默认值
    public string[] Categories { get; set; } // ?categories=books&categories=movies
}

[HttpGet("search")]
public IActionResult Search([FromQuery] SearchModel model)
{
    // model.Keyword, model.Page, model.Categories
    return Ok();
}
```

**自定义绑定**：

```csharp
// 绑定到复杂头信息
public class UserAgentInfo
{
    public string Browser { get; set; }
    public string OS { get; set; }
}

public class CustomHeaderBinder : IModelBinder
{
    public Task BindModelAsync(ModelBindingContext context)
    {
        var userAgent = context.HttpContext.Request.Headers["User-Agent"].ToString();
        // 解析 User-Agent...
        context.Result = ModelBindingResult.Success(userAgentInfo);
        return Task.CompletedTask;
    }
}

// 使用
public IActionResult Get([ModelBinder(BinderType = typeof(CustomHeaderBinder))] UserAgentInfo info)
```

## 50. 解释 [FromBody]、[FromQuery]、[FromRoute] 和 [FromForm] 的区别

| 特性             | [FromRoute]          | [FromQuery]          | [FromForm]                                                   | [FromBody]                            |
| ---------------- | -------------------- | -------------------- | ------------------------------------------------------------ | ------------------------------------- |
| **数据来源**     | URL 路径模板         | URL 查询字符串       | 表单数据（multipart/form-data）                              | 请求体（JSON/XML）                    |
| **数据位置**     | `/api/users/5` → `5` | `?page=2&size=10`    | HTML 表单 POST                                               | POST/PUT 的 Body                      |
| **Content-Type** | 不适用               | 不适用               | `application/x-www-form-urlencoded` 或 `multipart/form-data` | `application/json`、`application/xml` |
| **复杂对象**     | ❌ 仅简单类型        | ✅ 支持              | ✅ 支持（扁平化）                                            | ✅ 支持                               |
| **文件上传**     | ❌                   | ❌                   | ✅（配合 IFormFile）                                         | ❌                                    |
| **默认使用**     | 参数名匹配路由模板   | 默认用于简单类型参数 | 默认用于 [HttpPost] 表单                                     | 复杂类型参数需要显式指定              |

**示例对比**：

```csharp
// 请求 URL: POST /api/products/100?includeDetails=true
// 请求头: Content-Type: application/json
// 请求体: {"name": "Laptop", "price": 999}
// 表单: (如果有) category=Electronics

[HttpPost("{id}")]
public IActionResult Create(
    [FromRoute] int id,                    // 100 (来自 URL /100)
    [FromQuery] bool includeDetails,       // true (来自 ?includeDetails=true)
    [FromBody] Product product,            // { name: "Laptop", price: 999 }
    [FromForm] string category)            // "Electronics" (来自表单)
{
    // ...
}
```

**默认绑定规则**：

```csharp
// 简单类型（int, string, bool, DateTime 等）→ [FromQuery]
public IActionResult Get(int id, string name)  // ?id=1&name=test

// 复杂类型（自定义类）→ [FromBody]（需要 [ApiController]）
public IActionResult Create(Product product)   // 从 JSON Body 读取

// 但如果参数名匹配路由模板 → [FromRoute]
[HttpGet("{id}")]
public IActionResult Get(int id)  // 从 URL 路径读取，不是 Query
```

**常见错误与最佳实践**：

```csharp
// ❌ 错误：不能有多个 [FromBody]
public IActionResult Bad([FromBody] Product p, [FromBody] Order o)  // 异常

// ✅ 正确：包装成一个模型
public class CreateOrderRequest
{
    public Product Product { get; set; }
    public Order Order { get; set; }
}
public IActionResult Good([FromBody] CreateOrderRequest request)

// 文件上传使用 [FromForm]
[HttpPost("upload")]
public IActionResult Upload([FromForm] IFormFile file, [FromForm] string description)
```
