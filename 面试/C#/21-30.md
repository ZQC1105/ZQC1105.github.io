## 21. 创建新线程的所有方式

| 方式               | 说明         | 适用场景              |
| ------------------ | ------------ | --------------------- |
| `Thread`           | 手动管理线程 | 需要精细控制          |
| `Task` (TPL)       | 基于线程池   | 推荐，现代首选        |
| `ThreadPool`       | 从线程池获取 | 大量短小任务          |
| `BackgroundWorker` | 带进度报告   | WinForms 简单后台任务 |
| `Parallel`         | 并行循环     | 数据并行              |
| `async/await`      | 异步编程     | I/O 密集型            |
| `ValueTask`        | 减少分配     | 高频异步              |
| `Thread.Start`     | 启动新线程   | 传统方式              |

**示例**：

```csharp
// 1. Thread 类
Thread thread = new Thread(() =>
{
    Console.WriteLine("Thread 执行");
});
thread.Start();
thread.Join();  // 等待完成

// 带参数
Thread threadWithParam = new Thread((obj) =>
{
    int value = (int)obj;
    Console.WriteLine(value);
});
threadWithParam.Start(42);

// 2. Task（推荐）
Task task = Task.Run(() =>
{
    Console.WriteLine("Task 执行");
});
await task;

// 带返回值
Task<int> taskWithResult = Task.Run(() => 42);
int result = await taskWithResult;

// 3. ThreadPool
ThreadPool.QueueUserWorkItem(state =>
{
    Console.WriteLine("ThreadPool 执行");
});

// 4. BackgroundWorker（WinForms/WPF）
BackgroundWorker worker = new BackgroundWorker();
worker.DoWork += (s, e) => { /* 工作 */ };
worker.RunWorkerCompleted += (s, e) => { /* 完成 */ };
worker.RunWorkerAsync();

// 5. Parallel
Parallel.For(0, 10, i => Console.WriteLine(i));
Parallel.ForEach(new[] { 1, 2, 3 }, item => Process(item));

// 6. async/await（不是创建线程，而是释放线程）
public async Task ProcessAsync()
{
    await Task.Delay(1000);  // 不阻塞线程
}

// 7. ValueTask（减少分配）
public async ValueTask<int> GetValueAsync()
{
    return 42;
}
```

## 22. 如何同时执行多个异步任务？

**方法一：`Task.WhenAll`（等待全部完成）**

```csharp
// 启动多个任务
var task1 = DownloadAsync("url1");
var task2 = DownloadAsync("url2");
var task3 = DownloadAsync("url3");

// 等待全部完成
await Task.WhenAll(task1, task2, task3);

// 获取结果
var results = await Task.WhenAll(task1, task2, task3);

// 或者一行
var results = await Task.WhenAll(
    DownloadAsync("url1"),
    DownloadAsync("url2"),
    DownloadAsync("url3")
);
```

**方法二：`Task.WhenAny`（等待第一个完成）**

```csharp
var tasks = new List<Task<string>> { task1, task2, task3 };

while (tasks.Any())
{
    var completed = await Task.WhenAny(tasks);
    var result = await completed;
    Console.WriteLine($"完成: {result}");
    tasks.Remove(completed);  // 移除已完成的
}
```

**方法三：限制并发数**

```csharp
// 使用 SemaphoreSlim
private static async Task ProcessWithConcurrencyLimit(List<string> urls, int maxConcurrency)
{
    var semaphore = new SemaphoreSlim(maxConcurrency);
    var tasks = new List<Task>();

    foreach (var url in urls)
    {
        await semaphore.WaitAsync();
        tasks.Add(Task.Run(async () =>
        {
            try
            {
                await DownloadAsync(url);
            }
            finally
            {
                semaphore.Release();
            }
        }));
    }

    await Task.WhenAll(tasks);
}

// 使用 Parallel.ForEachAsync (.NET 6+)
await Parallel.ForEachAsync(urls, new ParallelOptions { MaxDegreeOfParallelism = 5 },
    async (url, token) =>
{
    await DownloadAsync(url);
});
```

**方法四：批量处理**

```csharp
public static async Task<List<T>> WhenAllBatched<T>(IEnumerable<Task<T>> tasks, int batchSize)
{
    var results = new List<T>();
    var batches = tasks.Chunk(batchSize);

    foreach (var batch in batches)
    {
        results.AddRange(await Task.WhenAll(batch));
    }

    return results;
}
```

## 23. 继承（Inheritance）vs 组合（Composition）

| 特性           | 继承             | 组合              |
| -------------- | ---------------- | ----------------- |
| **关系**       | "is-a"（是一个） | "has-a"（有一个） |
| **耦合度**     | 高（紧耦合）     | 低（松耦合）      |
| **代码复用**   | 通过派生         | 通过委托          |
| **运行时行为** | 静态绑定         | 动态绑定          |
| **灵活性**     | 低               | 高                |
| **测试**       | 难（需测试基类） | 易（可 Mock）     |

**继承示例**：

```csharp
// 基类
public class Animal
{
    public virtual void MakeSound() => Console.WriteLine("Some sound");
}

public class Dog : Animal  // Dog is-a Animal
{
    public override void MakeSound() => Console.WriteLine("Bark");
}

// 问题：深层次继承难以维护
public class Car : Vehicle { }
public class SportsCar : Car { }
public class ElectricSportsCar : SportsCar { }  // 类爆炸
```

**组合示例**：

```csharp
// 能力接口
public interface IFlyBehavior
{
    void Fly();
}

public interface IQuackBehavior
{
    void Quack();
}

// 可插拔的行为
public class FlyWithWings : IFlyBehavior
{
    public void Fly() => Console.WriteLine("Flying with wings");
}

public class FlyNoWay : IFlyBehavior
{
    public void Fly() => Console.WriteLine("Cannot fly");
}

// 使用组合
public class Duck
{
    private readonly IFlyBehavior _flyBehavior;
    private readonly IQuackBehavior _quackBehavior;

    public Duck(IFlyBehavior flyBehavior, IQuackBehavior quackBehavior)
    {
        _flyBehavior = flyBehavior;
        _quackBehavior = quackBehavior;
    }

    public void Fly() => _flyBehavior.Fly();
    public void Quack() => _quackBehavior.Quack();
}

// 运行时改变行为
var duck = new Duck(new FlyWithWings(), new LoudQuack());
duck.Fly();  // Flying with wings

// 组合优于继承的原则
```

## 24. class vs record vs struct 的区别

| 特性       | class    | record                                            | struct     |
| ---------- | -------- | ------------------------------------------------- | ---------- |
| **类型**   | 引用类型 | 引用类型（record class）或值类型（record struct） | 值类型     |
| **继承**   | 支持     | 支持（record class）                              | 不支持     |
| **可变性** | 可变     | 不可变（推荐）                                    | 可变       |
| **相等性** | 引用相等 | 值相等（按成员）                                  | 值相等     |
| **性能**   | 堆分配   | 堆/栈取决于类型                                   | 栈分配     |
| **用途**   | 通用对象 | 数据传输对象（DTO）、不可变数据                   | 轻量级数据 |

**示例**：

```csharp
// class：引用类型，可变
public class PersonClass
{
    public string Name { get; set; }
    public int Age { get; set; }
}

var p1 = new PersonClass { Name = "Alice", Age = 25 };
var p2 = p1;
p2.Name = "Bob";
Console.WriteLine(p1.Name);  // Bob（引用相同）

// record：引用类型，不可变，值相等
public record PersonRecord(string Name, int Age);

var r1 = new PersonRecord("Alice", 25);
var r2 = new PersonRecord("Alice", 25);
Console.WriteLine(r1 == r2);  // True（值相等）

// with 表达式创建副本
var r3 = r1 with { Age = 26 };

// struct：值类型
public struct Point
{
    public int X { get; set; }
    public int Y { get; set; }
}

var point1 = new Point { X = 1, Y = 2 };
var point2 = point1;
point2.X = 3;
Console.WriteLine(point1.X);  // 1（独立副本）

// record struct（C# 10+）
public record struct PointRecord(int X, int Y);
```

## 25. `ref struct` 的用途

**`ref struct`** 是**只能存在于栈上**的结构体，不能装箱、不能作为类字段、不能用于异步。

**用途**：

- 高性能场景（Span、ReadOnlySpan）
- 避免堆分配
- 临时数据缓冲区

**限制**：

```csharp
// ref struct 的限制
ref struct TempBuffer
{
    public Span<byte> Data { get; set; }

    // ❌ 不能实现接口
    // ❌ 不能是类字段
    // ❌ 不能装箱（object box = buffer;）
    // ❌ 不能用于异步方法
    // ❌ 不能是数组元素
}

// 正确使用
public void ProcessData()
{
    Span<byte> buffer = stackalloc byte[1024];  // ref struct
    var temp = new TempBuffer { Data = buffer };

    // 使用 buffer
}

// Span<T> 和 ReadOnlySpan<T> 是 ref struct 的典型例子
public static void UseSpan()
{
    Span<int> numbers = stackalloc int[10];  // 栈分配
    ReadOnlySpan<char> text = "Hello".AsSpan();
}
```

## 26. record 的两种形式

**形式一：record class（引用类型）**

```csharp
// 位置记录（Positional Record）
public record Person(string Name, int Age);

// 使用
var p1 = new Person("Alice", 25);
var (name, age) = p1;  // 解构

// 传统记录
public record Product
{
    public string Name { get; init; }
    public decimal Price { get; init; }

    public string GetDescription() => $"{Name}: {Price:C}";
}
```

**形式二：record struct（值类型，C# 10+）**

```csharp
// 位置记录结构
public record struct Point(int X, int Y);

// 可变记录结构
public record struct Vector
{
    public double X { get; set; }
    public double Y { get; set; }

    public Vector(double x, double y) => (X, Y) = (x, y);
}

// 使用
var p1 = new Point(10, 20);
var p2 = p1 with { X = 30 };  // 创建副本
```

**区别**：

```csharp
// record class - 引用语义
var rc1 = new RecordClass("A", 1);
var rc2 = rc1;
rc2.Name = "B";  // ❌ 不可变，需用 with

// record struct - 值语义
var rs1 = new RecordStruct("A", 1);
var rs2 = rs1;  // 复制
```

## 27. `with` 关键字的用途

`with` 表达式创建现有记录的**副本**并修改指定属性。

**示例**：

```csharp
// 基本用法
public record Person(string FirstName, string LastName, int Age);

var alice = new Person("Alice", "Smith", 25);
var aliceOlder = alice with { Age = 26 };  // 新实例，Age 改变

Console.WriteLine(alice.Age);        // 25
Console.WriteLine(aliceOlder.Age);   // 26

// 嵌套记录
public record Address(string Street, string City);
public record Employee(string Name, Address HomeAddress);

var emp1 = new Employee("Bob", new Address("Main St", "NYC"));
var emp2 = emp1 with { Name = "Robert" };
var emp3 = emp1 with { HomeAddress = emp1.HomeAddress with { City = "LA" } };

// 传统类模拟（需要手动实现）
public class PersonClass
{
    public string Name { get; set; }
    public int Age { get; set; }

    public PersonClass With(Func<PersonClass, PersonClass> transform)
        => transform(this);
}

var p = new PersonClass { Name = "Alice", Age = 25 };
var p2 = p.With(x => { x.Age = 26; return x; });
```

## 28. 主构造函数（Primary Constructor）的用途

**主构造函数**（C# 12+）在类/结构声明中直接定义参数，简化代码。

**用途**：

```csharp
// 传统方式
public class TraditionalService
{
    private readonly ILogger _logger;
    private readonly IRepository _repository;

    public TraditionalService(ILogger logger, IRepository repository)
    {
        _logger = logger;
        _repository = repository;
    }
}

// 主构造函数（C# 12）
public class ModernService(ILogger logger, IRepository repository)
{
    // 可直接使用 logger 和 repository
    public async Task ProcessAsync()
    {
        logger.LogInformation("Processing");
        await repository.SaveAsync();
    }
}

// 记录中使用
public record Product(string Name, decimal Price)
{
    public string GetInfo() => $"{Name}: {Price:C}";
}

// 结构体中使用
public struct Point(int x, int y)
{
    public int X => x;
    public int Y => y;
}

// 需要显式存储参数
public class Service(ILogger logger, IRepository repository)
{
    private readonly ILogger _logger = logger ?? throw new ArgumentNullException(nameof(logger));
    private readonly IRepository _repository = repository;
}
```

## 29. 可空引用类型（Nullable Reference Types）的工作原理

**可空引用类型**（C# 8+）通过编译器警告帮助避免 `NullReferenceException`。

**启用方式**：

```xml
<!-- .csproj -->
<PropertyGroup>
  <Nullable>enable</Nullable>
</PropertyGroup>
```

**工作原理**：

```csharp
#nullable enable

// 不可空引用类型（必须非空）
string name = "Alice";
// name = null;  // 警告：不能赋 null

// 可空引用类型（可能为 null）
string? nullableName = null;
if (nullableName != null)
{
    int length = nullableName.Length;  // 安全，编译器知道非空
}

// 强制解引用（使用 ! 告诉编译器你知道是安全的）
string definitelyNotNull = nullableName!;  // 空包容运算符

// 泛型处理
public class Repository<T> where T : class
{
    public T? Find(int id) => default;  // 可能返回 null
    public T Get(int id) => Find(id) ?? throw new Exception();  // 必须非空
}

#nullable restore  // 恢复默认
```

**数据库模型示例**：

```csharp
public class User
{
    public int Id { get; set; }
    public string Name { get; set; } = null!;  // 非空，但 EF Core 赋值
    public string? Email { get; set; }         // 可为空
}
```

## 30. switch 表达式有返回类型限制吗？

**没有硬性限制**，但所有分支必须返回**相同类型**或**可隐式转换的类型**。

**示例**：

```csharp
// 相同类型
int result = value switch
{
    1 => 10,
    2 => 20,
    _ => 0
};

// 可隐式转换
double result2 = value switch
{
    1 => 10,        // int → double
    2 => 20.5,      // double
    _ => 0.0
};

// 对象类型
object result3 = value switch
{
    1 => "One",     // string
    2 => 2,         // int
    _ => new { Name = "Unknown" }  // anonymous
};

// 抛出异常（特殊处理）
string GetStatus(int code) => code switch
{
    200 => "OK",
    404 => "Not Found",
    _ => throw new NotSupportedException($"Code {code} not supported")
};

// 返回 Task
Task<int> GetTask(bool flag) => flag switch
{
    true => Task.FromResult(1),
    false => Task.FromResult(0)
};

// ❌ 错误：类型不一致
// var bad = value switch
// {
//     1 => "string",    // string
//     2 => 42,          // int - 编译错误
//     _ => null
// };
```
