### 问题6：Tell me about a challenging bug you fixed.

**English Answer:**

> Once, the CAD-to-ERP integration system started failing randomly. Some BOM data would upload correctly, but others would get corrupted. After two days of debugging, I found the issue was in the AutoCAD .NET API — it wasn't thread-safe when processing multiple drawings simultaneously. I refactored the code to process drawings sequentially and added proper error handling. The system has been stable ever since. This taught me to always check thread safety when working with third-party APIs.

**中文要点：**
- 问题：CAD→ERP系统随机失败，部分数据损坏
- 根因：AutoCAD .NET API非线程安全
- 解决：改为串行处理 + 完善错误处理
- 教训：第三方API要检查线程安全性
