# SQL Server 函数详解

## [函数](https://learn.microsoft.com/zh-cn/sql/t-sql/functions/functions?view=sql-server-ver17#string-functions)

## [窗口函数](https://learn.microsoft.com/zh-cn/sql/t-sql/queries/select-over-clause-transact-sql?view=sql-server-ver17)

SQL Server 中的函数主要分为**标量函数**、**聚合函数**和**窗口函数**三大类。

---

## 📊 对比总览

| 特性          | 标量函数                | 聚合函数                 | 窗口函数         |
| ------------- | ----------------------- | ------------------------ | ---------------- |
| **返回结果**  | 单值（每行）            | 单值（每组）             | 多值（每行）     |
| **行数变化**  | 不变                    | 折叠                     | 不变             |
| **使用位置**  | SELECT、WHERE、ORDER BY | SELECT、HAVING           | SELECT、ORDER BY |
| **分组方式**  | 不分组                  | GROUP BY                 | PARTITION BY     |
| **NULL 处理** | 可能返回 NULL           | 通常忽略（除 COUNT(\*)） | 取决于函数       |
| **执行顺序**  | WHERE 之后              | GROUP BY 之后            | SELECT 阶段      |

---

## 1. 标量函数 (Scalar Functions)

### 特点

- 对单个值进行操作，返回单个值
- 在 SELECT、WHERE、ORDER BY 等子句中使用
- 每行独立计算

### 常见标量函数示例

```sql
-- 字符串函数
SELECT UPPER(name), LEN(description) FROM products;

-- 数学函数
SELECT ABS(-10), ROUND(price, 2), CEILING(3.14);

-- 日期函数
SELECT GETDATE(), YEAR(order_date), DATEADD(day, 7, order_date);

-- 类型转换
SELECT CAST(price AS DECIMAL(10,2)), CONVERT(VARCHAR, order_date, 112);
```

---

## 2. 聚合函数 (Aggregate Functions)

### 特点

- 对多行数据进行计算，返回单个汇总值
- 通常与 GROUP BY 一起使用
- 忽略 NULL 值（除非使用 COUNT(\*)）

### 常见聚合函数示例

```sql
-- 基本聚合
SELECT
    COUNT(*) AS total_orders,
    SUM(amount) AS total_amount,
    AVG(amount) AS avg_amount,
    MIN(order_date) AS first_order,
    MAX(order_date) AS last_order
FROM orders;

-- 分组聚合
SELECT
    customer_id,
    COUNT(*) AS order_count,
    SUM(amount) AS total_spent
FROM orders
GROUP BY customer_id;
```

---

## 3. 窗口函数 (Window Functions)

### 特点

- 在结果集的窗口（分区）上执行计算
- 保持原有行数，不折叠结果
- 需要 OVER() 子句定义窗口

### 分类和示例

#### 排名函数

```sql
SELECT
    customer_id,
    order_date,
    amount,
    ROW_NUMBER() OVER (ORDER BY amount DESC) AS row_num,
    RANK() OVER (ORDER BY amount DESC) AS rank,
    DENSE_RANK() OVER (ORDER BY amount DESC) AS dense_rank
FROM orders;
```

#### 聚合窗口函数

```sql
SELECT
    customer_id,
    order_date,
    amount,
    SUM(amount) OVER (PARTITION BY customer_id) AS customer_total,
    AVG(amount) OVER (PARTITION BY customer_id) AS customer_avg,
    SUM(amount) OVER (ORDER BY order_date
                      ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW) AS running_total
FROM orders;
```

#### 偏移函数

```sql
SELECT
    customer_id,
    order_date,
    amount,
    LAG(amount, 1) OVER (PARTITION BY customer_id ORDER BY order_date) AS prev_amount,
    LEAD(amount, 1) OVER (PARTITION BY customer_id ORDER BY order_date) AS next_amount,
    FIRST_VALUE(amount) OVER (PARTITION BY customer_id ORDER BY order_date) AS first_amount
FROM orders;
```

---

## 🎯 实际应用示例

```sql
-- 综合使用三种函数
SELECT
    customer_id,
    order_date,
    FORMAT(order_date, 'yyyy-MM') AS order_month,  -- 标量函数
    amount,
    -- 窗口函数
    SUM(amount) OVER (PARTITION BY customer_id) AS customer_lifetime_value,
    ROW_NUMBER() OVER (PARTITION BY customer_id ORDER BY order_date) AS order_sequence,
    -- 聚合函数（通过子查询）
    (SELECT AVG(amount) FROM orders WHERE customer_id = o.customer_id) AS customer_avg
FROM orders o
WHERE YEAR(order_date) = 2023  -- 标量函数在WHERE中
ORDER BY customer_id, order_date;
```

---

## ⚡ 性能考虑

1. **标量函数**：在 WHERE 子句中大量使用可能影响性能
2. **聚合函数**：GROUP BY 可能涉及排序和哈希操作
3. **窗口函数**：需要适当的索引支持 PARTITION BY 和 ORDER BY

---

## 📝 选择建议

- **使用标量函数**：转换或计算单个值
- **使用聚合函数**：进行分组汇总统计
- **使用窗口函数**：进行排名、累积计算、前后值比较等分析操作

> **提示**：窗口函数是 SQL Server 2005 及以后版本引入的强大功能，特别适合复杂的数据分析场景。

---

## 🔗 相关说明

- 所有函数都可以嵌套使用，但要注意性能影响
- 自定义函数（用户定义函数）也属于这些类别
- 理解函数的执行顺序有助于编写高效的查询语句

# SQL Server 窗口函数示例与测试结果

## 📋 测试数据准备

```sql
-- 创建测试表和数据
CREATE TABLE orders (
    order_id INT PRIMARY KEY,

    order_date DATE,

INSERT INTO orders VALUES
(1, 101, '2023-01-15', 500.00),
(2, 102, '2023-01-16', 300.00),
(3, 101, '2023-01-17', 500.00),
(4, 103, '2023-01-18', 800.00),
(5, 102, '2023-01-19', 300.00),
(6, 104, '2023-01-20', 200.00),
(7, 103, '2023-01-21', 100.00),
```

## 🥇 1. 排名函数示例结果

### 执行查询

```sql
SELECT
    customer_id,
    order_date,
    amount,
    ROW_NUMBER() OVER (ORDER BY amount DESC) AS row_num,
    RANK() OVER (ORDER BY amount DESC) AS rank,
    DENSE_RANK() OVER (ORDER BY amount DESC) AS dense_rank
FROM orders;
```

### 返回结果

| customer_id | order_date | amount | row_num | rank | dense_rank |
| ----------- | ---------- | ------ | ------- | ---- | ---------- |
| 103         | 2023-01-18 | 800.00 | 1       | 1    | 1          |
| 101         | 2023-01-22 | 600.00 | 2       | 2    | 2          |
| 101         | 2023-01-15 | 500.00 | 3       | 3    | 3          |
| 101         | 2023-01-17 | 500.00 | 4       | 3    | 3          |
| 102         | 2023-01-16 | 300.00 | 5       | 5    | 4          |
| 102         | 2023-01-19 | 300.00 | 6       | 5    | 4          |
| 104         | 2023-01-20 | 200.00 | 7       | 7    | 5          |
| 103         | 2023-01-21 | 100.00 | 8       | 8    | 6          |

### 📝 解释说明

| 函数             | 特点               | 示例说明                                               |
| ---------------- | ------------------ | ------------------------------------------------------ |
| **ROW_NUMBER()** | 唯一连续编号       | 即使金额相同也分配不同编号（500 元分别是 3 和 4）      |
| **RANK()**       | 有并列时跳过序号   | 两个 500 元并列第 3，下一个 300 元直接是第 5（跳过 4） |
| **DENSE_RANK()** | 有并列时不跳过序号 | 两个 500 元并列第 3，下一个 300 元是第 4（不跳过）     |

## 📈 2. 聚合窗口函数示例结果

### 执行查询

```sql
SELECT
    customer_id,
    order_date,
    amount,
    SUM(amount) OVER (PARTITION BY customer_id) AS customer_total,
    AVG(amount) OVER (PARTITION BY customer_id) AS customer_avg,
    SUM(amount) OVER (ORDER BY order_date
                      ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW) AS running_total
FROM orders;
```

### 返回结果

| customer_id | order_date | amount | customer_total | customer_avg | running_total |
| ----------- | ---------- | ------ | -------------- | ------------ | ------------- |
| 101         | 2023-01-15 | 500.00 | 1600.00        | 533.33       | 500.00        |
| 102         | 2023-01-16 | 300.00 | 600.00         | 300.00       | 800.00        |
| 101         | 2023-01-17 | 500.00 | 1600.00        | 533.33       | 1300.00       |
| 103         | 2023-01-18 | 800.00 | 900.00         | 450.00       | 2100.00       |
| 102         | 2023-01-19 | 300.00 | 600.00         | 300.00       | 2400.00       |
| 104         | 2023-01-20 | 200.00 | 200.00         | 200.00       | 2600.00       |
| 103         | 2023-01-21 | 100.00 | 900.00         | 450.00       | 2700.00       |
| 101         | 2023-01-22 | 600.00 | 1600.00        | 533.33       | 3300.00       |

### 📝 解释说明

| 函数               | 计算逻辑             | 结果分析                                                     |
| ------------------ | -------------------- | ------------------------------------------------------------ |
| **customer_total** | 按客户分区的总金额   | customer 101: 500+500+600=1600<br>customer 102: 300+300=600  |
| **customer_avg**   | 按客户分区的平均金额 | customer 101: 1600/3≈533.33<br>customer 103: (800+100)/2=450 |
| **running_total**  | 按日期排序的累计总额 | 随时间累积：500→800→1300→...→3300                            |

## 🔄 3. 偏移函数示例结果

### 执行查询

```sql
SELECT
    customer_id,
    order_date,
    amount,
    LAG(amount, 1) OVER (PARTITION BY customer_id ORDER BY order_date) AS prev_amount,
    LEAD(amount, 1) OVER (PARTITION BY customer_id ORDER BY order_date) AS next_amount,
    FIRST_VALUE(amount) OVER (PARTITION BY customer_id ORDER BY order_date) AS first_amount
FROM orders;
```

### 返回结果

| customer_id | order_date | amount | prev_amount | next_amount | first_amount |
| ----------- | ---------- | ------ | ----------- | ----------- | ------------ |
| 101         | 2023-01-15 | 500.00 | NULL        | 500.00      | 500.00       |
| 101         | 2023-01-17 | 500.00 | 500.00      | 600.00      | 500.00       |
| 101         | 2023-01-22 | 600.00 | 500.00      | NULL        | 500.00       |
| 102         | 2023-01-16 | 300.00 | NULL        | 300.00      | 300.00       |
| 102         | 2023-01-19 | 300.00 | 300.00      | NULL        | 300.00       |
| 103         | 2023-01-18 | 800.00 | NULL        | 100.00      | 800.00       |
| 103         | 2023-01-21 | 100.00 | 800.00      | NULL        | 800.00       |
| 104         | 2023-01-20 | 200.00 | NULL        | NULL        | 200.00       |

### 📝 解释说明

| 函数                    | 作用                         | 示例分析                                                            |
| ----------------------- | ---------------------------- | ------------------------------------------------------------------- |
| **LAG(amount, 1)**      | 获取同一客户上一笔订单的金额 | · 第一笔订单：没有前一笔 → **NULL**<br>· 后续订单：显示前一笔金额   |
| **LEAD(amount, 1)**     | 获取同一客户下一笔订单的金额 | · 最后一笔订单：没有下一笔 → **NULL**<br>· 前序订单：显示下一笔金额 |
| **FIRST_VALUE(amount)** | 获取同一客户第一笔订单的金额 | · 每个客户分区都返回该客户的第一笔订单金额                          |

---

## 🎯 关键点总结

### 📊 窗口函数核心特性

1. **不改变行数**：所有示例都返回 8 行（原始数据行数）
2. **分区概念**：`PARTITION BY` 将数据分组但不折叠
3. **排序影响**：`ORDER BY` 在窗口函数中决定计算顺序
4. **NULL 值处理**：LAG/LEAD 在没有前一行/后一行时返回 NULL

### 💡 窗口函数适用场景

| 场景类型         | 适用函数                    | 实际应用               |
| ---------------- | --------------------------- | ---------------------- |
| **时间序列分析** | SUM() OVER, AVG() OVER      | 累计总额、移动平均     |
| **排名和分位数** | ROW_NUMBER(), RANK()        | 销售排名、成绩排名     |
| **数据对比分析** | LAG(), LEAD()               | 月度环比、前后记录比较 |
| **获取边界值**   | FIRST_VALUE(), LAST_VALUE() | 获取首末记录           |

## 🔧 进阶提示

### 窗口框架（Window Frame）

```sql
-- 计算3天移动平均
AVG(amount) OVER (
    ORDER BY order_date
    ROWS BETWEEN 2 PRECEDING AND CURRENT ROW
) AS 3_day_moving_avg

-- 计算累计到当前行（包括所有前面的行）
SUM(amount) OVER (
    ORDER BY order_date
    ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
) AS cumulative_sum
```

### 性能优化建议

1. 为 `PARTITION BY` 和 `ORDER BY` 中的列创建索引
2. 避免在窗口函数中使用复杂的计算表达式
3. 考虑数据量，窗口函数在大量数据上可能较慢

---

> **📌 注意**：窗口函数在保持原始行结构的同时提供强大的分析能力，是 SQL Server 中进行复杂数据分析的重要工具。
