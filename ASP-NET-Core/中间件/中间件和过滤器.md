# 中间件和过滤器的区别详解

这是 ASP.NET Core 中两个非常重要的概念，它们都用于处理 HTTP 请求和响应，但设计目的和使用场景不同。

## 核心区别总结

| 特性         | **中间件 (Middleware)** | **过滤器 (Filters)**    |
| ------------ | ----------------------- | ----------------------- |
| **定位**     | HTTP 请求管道级别       | MVC 框架级别            |
| **执行时机** | 请求处理的早期和晚期    | 在 MVC 处理周期内       |
| **作用范围** | 所有请求                | MVC 相关的请求          |
| **访问内容** | 原始 HTTP 上下文        | Action、Controller 信息 |
| **顺序**     | 注册顺序决定执行顺序    | 按过滤器类型执行        |
| **依赖注入** | 支持，但有生命周期限制  | 完全支持                |

---

## 1. **中间件 (Middleware)**

### 执行位置

```
HTTP请求 → 中间件1 → 中间件2 → ... → MVC中间件 → 端点路由 → 响应 ← 中间件2 ← 中间件1
```

### 主要特点

```csharp
public class LoggingMiddleware
{
    private readonly RequestDelegate _next;

    public LoggingMiddleware(RequestDelegate next)
    {
        _next = next;
    }

    public async Task InvokeAsync(HttpContext context)
    {
        // 在 MVC 之前执行
        Console.WriteLine($"Request: {context.Request.Path}");

        // 调用下一个中间件
        await _next(context);

        // 在 MVC 之后执行
        Console.WriteLine($"Response: {context.Response.StatusCode}");
    }
}

// Program.cs 中注册
app.UseMiddleware<LoggingMiddleware>();
// 或使用扩展方法
app.UseLogging();
```

### 典型的中间件

1. **静态文件中间件** - `app.UseStaticFiles()`
2. **认证中间件** - `app.UseAuthentication()`
3. **授权中间件** - `app.UseAuthorization()`
4. **异常处理中间件** - `app.UseExceptionHandler()`
5. **HTTPS 重定向中间件** - `app.UseHttpsRedirection()`
6. **CORS 中间件** - `app.UseCors()`

### 执行顺序示例

```csharp
// Program.cs
var app = builder.Build();

// 顺序很重要！
app.UseExceptionHandler("/error"); // 1. 全局异常处理
app.UseHttpsRedirection();         // 2. HTTPS重定向
app.UseStaticFiles();              // 3. 静态文件
app.UseRouting();                  // 4. 路由
app.UseAuthentication();           // 5. 认证
app.UseAuthorization();            // 6. 授权
app.UseCors("AllowAll");           // 7. CORS
app.UseRequestLocalization();      // 8. 本地化

// 自定义中间件
app.Use(async (context, next) =>
{
    // 请求前
    var watch = Stopwatch.StartNew();
    await next(); // 调用下一个中间件
    // 请求后
    watch.Stop();
    context.Response.Headers["X-Response-Time"] = watch.ElapsedMilliseconds.ToString();
});

app.MapControllers(); // 终结点
```

## 2. **过滤器 (Filters)**

### MVC 请求处理管道中的位置

```
Request → Routing Middleware → MVC Middleware →
Authorization Filters → Resource Filters →
Action Filters (Before) → Model Binding →
Action Filters (After) → Action Execution →
Exception Filters ← Exception Filters ←
Result Filters → Response ←
Resource Filters (After) ← Response
```

### 五种过滤器类型

```csharp
// 1. 授权过滤器 (IAuthorizationFilter) - 最先执行
public class CustomAuthorizeFilter : IAuthorizationFilter
{
    public void OnAuthorization(AuthorizationFilterContext context)
    {
        // 认证检查
        if (!context.HttpContext.User.Identity.IsAuthenticated)
        {
            context.Result = new UnauthorizedResult();
        }

        // 角色检查
        var hasRole = context.HttpContext.User.IsInRole("Admin");
        if (!hasRole)
        {
            context.Result = new ForbidResult();
        }
    }
}

// 2. 资源过滤器 (IResourceFilter) - 在模型绑定前后执行
public class CacheResourceFilter : IResourceFilter
{
    public void OnResourceExecuting(ResourceExecutingContext context)
    {
        // 执行前 - 缓存检查
        var cache = context.HttpContext.RequestServices.GetService<IMemoryCache>();
        var cacheKey = context.HttpContext.Request.Path;

        if (cache.TryGetValue(cacheKey, out var cachedResult))
        {
            context.Result = (IActionResult)cachedResult;
        }
    }

    public void OnResourceExecuted(ResourceExecutedContext context)
    {
        // 执行后 - 缓存结果
        var cache = context.HttpContext.RequestServices.GetService<IMemoryCache>();
        var cacheKey = context.HttpContext.Request.Path;
        cache.Set(cacheKey, context.Result, TimeSpan.FromMinutes(5));
    }
}

// 3. 动作过滤器 (IActionFilter) - 在Action执行前后
public class LogActionFilter : IActionFilter
{
    private readonly ILogger _logger;

    public LogActionFilter(ILogger<LogActionFilter> logger)
    {
        _logger = logger;
    }

    public void OnActionExecuting(ActionExecutingContext context)
    {
        // Action执行前
        _logger.LogInformation($"Action: {context.ActionDescriptor.DisplayName}");
        _logger.LogInformation($"Arguments: {JsonSerializer.Serialize(context.ActionArguments)}");
    }

    public void OnActionExecuted(ActionExecutedContext context)
    {
        // Action执行后
        if (context.Exception != null)
        {
            _logger.LogError(context.Exception, "Action执行出错");
        }
        else
        {
            _logger.LogInformation("Action执行成功");
        }
    }
}

// 4. 异常过滤器 (IExceptionFilter) - 处理异常
public class GlobalExceptionFilter : IExceptionFilter
{
    private readonly ILogger _logger;

    public GlobalExceptionFilter(ILogger<GlobalExceptionFilter> logger)
    {
        _logger = logger;
    }

    public void OnException(ExceptionContext context)
    {
        _logger.LogError(context.Exception, "未处理的异常");

        // 自定义错误响应
        context.Result = new ObjectResult(new
        {
            Error = "服务器内部错误",
            Message = context.Exception.Message,
            RequestId = context.HttpContext.TraceIdentifier
        })
        {
            StatusCode = 500
        };

        context.ExceptionHandled = true; // 标记为已处理
    }
}

// 5. 结果过滤器 (IResultFilter) - 在结果执行前后
public class FormatResultFilter : IResultFilter
{
    public void OnResultExecuting(ResultExecutingContext context)
    {
        // 结果执行前 - 可以修改结果
        if (context.Result is ObjectResult objectResult)
        {
            objectResult.Value = new ApiResponse
            {
                Success = true,
                Data = objectResult.Value,
                Timestamp = DateTime.UtcNow
            };
        }
    }

    public void OnResultExecuted(ResultExecutedContext context)
    {
        // 结果执行后 - 只能记录日志等
        _logger.LogInformation("结果已返回给客户端");
    }
}
```

### 注册过滤器的方式

```csharp
// 1. 全局注册 - 作用于所有Controller和Action
builder.Services.AddControllers(options =>
{
    options.Filters.Add<GlobalExceptionFilter>();
    options.Filters.Add<LogActionFilter>();
    options.Filters.Add(new ProducesResponseTypeAttribute(typeof(ApiResponse), 200));
    options.Filters.Add(new ProducesResponseTypeAttribute(typeof(ErrorResponse), 400));
    options.Filters.Add(new ProducesResponseTypeAttribute(typeof(ErrorResponse), 500));
});

// 2. 控制器级别 - 作用于整个控制器
[ApiController]
[Route("api/[controller]")]
[Authorize] // 内置的授权过滤器
[ServiceFilter(typeof(LogActionFilter))] // 自定义过滤器
[TypeFilter(typeof(CacheResourceFilter))]
public class ProductsController : ControllerBase
{
    // 所有Action都会应用上面的过滤器
}

// 3. 动作级别 - 作用于单个Action
public class ProductsController : ControllerBase
{
    [HttpGet("{id}")]
    [ResponseCache(Duration = 60)] // 内置的结果缓存过滤器
    [ServiceFilter(typeof(LogActionFilter))]
    [ProducesResponseType(typeof(ProductDto), 200)]
    [ProducesResponseType(typeof(ErrorResponse), 404)]
    public IActionResult GetProduct(int id)
    {
        // ...
    }

    [HttpPost]
    [ValidateModel] // 自定义模型验证过滤器
    [Authorize(Roles = "Admin")]
    public IActionResult CreateProduct([FromBody] CreateProductDto dto)
    {
        // ...
    }
}

// 4. 过滤器工厂 - 动态创建过滤器
public class CustomFilterFactory : IFilterFactory
{
    public bool IsReusable => false;

    public IFilterMetadata CreateInstance(IServiceProvider serviceProvider)
    {
        // 可以基于服务容器创建复杂的过滤器
        var logger = serviceProvider.GetService<ILogger<LogActionFilter>>();
        var config = serviceProvider.GetService<IConfiguration>();

        return new LogActionFilter(logger)
        {
            LogLevel = config.GetValue<LogLevel>("Logging:Level")
        };
    }
}
```

## 3. **关键区别对比**

### 执行时机对比图

```
HTTP 请求
    ↓
中间件1（全局异常处理） ← 异常处理在最外层
    ↓
中间件2（HTTPS重定向）
    ↓
中间件3（静态文件） ← 如果是静态文件请求，直接返回
    ↓
中间件4（路由）
    ↓
中间件5（认证）
    ↓
中间件6（授权）
    ↓
MVC 中间件
    ├── 授权过滤器 ← 第一个过滤器
    ├── 资源过滤器
    ├── 动作过滤器 (Before)
    ├── Action 执行
    ├── 动作过滤器 (After)
    ├── 结果过滤器 (Before)
    ├── 结果生成
    ├── 结果过滤器 (After)
    └── 资源过滤器 (After)
    ↓
中间件7（响应压缩） ← 处理MVC返回的响应
    ↓
中间件8（日志记录）
    ↓
HTTP 响应
```

### 访问内容对比

```csharp
// 中间件 - 只能访问原始HTTP上下文
public class SimpleMiddleware
{
    public async Task InvokeAsync(HttpContext context)
    {
        // 只能访问:
        // context.Request
        // context.Response
        // context.User
        // context.Connection
        // context.Items
        // 等HTTP相关属性

        // 无法访问:
        // Action信息
        // Controller信息
        // Model绑定信息
        // 验证信息
    }
}

// 过滤器 - 可以访问MVC上下文
public class MvcFilter : IActionFilter
{
    public void OnActionExecuting(ActionExecutingContext context)
    {
        // 可以访问:
        // context.ActionDescriptor - Action信息
        // context.Controller - Controller实例
        // context.ModelState - 模型状态
        // context.ActionArguments - Action参数
        // context.Result - 可以设置结果

        // context.HttpContext - 仍然可以访问HTTP上下文
        // context.HttpContext.Items - 可以传递数据
    }
}
```

### 生命周期和依赖注入

```csharp
// 中间件的DI限制
public class MiddlewareWithDI
{
    private readonly RequestDelegate _next;
    private readonly ILogger _logger;

    // 中间件的构造函数在应用启动时执行
    // 只能注入Singleton或Transient服务
    // 不能注入Scoped服务！
    public MiddlewareWithDI(RequestDelegate next, ILogger<MiddlewareWithDI> logger)
    {
        _next = next;
        _logger = logger; // OK - ILogger是单例
    }

    public async Task InvokeAsync(HttpContext context)
    {
        // 这里可以注入Scoped服务
        var scopedService = context.RequestServices.GetService<IScopedService>();

        await _next(context);
    }
}

// 过滤器的DI支持
[AttributeUsage(AttributeTargets.Class | AttributeTargets.Method)]
public class CustomFilterAttribute : TypeFilterAttribute
{
    public CustomFilterAttribute()
        : base(typeof(CustomFilterImpl))
    {
    }

    private class CustomFilterImpl : IActionFilter
    {
        // 过滤器支持完整的DI
        private readonly IScopedService _scopedService;
        private readonly ITransientService _transientService;
        private readonly ISingletonService _singletonService;

        // 可以注入任何生命周期的服务
        public CustomFilterImpl(
            IScopedService scopedService,
            ITransientService transientService,
            ISingletonService singletonService)
        {
            _scopedService = scopedService;
            _transientService = transientService;
            _singletonService = singletonService;
        }

        public void OnActionExecuting(ActionExecutingContext context)
        {
            // 使用注入的服务
        }

        public void OnActionExecuted(ActionExecutedContext context) { }
    }
}
```

## 4. **选择指南：何时使用哪个**

### **使用中间件的情况**

```csharp
// 适合中间件的场景：
app.UseWhen(context =>
{
    // 1. 需要处理所有类型的请求（包括非API请求）
    return true; // 所有请求
}, appBuilder =>
{
    // 例如：全局日志、性能监控、请求跟踪
    appBuilder.UseMiddleware<RequestLoggingMiddleware>();
});

// 2. 需要在MVC处理之前或之后执行
app.Use(async (context, next) =>
{
    // 请求预处理：解压缩、编码转换等
    if (context.Request.Headers.ContainsKey("Content-Encoding"))
    {
        // 处理压缩内容
    }

    await next();

    // 响应后处理：压缩、添加响应头等
    context.Response.Headers["Server"] = "MyServer";
});

// 3. 需要终止请求管道
app.Run(async context =>
{
    // 直接响应，不进入MVC
    if (context.Request.Path.StartsWithSegments("/health"))
    {
        await context.Response.WriteAsync("Healthy");
        return; // 终止管道
    }

    // 否则继续
    await next();
});

// 4. 需要基于路径条件执行
app.Map("/admin", adminApp =>
{
    adminApp.UseMiddleware<AdminAuthenticationMiddleware>();
    adminApp.UseRouting();
    adminApp.UseEndpoints(endpoints =>
    {
        endpoints.MapControllers();
    });
});
```

### **使用过滤器的情况**

```csharp
// 适合过滤器的场景：

// 1. 需要访问Action/Controller信息
[AttributeUsage(AttributeTargets.Method)]
public class AuditLogAttribute : ActionFilterAttribute
{
    public override void OnActionExecuting(ActionExecutingContext context)
    {
        var actionName = context.ActionDescriptor.DisplayName;
        var controllerName = context.Controller.GetType().Name;
        var userId = context.HttpContext.User.FindFirst(ClaimTypes.NameIdentifier)?.Value;

        // 记录审计日志，包含具体的业务操作信息
        _auditService.LogAction(userId, controllerName, actionName, context.ActionArguments);
    }
}

// 2. 需要处理模型绑定和验证
[AttributeUsage(AttributeTargets.Method)]
public class ValidateModelAttribute : ActionFilterAttribute
{
    public override void OnActionExecuting(ActionExecutingContext context)
    {
        if (!context.ModelState.IsValid)
        {
            // 返回详细的验证错误
            var errors = context.ModelState
                .Where(e => e.Value.Errors.Count > 0)
                .ToDictionary(
                    kvp => kvp.Key,
                    kvp => kvp.Value.Errors.Select(e => e.ErrorMessage).ToArray()
                );

            context.Result = new BadRequestObjectResult(new
            {
                Message = "参数验证失败",
                Errors = errors
            });
        }
    }
}

// 3. 需要基于Action的结果进行处理
[AttributeUsage(AttributeTargets.Method)]
public class FormatResponseAttribute : ResultFilterAttribute
{
    public override void OnResultExecuting(ResultExecutingContext context)
    {
        if (context.Result is ObjectResult objectResult)
        {
            // 统一包装响应格式
            objectResult.Value = new ApiResponse
            {
                Code = 200,
                Message = "Success",
                Data = objectResult.Value,
                Timestamp = DateTimeOffset.UtcNow.ToUnixTimeSeconds()
            };
        }
    }
}

// 4. 需要异常处理和业务逻辑
[AttributeUsage(AttributeTargets.Class | AttributeTargets.Method)]
public class HandleBusinessExceptionAttribute : ExceptionFilterAttribute
{
    public override void OnException(ExceptionContext context)
    {
        if (context.Exception is BusinessException businessEx)
        {
            // 处理业务异常，返回友好的错误信息
            context.Result = new ObjectResult(new
            {
                Code = businessEx.ErrorCode,
                Message = businessEx.Message,
                Suggestion = businessEx.Suggestion
            })
            {
                StatusCode = 400
            };
            context.ExceptionHandled = true;
        }
    }
}
```

### **实际项目中的最佳实践组合**

```csharp
// Program.cs - 配置完整的管道
var app = builder.Build();

// ========== 中间件部分 ==========
// 1. 全局异常处理（最外层）
app.UseExceptionHandler(exceptionHandlerApp =>
{
    exceptionHandlerApp.Run(async context =>
    {
        context.Response.StatusCode = 500;
        context.Response.ContentType = "application/json";
        await context.Response.WriteAsync(
            JsonSerializer.Serialize(new { error = "服务器内部错误" })
        );
    });
});

// 2. 安全相关中间件
app.UseHttpsRedirection();
app.UseHsts(); // HTTP严格传输安全

// 3. 静态资源
app.UseStaticFiles();
app.UseStaticFiles(new StaticFileOptions
{
    ServeUnknownFileTypes = false,
    DefaultContentType = "application/octet-stream"
});

// 4. 路由和CORS
app.UseRouting();
app.UseCors("ApiPolicy");

// 5. 认证授权
app.UseAuthentication();
app.UseAuthorization();

// 6. 性能监控中间件
app.UseMiddleware<PerformanceMiddleware>();

// ========== MVC部分 ==========
app.UseEndpoints(endpoints =>
{
    endpoints.MapControllers()
        // 全局过滤器在这里配置
        .AddEndpointFilterFactory((context, next) =>
        {
            return async invocationContext =>
            {
                try
                {
                    return await next(invocationContext);
                }
                catch (Exception ex)
                {
                    var logger = invocationContext.HttpContext
                        .RequestServices.GetRequiredService<ILogger<Program>>();
                    logger.LogError(ex, "端点执行异常");
                    throw;
                }
            };
        });
});

// ========== 过滤器配置 ==========
// 在 Startup.cs 或 Program.cs 的 AddControllers 中
builder.Services.AddControllers(options =>
{
    // 全局异常过滤器
    options.Filters.Add<GlobalExceptionFilter>();

    // 全局模型验证过滤器
    options.Filters.Add<ValidateModelFilter>();

    // 全局响应格式过滤器
    options.Filters.Add<ApiResponseFilter>();

    // 全局授权策略
    options.Filters.Add(new AuthorizeFilter("DefaultPolicy"));

    // 全局禁用某些功能
    options.Filters.Add(new AutoValidateAntiforgeryTokenAttribute());
    options.Filters.Add(new RequireHttpsAttribute());
})
.AddJsonOptions(options =>
{
    // JSON配置
    options.JsonSerializerOptions.PropertyNamingPolicy = JsonNamingPolicy.CamelCase;
});
```

## 总结

| 决策点                    | 选择中间件          | 选择过滤器            |
| ------------------------- | ------------------- | --------------------- |
| **需要处理所有请求**      | ✅ 是               | ❌ 否                 |
| **需要访问Action信息**    | ❌ 否               | ✅ 是                 |
| **需要在模型绑定前处理**  | ✅ 是               | ✅ 是（用资源过滤器） |
| **需要处理认证/授权**     | ✅ 是（基础认证）   | ✅ 是（细粒度控制）   |
| **需要全局异常处理**      | ✅ 是（未处理异常） | ✅ 是（业务异常）     |
| **需要修改请求/响应内容** | ✅ 是               | ✅ 是                 |
| **需要基于路由分支处理**  | ✅ 是               | ❌ 否                 |
| **需要依赖完整的DI**      | ❌ 有限             | ✅ 是                 |

**简单规则**：

- 如果逻辑与**HTTP协议本身**相关（压缩、编码、协议升级等），用**中间件**
- 如果逻辑与**业务/应用**相关（权限、日志、缓存、验证等），用**过滤器**
- 如果需要**两者结合**，可以在中间件中设置上下文，在过滤器中读取使用
