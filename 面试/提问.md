# 程序员面试提问优先级清单（实战总结）

## 🎯 **优先级一：必须问的核心问题**

### **1. 关于工作内容和团队**

```markdown
🔹 **我具体负责什么？**
• 入职后主要参与哪个产品或模块？
• 这个岗位的典型一天是怎样的？

🔹 **团队情况怎样？**
• 团队规模、组成（前后端比例）？
• 团队现在面临的最大技术挑战是什么？
```

### **2. 关于技术栈和开发流程**

```markdown
🔹 **技术环境如何？**
• 主要技术栈是什么？选择原因？
• 项目架构是微服务还是单体？

🔹 **开发流程怎样？**
• CI/CD流程完备吗？部署频率？
• 代码审查是强制的吗？流程如何？
• 测试策略是什么？（单元/集成/E2E测试覆盖率）
```

### **3. 关于工作方式**

```markdown
🔹 **工作节奏如何？**（巧妙问加班）
• "项目紧急时如何处理？团队如何平衡工作节奏？"
• "团队成员通常什么时间下班？"

🔹 **沟通协作方式？**
• 团队用什么工具沟通？（Slack/飞书/钉钉）
• 需求从提出到上线的完整流程？
```

## 📈 **优先级二：应该问的发展问题**

### **1. 职业成长路径**

```markdown
🔹 **成长机会有哪些？**
• 公司提供哪些学习资源？（培训预算、技术会议支持）
• 有Mentor制度吗？新人如何快速上手？

🔹 **晋升机制如何？**
• 技术晋升标准是什么？（偏业务产出还是技术创新）
• 绩效评估的频率和标准？
```

### **2. 团队文化和工程文化**

```markdown
🔹 **技术文化怎样？**
• 如何管理技术债务？有专门的重构时间吗？
• 对新技术的尝试态度如何？

🔹 **团队氛围如何？**
• 团队成员的平均司龄？
• 团队最吸引人的特点是什么？
• 技术决策是如何做出的？
```

## 🎁 **优先级三：可以问的补充问题**

### **1. 福利和待遇**（放在面试后期）

```markdown
🔹 **薪资结构如何？**
• 薪资构成（基本、绩效、奖金比例）
• 年终奖评定标准？

🔹 **其他福利？**
• 五险一金缴纳基数和比例？
• 年假、病假政策？
• 补充商业保险、年度体检？
```

### **2. 业务和发展**

```markdown
🔹 **业务前景如何？**
• 产品的核心KPI是什么？
• 未来半年的产品规划？
• 部门是成本中心还是利润中心？
```

## 🚫 **绝对不能问的问题**

```markdown
❌ 太早问薪资："这个职位给多少钱？"
❌ 显得不敬业："加班多吗？我可以不加班吗？"
❌ 准备不足："公司是做什么的？"
❌ 过于私人："您的薪资是多少？"
```

## 💡 **高级提问技巧**

### **反向面试技巧**

```markdown
🌟 "能分享团队最近解决的一个技术难题吗？过程是怎样的？"
🌟 "回顾过去一年，团队最大的成就和遗憾分别是什么？"
🌟 "您在这里工作最满意的是什么？"
🌟 "基于今天的交流，您觉得我是否适合这个岗位？"
```

### **提问时机策略**

```markdown
📍 **面试开始**：简短确认性问题
📍 **面试中间**：针对讨论内容深入提问
📍 **面试结尾**：当面试官问"你有什么问题吗"时
📍 **面试后**：通过感谢信补充少量问题
```

## 📊 **面试提问速查表**

| 面试阶段    | 推荐问题               | 目的         |
| ----------- | ---------------------- | ------------ |
| **技术面**  | 技术栈、架构、开发流程 | 了解技术环境 |
| **交叉面**  | 团队协作、代码审查     | 了解工程文化 |
| **总监面**  | 团队文化、发展规划     | 了解公司方向 |
| **HR面**    | 薪资福利、晋升机制     | 了解个人发展 |
| **谈offer** | 具体待遇、入职安排     | 确认细节     |

## 🎯 **最终建议**

### **1. 问题要体现：**

```markdown
✅ **专业性**：展示你对技术、流程的关注
✅ **主动性**：显示你对这个机会的重视
✅ **思考深度**：不只是问表面问题
✅ **匹配度**：帮助你判断是否适合
```

### **2. 提问三要素：**

```markdown
🔸 **问题质量 > 问题数量**
🔸 **合适的时机问合适的问题**
🔸 **观察面试官的回答方式和态度**
```

### **3. 终极问题预备：**

```markdown
"基于我们今天的交流，您觉得我有哪些需要提升的地方？"
"您对我加入团队后的期望是什么？"
"还有什么需要我了解的吗？"
```

记住：**好的提问是面试成功的一半**。这些问题不仅能帮你全面了解公司，更能展示你的专业素养和思考深度，让你在众多候选人中脱颖而出。
