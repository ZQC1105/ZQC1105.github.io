## 31. `yield return` 的作用是什么？

`yield return` 用于创建**迭代器**，逐个返回值，实现**延迟执行**和**按需生成**。

**工作原理**：

- 编译器生成状态机
- 每次迭代只返回一个元素
- 方法状态在 `yield return` 后保留

**示例**：

```csharp
// 基本用法
public static IEnumerable<int> GetNumbers()
{
    yield return 1;
    yield return 2;
    yield return 3;
}

foreach (var num in GetNumbers())
{
    Console.WriteLine(num);  // 输出 1,2,3，逐个返回
}

// 无限序列（按需生成）
public static IEnumerable<int> Fibonacci()
{
    int a = 0, b = 1;
    while (true)
    {
        yield return a;
        (a, b) = (b, a + b);
    }
}

// 只取前 10 个斐波那契数
var first10 = Fibonacci().Take(10).ToList();

// 延迟执行示例
public static IEnumerable<int> GetNumbersWithLogging()
{
    Console.WriteLine("开始执行");
    yield return 1;
    Console.WriteLine("返回 1 后");
    yield return 2;
    Console.WriteLine("返回 2 后");
}

var numbers = GetNumbersWithLogging();  // 此时不输出任何内容
Console.WriteLine("开始迭代");
foreach (var n in numbers)  // 迭代时才开始执行
{
    Console.WriteLine($"收到: {n}");
}
// 输出:
// 开始迭代
// 开始执行
// 收到: 1
// 返回 1 后
// 收到: 2
// 返回 2 后

// yield break 提前结束
public static IEnumerable<int> GetUntil(int max)
{
    for (int i = 0; i < 100; i++)
    {
        if (i > max) yield break;
        yield return i;
    }
}
```

## 32. 垃圾回收器（GC）有多少个代（Generation）？

**3 个代**：Gen 0、Gen 1、Gen 2。

| 代        | 说明                           | 回收频率 | 性能 |
| --------- | ------------------------------ | -------- | ---- |
| **Gen 0** | 新分配的对象                   | 最频繁   | 最快 |
| **Gen 1** | 幸存 1 次的对象                | 较频繁   | 中等 |
| **Gen 2** | 长期存活的对象（大对象也在此） | 最少     | 最慢 |

**工作原理**：

```csharp
// 代的工作原理
for (int i = 0; i < 1000; i++)
{
    var obj = new object();      // 分配到 Gen 0
    // 当 Gen 0 满时触发回收
    // 幸存的对象升级到 Gen 1
    // Gen 1 满时触发回收，幸存者升级到 Gen 2
}

// 查看对象的代
object obj2 = new object();
int generation = GC.GetGeneration(obj2);  // 0

GC.Collect();  // 强制回收
generation = GC.GetGeneration(obj2);  // 可能变为 1

GC.Collect();
generation = GC.GetGeneration(obj2);  // 可能变为 2

// 大对象（>= 85KB）直接分配到 Gen 2
byte[] bigArray = new byte[85000];  // 直接进入 Gen 2

// 手动触发 GC（不推荐）
GC.Collect();
GC.WaitForPendingFinalizers();

// 监控 GC
GC.RegisterForFullGCNotification(10, 10);
```

## 33. `Interlocked` 类的作用

`Interlocked` 提供**原子操作**，在多线程环境下安全地操作共享变量，无需使用锁。

**常用方法**：

```csharp
// 1. Increment / Decrement
int counter = 0;
Interlocked.Increment(ref counter);  // counter = 1
Interlocked.Decrement(ref counter);  // counter = 0

// 2. Add
int value = 10;
Interlocked.Add(ref value, 5);  // value = 15

// 3. Exchange（交换）
int a = 10;
int old = Interlocked.Exchange(ref a, 20);  // a = 20, old = 10

// 4. CompareExchange（比较并交换）
int b = 10;
int result = Interlocked.CompareExchange(ref b, 20, 10);  // 如果 b == 10，设为 20
Console.WriteLine(b);  // 20

// 5. Read（读取 64 位值）
long value64 = 100;
long read = Interlocked.Read(ref value64);

// 6. 实现线程安全计数器
public class ThreadSafeCounter
{
    private int _count = 0;

    public int Increment() => Interlocked.Increment(ref _count);
    public int Decrement() => Interlocked.Decrement(ref _count);
    public int Value => Interlocked.CompareExchange(ref _count, 0, 0);
}

// 7. 实现线程安全的单例
public class Singleton
{
    private static Singleton? _instance;
    private static readonly object _lock = new();

    public static Singleton Instance
    {
        get
        {
            if (_instance is null)
            {
                lock (_lock)
                {
                    if (_instance is null)
                    {
                        Interlocked.CompareExchange(ref _instance, new Singleton(), null);
                    }
                }
            }
            return _instance;
        }
    }
}
```

## 34. 自动属性（Auto Property）编译器生成的代码

**自动属性**是语法糖，编译器生成**私有字段**和**默认 getter/setter**。

```csharp
// 源代码
public class Person
{
    public string Name { get; set; }
    public int Age { get; set; } = 18;
    public string? Email { get; }
}

// 编译器生成的代码（近似）
public class Person
{
    [CompilerGenerated]
    private string <Name>k__BackingField;

    [CompilerGenerated]
    private int <Age>k__BackingField;

    [CompilerGenerated]
    private string? <Email>k__BackingField;

    public string Name
    {
        [CompilerGenerated]
        get => <Name>k__BackingField;
        [CompilerGenerated]
        set => <Name>k__BackingField = value;
    }

    public int Age
    {
        [CompilerGenerated]
        get => <Age>k__BackingField;
        [CompilerGenerated]
        set => <Age>k__BackingField = value;
    }

    public string? Email
    {
        [CompilerGenerated]
        get => <Email>k__BackingField;
    }

    public Person()
    {
        <Age>k__BackingField = 18;
    }
}
```

**只读自动属性**：

```csharp
// 源代码
public class Product
{
    public string Name { get; }
    public Product(string name) => Name = name;
}

// 生成的代码
public class Product
{
    private readonly string <Name>k__BackingField;

    public string Name => <Name>k__BackingField;

    public Product(string name)
    {
        <Name>k__BackingField = name;
    }
}
```

## 35. C# 中如何实现多态（Polymorphism）？

**三种多态**：

| 类型           | 实现方式               | 时机          |
| -------------- | ---------------------- | ------------- |
| **编译时多态** | 方法重载、运算符重载   | 编译时决定    |
| **运行时多态** | 虚方法、抽象方法、接口 | 运行时决定    |
| **泛型多态**   | 泛型类、泛型方法       | 编译时/运行时 |

**示例**：

```csharp
// 1. 继承多态（运行时）
public abstract class Shape
{
    public abstract double GetArea();
    public virtual string GetName() => "Shape";
}

public class Circle : Shape
{
    public double Radius { get; set; }
    public override double GetArea() => Math.PI * Radius * Radius;
    public override string GetName() => "Circle";
}

public class Rectangle : Shape
{
    public double Width { get; set; }
    public double Height { get; set; }
    public override double GetArea() => Width * Height;
}

// 使用
Shape shape = new Circle { Radius = 5 };
Console.WriteLine(shape.GetArea());  // 调用 Circle 的实现

// 2. 接口多态
public interface ILogger
{
    void Log(string message);
}

public class ConsoleLogger : ILogger
{
    public void Log(string message) => Console.WriteLine(message);
}

public class FileLogger : ILogger
{
    public void Log(string message) => File.AppendAllText("log.txt", message);
}

// 使用
ILogger logger = new ConsoleLogger();
logger.Log("Hello");  // 多态行为

// 3. 方法重载（编译时）
public class Calculator
{
    public int Add(int a, int b) => a + b;
    public double Add(double a, double b) => a + b;
    public int Add(int a, int b, int c) => a + b + c;
}
```

## 36. C# 中如何实现封装（Encapsulation）？

**封装**通过访问修饰符和属性实现。

**实现方式**：

```csharp
// 1. 访问修饰符控制可见性
public class BankAccount
{
    // 私有字段（内部状态）
    private decimal _balance;
    private readonly string _accountNumber;

    // 构造函数初始化
    public BankAccount(string accountNumber, decimal initialBalance)
    {
        _accountNumber = accountNumber;
        _balance = initialBalance;
    }

    // 公开属性（受控访问）
    public decimal Balance
    {
        get => _balance;
        private set => _balance = value;  // 只有内部可设置
    }

    public string AccountNumber => _accountNumber;  // 只读

    // 公开方法（行为封装）
    public void Deposit(decimal amount)
    {
        if (amount <= 0)
            throw new ArgumentException("金额必须大于 0");

        _balance += amount;
        OnBalanceChanged();
    }

    public bool Withdraw(decimal amount)
    {
        if (amount <= 0) return false;
        if (amount > _balance) return false;

        _balance -= amount;
        OnBalanceChanged();
        return true;
    }

    // 私有方法（内部实现细节）
    private void OnBalanceChanged()
    {
        Console.WriteLine($"余额变化: {_balance:C}");
    }
}

// 2. 属性验证
public class Product
{
    private string _name;
    private decimal _price;

    public string Name
    {
        get => _name;
        set => _name = string.IsNullOrWhiteSpace(value)
            ? throw new ArgumentException("名称不能为空")
            : value;
    }

    public decimal Price
    {
        get => _price;
        set => _price = value >= 0 ? value : 0;
    }
}

// 3. 只读/只写属性
public class Configuration
{
    public string ReadOnlyProperty => "Fixed Value";
    public string WriteOnlyProperty { set => Save(value); }
}
```

## 37. `ref` 和 `out` 参数的区别

| 特性                 | ref            | out        |
| -------------------- | -------------- | ---------- |
| **传入前必须初始化** | ✅ 必须        | ❌ 不需要  |
| **方法内必须赋值**   | ❌ 不必须      | ✅ 必须    |
| **用途**             | 传入并可能修改 | 返回多个值 |
| **重载区分**         | 不可区分       | 不可区分   |

**示例**：

```csharp
// ref：需要初始化
int x = 10;  // 必须初始化
void ModifyRef(ref int value)
{
    value = value * 2;  // 可以读取原值
}
ModifyRef(ref x);  // x = 20

// out：不需要初始化
int y;  // 可以不初始化
void GetValues(out int value1, out int value2)
{
    value1 = 10;  // 必须赋值
    value2 = 20;  // 必须赋值
}
GetValues(out y, out int z);  // y = 10, z = 20

// 实际应用
public bool TryParseInt(string input, out int result)
{
    return int.TryParse(input, out result);
}

// ref readonly（C# 12+）
public void Process(ref readonly int value)
{
    // 只能读取，不能修改
    Console.WriteLine(value);
}

// 在异步方法中限制
// ❌ 不能使用 ref/out 在 async 方法
// ✅ 使用 Task<Tuple<T>> 或自定义类型
```

## 38. `using` 语句如何工作？

`using` 确保 `IDisposable` 对象在使用后正确释放资源。

**工作原理**：编译器将 `using` 转换为 `try-finally` 块。

```csharp
// 源代码
using (var file = new FileStream("test.txt", FileMode.Open))
{
    // 使用文件
}

// 编译器生成的代码（近似）
FileStream file = new FileStream("test.txt", FileMode.Open);
try
{
    // 使用文件
}
finally
{
    if (file != null)
        ((IDisposable)file).Dispose();
}
```

**多种使用方式**：

```csharp
// 1. 多个 using
using (var file = new FileStream("a.txt", FileMode.Open))
using (var writer = new StreamWriter(file))
{
    writer.Write("Hello");
}

// 2. using 声明（C# 8+）
using var file2 = new FileStream("b.txt", FileMode.Open);
// 作用域结束时自动释放

// 3. await using（异步释放）
await using (var conn = new SqlConnection(connectionString))
{
    await conn.OpenAsync();
}

// 4. 自定义 IDisposable
public class Resource : IDisposable
{
    private bool _disposed = false;

    public void Use() => Console.WriteLine("Using resource");

    public void Dispose()
    {
        if (!_disposed)
        {
            Console.WriteLine("释放资源");
            _disposed = true;
        }
    }
}

using var resource = new Resource();
resource.Use();  // 结束时自动调用 Dispose
```

## 39. 什么是委托（Delegate）？如何使用？

**委托** 是类型安全的函数指针，可以引用方法。

**示例**：

```csharp
// 1. 声明委托
public delegate int MathOperation(int a, int b);

// 2. 实例化并调用
public static int Add(int a, int b) => a + b;
public static int Multiply(int a, int b) => a * b;

MathOperation op = Add;
int result = op(3, 5);  // 8

op = Multiply;
result = op(3, 5);  // 15

// 3. 内置委托
// Func<T>：有返回值
Func<int, int, int> addFunc = (a, b) => a + b;
int sum = addFunc(10, 20);

// Action<T>：无返回值
Action<string> printAction = msg => Console.WriteLine(msg);
printAction("Hello");

// Predicate<T>：返回 bool
Predicate<int> isEven = x => x % 2 == 0;
bool even = isEven(4);  // true

// 4. 多播委托
MathOperation multi = Add;
multi += Multiply;
multi += Add;
int result2 = multi(2, 3);  // 返回最后一个方法的结果

// 5. 委托作为参数
public void ProcessData(int[] data, Func<int, int> processor)
{
    for (int i = 0; i < data.Length; i++)
    {
        data[i] = processor(data[i]);
    }
}

ProcessData(new[] { 1, 2, 3 }, x => x * 2);  // { 2, 4, 6 }

// 6. 事件（基于委托）
public class Button
{
    public event EventHandler Clicked;

    public void Click()
    {
        Clicked?.Invoke(this, EventArgs.Empty);
    }
}
```

## 40. 方法重载（Overloading）vs 方法重写（Overriding）

| 特性              | 重载（Overloading）          | 重写（Overriding）     |
| ----------------- | ---------------------------- | ---------------------- |
| **关系**          | 同一类中的多个方法           | 基类和派生类之间       |
| **关键字**        | 无特殊关键字                 | `virtual`/`override`   |
| **参数**          | 必须不同（数量、类型、顺序） | 必须相同               |
| **返回类型**      | 可以不同                     | 必须相同（或协变返回） |
| **访问修饰符**    | 可以不同                     | 不能降低可见性         |
| **编译时/运行时** | 编译时绑定                   | 运行时绑定             |

**示例**：

```csharp
// 重载（同一类，不同参数）
public class Calculator
{
    public int Add(int a, int b) => a + b;
    public double Add(double a, double b) => a + b;
    public int Add(int a, int b, int c) => a + b + c;
    public int Add(params int[] numbers) => numbers.Sum();
}

// 使用
var calc = new Calculator();
calc.Add(1, 2);           // 调用 int 版本
calc.Add(1.5, 2.5);       // 调用 double 版本
calc.Add(1, 2, 3);        // 调用 3 参数版本

// 重写（基类和派生类）
public class Animal
{
    public virtual string Speak() => "Animal sound";
    public virtual void Move() => Console.WriteLine("Moving");
}

public class Dog : Animal
{
    public override string Speak() => "Bark";  // 重写
    public override void Move() => Console.WriteLine("Running");
}

public class Cat : Animal
{
    public override string Speak() => "Meow";
}

// 运行时多态
Animal animal = new Dog();
Console.WriteLine(animal.Speak());  // "Bark"（Dog 的实现）
animal.Move();  // "Running"

// 重载 + 重写结合
public class Base
{
    public virtual void Process(int x) => Console.WriteLine($"Base int: {x}");
    public virtual void Process(string s) => Console.WriteLine($"Base string: {s}");
}

public class Derived : Base
{
    public override void Process(int x) => Console.WriteLine($"Derived int: {x}");
    // Process(string) 继承未重写
}

var d = new Derived();
d.Process(10);     // 调用 Derived.Process(int)
d.Process("Hi");   // 调用 Base.Process(string)
```
