## 11. 如何创建带特定时区的日期？

**方法一：使用 `DateTime` + `TimeZoneInfo`**

```csharp
// 获取特定时区
TimeZoneInfo estZone = TimeZoneInfo.FindSystemTimeZoneById("Eastern Standard Time");
TimeZoneInfo pstZone = TimeZoneInfo.FindSystemTimeZoneById("Pacific Standard Time");
TimeZoneInfo utcZone = TimeZoneInfo.Utc;

// 创建特定时区的 DateTime（假设本地时间）
DateTime localTime = new DateTime(2024, 1, 15, 14, 30, 0);
DateTime estTime = TimeZoneInfo.ConvertTime(localTime, estZone);

// 创建 UTC 时间并转换
DateTime utcTime = new DateTime(2024, 1, 15, 14, 30, 0, DateTimeKind.Utc);
DateTime tokyoTime = TimeZoneInfo.ConvertTimeFromUtc(utcTime,
    TimeZoneInfo.FindSystemTimeZoneById("Tokyo Standard Time"));
```

**方法二：使用 `DateTimeOffset`（推荐）**

```csharp
// 直接创建带偏移量的时间
DateTimeOffset nyTime = new DateTimeOffset(2024, 1, 15, 14, 30, 0, TimeSpan.FromHours(-5));
DateTimeOffset utcTime = DateTimeOffset.UtcNow;
DateTimeOffset localTime = DateTimeOffset.Now;

// 转换时区
DateTimeOffset converted = nyTime.ToOffset(TimeSpan.FromHours(8)); // 转换为 UTC+8
```

**方法三：使用 `NodaTime`（最强大）**

```csharp
// 安装: dotnet add package NodaTime

var clock = SystemClock.Instance;
var tz = DateTimeZoneProviders.Tzdb["Asia/Shanghai"];
var now = clock.GetCurrentInstant();
var zonedDateTime = now.InZone(tz);

// 创建特定时间
var localDate = new LocalDateTime(2024, 1, 15, 14, 30, 0);
var zoned = tz.AtStrictly(localDate);
```

## 12. 如何更改当前线程的区域性（Culture）？

**方法一：更改当前线程**

```csharp
using System.Globalization;

// 设置当前线程的 Culture
Thread.CurrentThread.CurrentCulture = new CultureInfo("zh-CN");
Thread.CurrentThread.CurrentUICulture = new CultureInfo("zh-CN");

// 设置日期格式
Console.WriteLine(DateTime.Now.ToString("D"));  // 2024年1月15日

// 设置货币格式
Console.WriteLine(1234.56.ToString("C"));  // ¥1,234.56

// 恢复默认
Thread.CurrentThread.CurrentCulture = CultureInfo.InvariantCulture;
```

**方法二：使用 `CultureInfo.DefaultThreadCurrentCulture`**

```csharp
// 设置应用程序默认 Culture（影响所有新线程）
CultureInfo.DefaultThreadCurrentCulture = new CultureInfo("fr-FR");
CultureInfo.DefaultThreadCurrentUICulture = new CultureInfo("fr-FR");
```

**方法三：在 ASP.NET Core 中设置**

```csharp
// Program.cs
var app = builder.Build();

app.Use(async (context, next) =>
{
    var culture = new CultureInfo("zh-CN");
    CultureInfo.CurrentCulture = culture;
    CultureInfo.CurrentUICulture = culture;
    await next();
});

// 或使用中间件
app.UseRequestLocalization(options =>
{
    options.AddSupportedCultures("zh-CN", "en-US")
           .AddSupportedUICultures("zh-CN", "en-US")
           .SetDefaultCulture("zh-CN");
});
```

**方法四：异步代码中设置（注意上下文流）**

```csharp
// 使用 AsyncLocal 保持 Culture
private static AsyncLocal<CultureInfo> _culture = new AsyncLocal<CultureInfo>();

public async Task ProcessAsync()
{
    _culture.Value = new CultureInfo("ja-JP");
    CultureInfo.CurrentCulture = _culture.Value;

    await Task.Run(() =>
    {
        // 在另一个线程中，Culture 会自动流动
        Console.WriteLine(CultureInfo.CurrentCulture.Name);  // "ja-JP"
    });
}
```

## 13. HashSet 和 Dictionary 的区别

| 特性         | HashSet                            | Dictionary                                    |
| ------------ | ---------------------------------- | --------------------------------------------- |
| **存储内容** | 唯一值的集合                       | 键值对集合                                    |
| **索引访问** | ❌ 不能通过索引访问                | ✅ 通过 Key 访问 Value                        |
| **主要操作** | `Add`, `Contains`, `Remove`        | `Add`, `ContainsKey`, `Remove`, `TryGetValue` |
| **性能**     | `Contains` O(1)                    | `ContainsKey` O(1)                            |
| **内存**     | 较少（只存 Key）                   | 较多（存 Key + Value）                        |
| **重复**     | 不允许重复值                       | 不允许重复 Key                                |
| **排序**     | 无序（HashSet）或有序（SortedSet） | 无序（Dictionary）或有序（SortedDictionary）  |

**示例**：

```csharp
// HashSet：唯一值集合
HashSet<string> uniqueNames = new HashSet<string>();
uniqueNames.Add("Alice");
uniqueNames.Add("Bob");
uniqueNames.Add("Alice");  // 不会添加，返回 false

bool contains = uniqueNames.Contains("Bob");  // true

// 集合运算
HashSet<int> set1 = new HashSet<int> { 1, 2, 3 };
HashSet<int> set2 = new HashSet<int> { 2, 3, 4 };
set1.UnionWith(set2);      // { 1, 2, 3, 4 }
set1.IntersectWith(set2);  // { 2, 3 }
set1.ExceptWith(set2);     // { 1 }

// Dictionary：键值对
Dictionary<string, int> ages = new Dictionary<string, int>();
ages["Alice"] = 25;
ages["Bob"] = 30;
// ages["Alice"] = 26;  // 覆盖

if (ages.TryGetValue("Bob", out int bobAge))
{
    Console.WriteLine(bobAge);  // 30
}

// 选择指南
// 需要快速查重 → HashSet
// 需要存储关联数据 → Dictionary
// 只需要值 → HashSet
// 需要按索引访问 → Dictionary
```

## 14. `ToLookup` 方法的作用

`ToLookup` 创建 **Lookup<TKey, TElement>**，类似于分组后的**只读字典**，每个 Key 对应一个值的集合。

**特点**：

- 立即执行（非延迟）
- 不可变（创建后不能修改）
- 每个 Key 可对应多个值
- 类似 `GroupBy`，但立即执行且可重复使用

**示例**：

```csharp
public class Person
{
    public string Name { get; set; }
    public int Age { get; set; }
    public string City { get; set; }
}

var people = new List<Person>
{
    new Person { Name = "Alice", Age = 25, City = "Beijing" },
    new Person { Name = "Bob", Age = 30, City = "Shanghai" },
    new Person { Name = "Charlie", Age = 25, City = "Beijing" },
    new Person { Name = "Diana", Age = 35, City = "Shanghai" }
};

// 按年龄分组
var lookupByAge = people.ToLookup(p => p.Age);

// 访问特定 Key
foreach (var person in lookupByAge[25])
{
    Console.WriteLine(person.Name);  // Alice, Charlie
}

// 检查 Key 是否存在
bool hasAge30 = lookupByAge.Contains(30);  // true

// 获取所有 Key
foreach (var key in lookupByAge.Select(g => g.Key))
{
    Console.WriteLine($"Age {key}: {lookupByAge[key].Count()} people");
}

// 按城市分组，只保留姓名
var lookupByCity = people.ToLookup(p => p.City, p => p.Name);
foreach (var name in lookupByCity["Beijing"])
{
    Console.WriteLine(name);  // Alice, Charlie
}

// 与 GroupBy 的区别
var groupBy = people.GroupBy(p => p.Age);      // 延迟执行，只能迭代一次
var lookup = people.ToLookup(p => p.Age);      // 立即执行，可多次查询
```

## 15. LINQ 的 `Cast<T>` 方法会创建新对象吗？

**不会创建新对象**，只创建**新的引用**（对于引用类型）或**装箱**（对于值类型）。

```csharp
// 对于引用类型：只创建新引用，对象本身不变
ArrayList list = new ArrayList { "A", "B", "C" };
var strings = list.Cast<string>();  // 不创建新 string 对象

foreach (var s in strings)
{
    Console.WriteLine(s);  // 同原始对象
}

// 对于值类型：会发生装箱/拆箱
ArrayList ints = new ArrayList { 1, 2, 3 };
var casted = ints.Cast<int>();  // 拆箱：从 object 到 int，创建新的 int 值

// Cast 与 OfType 的区别
object[] objects = { "A", 123, "B", 456, "C" };

var allStrings = objects.Cast<string>();    // 抛出异常（遇到 int）
var onlyStrings = objects.OfType<string>(); // 只返回 "A", "B", "C"

// 性能考虑
var list2 = new List<int> { 1, 2, 3 };
var casted2 = list2.Cast<object>();  // 装箱：创建新的 object 引用
```

## 16. 解释 LINQ 中的延迟执行（Deferred Execution）

**延迟执行**：LINQ 查询在定义时**不立即执行**，只在**迭代结果时**才执行。

**执行时机**：

```csharp
// 定义查询（不执行）
var numbers = new List<int> { 1, 2, 3, 4, 5 };
var query = numbers.Where(n => n > 2);  // 未执行

// 修改源数据
numbers.Add(6);
numbers.Add(7);

// 迭代时才执行
foreach (var n in query)  // 此时执行查询，包含新增的 6, 7
{
    Console.WriteLine(n);  // 输出 3,4,5,6,7
}
```

**立即执行的方法**：

```csharp
// 这些方法会立即执行
var list = numbers.Where(n => n > 2).ToList();   // ToList()
var array = numbers.Where(n => n > 2).ToArray(); // ToArray()
var count = numbers.Where(n => n > 2).Count();   // Count()
var first = numbers.Where(n => n > 2).First();   // First()
var max = numbers.Max();                          // Max()
```

**延迟执行的好处**：

```csharp
// 1. 性能优化：只处理需要的数据
var firstBig = numbers.Where(n => n > 100).First();  // 找到第一个就停止

// 2. 避免不必要计算
var expensiveQuery = numbers
    .Where(n => n % 2 == 0)
    .Select(n => ExpensiveOperation(n));  // 只在迭代时计算

// 3. 链式操作多次迭代
var filtered = numbers.Where(n => n > 2);
var result1 = filtered.Count();   // 执行一次
var result2 = filtered.Max();     // 再次执行（重新遍历）

// 4. 避免多次执行（缓存结果）
var cached = numbers.Where(n => n > 2).ToList();  // 立即执行并缓存
var count1 = cached.Count();   // 使用缓存
var max1 = cached.Max();       // 使用缓存
```

## 17. `ImmutableList` 的工作原理

**不可变集合**：任何修改操作都返回**新集合**，原集合不变。

**工作原理**：

- 使用**结构共享**（Structural Sharing）
- 修改时只复制受影响的节点
- 未修改部分共享内存

**示例**：

```csharp
using System.Collections.Immutable;

// 创建不可变列表
ImmutableList<int> list1 = ImmutableList.Create<int>();
ImmutableList<int> list2 = ImmutableList.Create(1, 2, 3);

// 添加元素（返回新列表）
var list3 = list2.Add(4);     // list2 不变
var list4 = list3.AddRange(new[] { 5, 6 });

// 删除元素
var list5 = list4.Remove(3);

// 更新元素
var list6 = list5.SetItem(0, 100);

// 批量操作
var builder = list2.ToBuilder();
builder.Add(4);
builder.Add(5);
var list7 = builder.ToImmutable();

// 原始列表不变
Console.WriteLine(string.Join(",", list2));  // 1,2,3
Console.WriteLine(string.Join(",", list3));  // 1,2,3,4
```

**性能对比**：

```csharp
// 普通 List
var list = new List<int>();
for (int i = 0; i < 100000; i++)
{
    list.Add(i);  // 原地修改，快
}

// ImmutableList
var immutable = ImmutableList<int>.Empty;
for (int i = 0; i < 100000; i++)
{
    immutable = immutable.Add(i);  // 每次创建新列表，慢
}

// 使用 Builder 提高性能
var builder2 = ImmutableList.CreateBuilder<int>();
for (int i = 0; i < 100000; i++)
{
    builder2.Add(i);  // 原地修改
}
var result = builder2.ToImmutable();
```

## 18. 使用 `FrozenSet` / `FrozenDictionary` 的好处

**FrozenSet 和 FrozenDictionary**（.NET 8+）是**完全不可变**且**优化只读查找**的集合。

**优势**：

| 特性           | 普通 Dictionary | FrozenDictionary     |
| -------------- | --------------- | -------------------- |
| **初始化开销** | 低              | 高（需构建优化结构） |
| **查找性能**   | 快              | **更快**（20-30%）   |
| **内存**       | 较少            | 较多（预分配）       |
| **修改**       | 可修改          | 不可修改             |
| **适用场景**   | 动态数据        | **静态、高频查找**   |

**示例**：

```csharp
using System.Collections.Frozen;

// 创建 FrozenDictionary
var source = new Dictionary<string, int>
{
    ["Alice"] = 25,
    ["Bob"] = 30,
    ["Charlie"] = 35
};

var frozen = source.ToFrozenDictionary();

// 查找性能极高
for (int i = 0; i < 1000000; i++)
{
    var age = frozen["Alice"];  // 非常快
}

// FrozenSet
var numbers = Enumerable.Range(1, 1000).ToFrozenSet();
bool contains = numbers.Contains(500);  // 快速查找

// 使用场景：静态查找表
public static class StatusCodes
{
    private static readonly FrozenDictionary<int, string> _statusMap =
        new Dictionary<int, string>
        {
            [200] = "OK",
            [404] = "Not Found",
            [500] = "Internal Error"
        }.ToFrozenDictionary();

    public static string GetMessage(int code) => _statusMap.GetValueOrDefault(code);
}
```

## 19. 线程安全集合（Thread-Safe Collections）

**System.Collections.Concurrent 命名空间**：

| 集合                                 | 对应非安全版本             | 特点                        |
| ------------------------------------ | -------------------------- | --------------------------- |
| `ConcurrentDictionary<TKey, TValue>` | `Dictionary<TKey, TValue>` | 键值对，最常用              |
| `ConcurrentQueue<T>`                 | `Queue<T>`                 | FIFO 队列                   |
| `ConcurrentStack<T>`                 | `Stack<T>`                 | LIFO 栈                     |
| `ConcurrentBag<T>`                   | `List<T>`                  | 无序集合，适合生产者-消费者 |
| `BlockingCollection<T>`              | -                          | 支持阻塞和界限              |
| `ConcurrentLinkedQueue`              | -                          | 无界队列                    |

**示例**：

```csharp
// ConcurrentDictionary
var dict = new ConcurrentDictionary<string, int>();

// 线程安全的添加
dict.TryAdd("Alice", 25);
dict.AddOrUpdate("Bob", 30, (key, old) => old + 1);

// 获取或添加
int age = dict.GetOrAdd("Charlie", 35);

// ConcurrentQueue
var queue = new ConcurrentQueue<int>();
queue.Enqueue(1);
queue.Enqueue(2);
queue.TryDequeue(out int result);  // result = 1

// ConcurrentBag（无序）
var bag = new ConcurrentBag<int>();
bag.Add(1);
bag.Add(2);
bag.TryTake(out int item);  // 取出任意一个

// BlockingCollection（生产者-消费者）
var blocking = new BlockingCollection<int>(boundedCapacity: 10);

// 生产者
Task.Run(() =>
{
    for (int i = 0; i < 100; i++)
    {
        blocking.Add(i);
    }
    blocking.CompleteAdding();
});

// 消费者
foreach (var item in blocking.GetConsumingEnumerable())
{
    Console.WriteLine(item);
}
```

## 20. 如何对异步代码进行锁定（Lock）？

**异步代码不能使用 `lock` 关键字**（会导致死锁），应使用 `SemaphoreSlim`。

**方法一：SemaphoreSlim（推荐）**

```csharp
public class AsyncService
{
    private readonly SemaphoreSlim _semaphore = new SemaphoreSlim(1, 1);
    private int _sharedResource = 0;

    public async Task DoWorkAsync()
    {
        await _semaphore.WaitAsync();
        try
        {
            // 临界区代码
            _sharedResource++;
            await Task.Delay(100);  // 异步操作
            Console.WriteLine($"Value: {_sharedResource}");
        }
        finally
        {
            _semaphore.Release();
        }
    }

    // 带超时
    public async Task<bool> DoWorkWithTimeoutAsync(TimeSpan timeout)
    {
        if (await _semaphore.WaitAsync(timeout))
        {
            try
            {
                // 临界区
                return true;
            }
            finally
            {
                _semaphore.Release();
            }
        }
        return false;  // 超时未获取锁
    }
}
```

**方法二：AsyncLock（自定义实现）**

```csharp
public class AsyncLock
{
    private readonly SemaphoreSlim _semaphore = new SemaphoreSlim(1, 1);
    private readonly Task<IDisposable> _releaser;

    public AsyncLock()
    {
        _releaser = Task.FromResult((IDisposable)new Releaser(this));
    }

    public Task<IDisposable> LockAsync()
    {
        var wait = _semaphore.WaitAsync();
        return wait.IsCompleted
            ? _releaser
            : wait.ContinueWith((_, state) => (IDisposable)state!, _releaser.Result,
                CancellationToken.None, TaskContinuationOptions.ExecuteSynchronously, TaskScheduler.Default);
    }

    private class Releaser : IDisposable
    {
        private readonly AsyncLock _parent;
        public Releaser(AsyncLock parent) => _parent = parent;
        public void Dispose() => _parent._semaphore.Release();
    }
}

// 使用
private readonly AsyncLock _asyncLock = new AsyncLock();

public async Task ProcessAsync()
{
    using (await _asyncLock.LockAsync())
    {
        // 临界区代码
        await Task.Delay(100);
    }
}
```

**方法三：使用 Nito.AsyncEx 库**

```csharp
// 安装: dotnet add package Nito.AsyncEx

using Nito.AsyncEx;

private readonly AsyncLock _asyncLock = new AsyncLock();

public async Task ProcessAsync()
{
    using (await _asyncLock.LockAsync())
    {
        // 临界区
    }
}
```

**注意事项**：

```csharp
// ❌ 错误：在异步代码中使用 lock
// lock (_lockObject) { await Task.Delay(100); }  // 编译错误

// ❌ 错误：Monitor.Enter/Exit
// Monitor.Enter(_lock);
// await Task.Delay(100);  // 可能导致死锁
// Monitor.Exit(_lock);

// ✅ 正确：使用 SemaphoreSlim
private readonly SemaphoreSlim _semaphore = new SemaphoreSlim(1, 1);
await _semaphore.WaitAsync();
try { await Task.Delay(100); }
finally { _semaphore.Release(); }
```
