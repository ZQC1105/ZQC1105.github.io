### Vue3 知识体系总览表

| 层级           | 知识点             | 核心用途                     | 典型场景                        |
| -------------- | ------------------ | ---------------------------- | ------------------------------- |
| **基础响应式** | `ref` / `reactive` | 定义响应式数据               | 单向数据绑定 `:value`           |
|                | `computed`         | 派生数据，自带缓存           | 过滤列表、拼接全名、计算总价    |
|                | `watch`            | 监听变化，执行副作用         | 搜索联动、本地存储同步          |
| **组件通信**   | `defineProps`      | 父 → 子 传递数据             | 父组件传配置给子组件            |
|                | `defineEmits`      | 子 → 父 传递事件             | 子组件通知父组件提交/取消       |
|                | `v-model`          | 双向绑定（Props+Emit语法糖） | 表单输入、选择器                |
|                | `Slots`            | 内容分发，组件可定制         | 布局组件、弹窗内容区            |
|                | `Provide / Inject` | 祖 → 孙 跨层级传递           | 主题、语言、全局配置            |
| **生命周期**   | `onMounted`        | DOM挂载后执行                | 发首屏请求、初始化图表          |
|                | `onUnmounted`      | 组件销毁前清理               | 清除定时器、取消订阅            |
| **路由**       | Vue Router         | 页面跳转、参数传递           | 列表→详情、登录拦截             |
|                | 路由守卫           | 权限控制                     | 未登录强制跳转登录页            |
| **状态管理**   | Pinia              | 全局共享数据                 | 用户信息、购物车、多标签页      |
| **数据请求**   | Axios              | 与 .NET API 通信             | 封装拦截器统一处理 Token        |
| **逻辑复用**   | Composables        | 抽离可复用逻辑               | `useCounter`、`useRequest`      |
| **DOM操作**    | 模板 `ref`         | 获取 DOM / 组件实例          | 自动聚焦输入框、调用子组件方法  |
| **内置组件**   | `Teleport`         | 渲染到指定 DOM 位置          | 弹窗、下拉菜单（避开 overflow） |
|                | `KeepAlive`        | 缓存组件状态                 | 列表页返回保留滚动位置          |
|                | `Suspense`         | 异步组件加载状态             | 代码分割时的加载中效果          |
| **自定义**     | 自定义指令         | 封装 DOM 操作逻辑            | 点击外部关闭、懒加载、防抖      |
| **编译宏**     | `defineExpose`     | 暴露子组件方法/属性          | 父组件调用子组件的 `reset()`    |
