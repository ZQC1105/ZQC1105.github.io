## 📝 **创建 PR 评审的 API**

这个接口是用于**创建正式的代码评审**，而不是简单的评论。让我详细解释：

```
POST /repos/{owner}/{repo}/pulls/{index}/reviews
```

## 📌 **什么是 PR 评审？**

PR 评审是一个**正式的操作**，包含：

- 评审结论（批准/请求更改/评论）
- 可以包含多条代码行评论
- 会显示在 PR 的 **Files changed** 标签页中
- 会影响 PR 的合并状态（如果设置了保护分支）

## 🔄 **评论 vs 评审的区别**

| 类型           | API 端点                   | 特点                | 用途         |
| -------------- | -------------------------- | ------------------- | ------------ |
| **普通评论**   | `/issues/{index}/comments` | 简单对话            | PR 底部聊天  |
| **代码行评论** | `/pulls/{index}/comments`  | 针对代码行          | 指出具体问题 |
| **PR 评审**    | `/pulls/{index}/reviews`   | 正式结论 + 多条评论 | 代码审查总结 |

## 📋 **创建评审的 API 详解**

### 基本请求格式

```bash
curl -X POST \
  'http://localhost:3000/api/v1/repos/Chen/Test/pulls/5/reviews' \
  -H 'authorization: Basic Q2hlbjpjaGVuMTEwNQ==' \
  -H 'Content-Type: application/json' \
  -d '{
    "body": "评审总结",
    "event": "APPROVED",
    "comments": [
      {
        "path": "MainWindow.xaml",
        "body": "这里需要修改",
        "line": 15
      }
    ]
  }'
```

### 参数说明

| 参数        | 类型   | 必填 | 说明                                             |
| ----------- | ------ | ---- | ------------------------------------------------ |
| `body`      | string | 是   | 评审总结                                         |
| `event`     | string | 是   | 评审结论：`APPROVED`/`REQUEST_CHANGES`/`COMMENT` |
| `comments`  | array  | 否   | 相关的代码行评论列表                             |
| `commit_id` | string | 否   | 指定评审的提交版本                               |

### `event` 可选值

| 值                | 含义     | 效果                      |
| ----------------- | -------- | ------------------------- |
| `APPROVED`        | 批准     | ✅ 标记 PR 为可合并       |
| `REQUEST_CHANGES` | 请求更改 | ❌ 阻止合并（保护分支时） |
| `COMMENT`         | 仅评论   | 💬 只发表评论，不阻止合并 |

## 💡 **三种评审类型示例**

### 1. **批准 PR (APPROVED)**

```bash

  'http://localhost:3000/api/v1/repos/Chen/Test/pulls/5/reviews' \
```

## 🐍 **Python 完整示例**

```python
import requests
from base64 import b64encode
import json

class GiteaAPI:
    def __init__(self, base_url, username, password):
        self.base_url = base_url.rstrip('/')
        auth_str = f"{username}:{password}"
        self.headers = {
            "authorization": f"Basic {b64encode(auth_str.encode()).decode()}",
            "Content-Type": "application/json",
            "accept": "application/json"
        }

    def create_review(self, owner, repo, pr_number, body, event, comments=None, commit_id=None):
        """
        创建 PR 评审

        Args:
            event: APPROVED / REQUEST_CHANGES / COMMENT
        """
        url = f"{self.base_url}/api/v1/repos/{owner}/{repo}/pulls/{pr_number}/reviews"

        data = {
            "body": body,
            "event": event
        }

        if comments:
            data["comments"] = comments

        if commit_id:
            data["commit_id"] = commit_id

        print(f"创建 {event} 评审...")
        response = requests.post(url, headers=self.headers, json=data)

        if response.status_code == 200:
            result = response.json()
            print(f"✅ 评审创建成功！")
            print(f"   评审ID: {result['id']}")
            print(f"   评审状态: {result['state']}")
            return result
        else:
            print(f"❌ 评审创建失败: {response.status_code}")
            print(f"   错误: {response.text}")
            return None

    def get_reviews(self, owner, repo, pr_number):
        """获取 PR 的所有评审"""
        url = f"{self.base_url}/api/v1/repos/{owner}/{repo}/pulls/{pr_number}/reviews"
        response = requests.get(url, headers=self.headers)
        return response.json() if response.status_code == 200 else []

    def submit_review(self, owner, repo, pr_number, review_id, event, body=""):
        """提交一个 pending 状态的评审"""
        url = f"{self.base_url}/api/v1/repos/{owner}/{repo}/pulls/{pr_number}/reviews/{review_id}"
        data = {
            "event": event,
            "body": body
        }
        response = requests.post(url, headers=self.headers, json=data)
        return response.status_code == 200

# 使用示例
api = GiteaAPI("http://localhost:3000", "Chen", "chen1105")

# 1. 批准 PR
api.create_review(
    owner="Chen",
    repo="Test",
    pr_number=5,
    body="代码质量很好，符合规范",
    event="APPROVED"
)

# 2. 请求更改（带代码行评论）
api.create_review(
    owner="Chen",
    repo="Test",
    pr_number=5,
    body="请修改以下问题后再合并",
    event="REQUEST_CHANGES",
    comments=[
        {
            "path": "MainWindow.xaml",
            "body": "按钮文字应该使用资源文件",
            "line": 15
        }
    ],
    commit_id="9219542366e6fd9913b580aae42f32691cba67dc"
)

# 3. 查看所有评审
reviews = api.get_reviews("Chen", "Test", 5)
for review in reviews:
    print(f"评审 #{review['id']}: {review['state']} by {review['user']['login']}")
```

## 🎯 **在 Webhook 中自动评审**

```python
from flask import Flask, request
import requests
from base64 import b64encode

app = Flask(__name__)

class GiteaClient:
    def __init__(self, base_url, username, password):
        self.base_url = base_url
        auth_str = f"{username}:{password}"
        self.headers = {
            "authorization": f"Basic {b64encode(auth_str.encode()).decode()}",
            "Content-Type": "application/json"
        }

    def auto_review_pr(self, owner, repo, pr_number, pr_data):
        """根据 PR 内容自动评审"""

        # 分析 PR 数据
        additions = pr_data['pull_request']['additions']
        deletions = pr_data['pull_request']['deletions']
        changed_files = pr_data['pull_request']['changed_files']

        # 小改动 -> 自动批准
        if changed_files == 1 and additions + deletions < 10:
            return self.create_review(
                owner, repo, pr_number,
                body="✅ 小改动，自动批准",
                event="APPROVED"
            )

        # 大改动 -> 请求人工审查
        elif changed_files > 5 or additions + deletions > 100:
            return self.create_review(
                owner, repo, pr_number,
                body="⚠️ 改动较大，需要人工审查",
                event="COMMENT"
            )

        # 默认只评论
        else:
            return self.create_review(
                owner, repo, pr_number,
                body="📝 请人工审查",
                event="COMMENT"
            )

    def create_review(self, owner, repo, pr_number, body, event):
        url = f"{self.base_url}/api/v1/repos/{owner}/{repo}/pulls/{pr_number}/reviews"
        data = {"body": body, "event": event}
        response = requests.post(url, headers=self.headers, json=data)
        return response.status_code == 200

gitea = GiteaClient("http://localhost:3000", "Chen", "chen1105")

@app.route('/webhook', methods=['POST'])
def handle_webhook():
    data = request.json

    if data.get('action') == 'opened':
        owner = data['repository']['owner']['login']
        repo = data['repository']['name']
        pr_number = data['number']

        # 自动评审新创建的 PR
        gitea.auto_review_pr(owner, repo, pr_number, data)

    return "OK", 200
```

## ✅ **评审 vs 评论 选择指南**

| 场景         | 使用评论      | 使用评审           |
| ------------ | ------------- | ------------------ |
| 简单讨论     | ✅ 普通评论   | ❌                 |
| 指出代码问题 | ✅ 代码行评论 | ❌                 |
| 正式批准     | ❌            | ✅ APPROVED        |
| 要求修改     | ❌            | ✅ REQUEST_CHANGES |
| 需要阻止合并 | ❌            | ✅ REQUEST_CHANGES |
| 汇总多条意见 | ❌            | ✅ 评审 + comments |

## 📊 **评审状态的影响**

| 评审状态          | 对合并的影响（保护分支时） |
| ----------------- | -------------------------- |
| `APPROVED`        | ✅ 允许合并                |
| `REQUEST_CHANGES` | ❌ 阻止合并                |
| `COMMENT`         | ⚪ 无影响                  |
| `PENDING`         | ⚪ 等待提交                |
