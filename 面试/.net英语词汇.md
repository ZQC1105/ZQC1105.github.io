## 🎯 **面试高频问答题示例**

### WPF相关问题

1. **"Explain the MVVM pattern and its benefits."**
   - Separation of concerns, testability, designer-developer workflow

2. **"What's the difference between DependencyProperty and INotifyPropertyChanged?"**
   - DependencyProperty is for WPF properties, INPC is for ViewModel properties

3. **"How does data binding work in WPF?"**
   - Binding object connects target (UI) to source (data)

### .NET Core相关问题

1. **"Explain the request pipeline in ASP.NET Core."**
   - Middleware components handle requests in sequence

2. **"What are the service lifetimes in DI?"**
   - Transient, Scoped, Singleton

3. **"How does middleware differ from filters?"**
   - Middleware operates at request level, filters at action level

### SQL Server相关问题

1. **"What's the difference between clustered and non-clustered index?"**
   - Clustered determines physical order, non-clustered is separate

2. **"Explain the difference between UNION and UNION ALL."**
   - UNION removes duplicates, UNION ALL keeps all

3. **"What is a deadlock and how to avoid it?"**
   - Circular dependency, access objects in same order
