## 面试官可能问的问题（准备一下）

| 问题                       | 你的回答要点                                                         |
| -------------------------- | -------------------------------------------------------------------- |
| 为什么不用异常？           | 异常适合系统级错误，业务错误用 Result 更清晰、性能更好、控制流可预测 |
| Result 模式有什么缺点？    | 需要显式处理错误，代码可能变长；与 async/await 配合稍显繁琐          |
| 怎么保证调用方不忽略错误？ | 通过返回 Result 类型，调用方必须检查 IsSuccess 才能获取 Value        |
| 和 FluentResults 库比呢？  | 自己封装更轻量，无依赖，且完全符合项目现有架构规范                   |
